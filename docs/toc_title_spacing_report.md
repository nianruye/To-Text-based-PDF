## 附录 A：captain 追加实验（2026-11-18，机制已定位）

### A.1 最小实验：`\vspace*` 其实是精确生效的

```
\vspace*{61.4pt} + \centerline{HEADER}   → HEADER 落在 y=82.4
无 vspace*                                → HEADER 落在 y=21.0（自然位置）
82.4 − 21.0 = 61.4                        ← 分毫不差
```

**结论**：`\vspace*` 完全精确。之前觉得「只移了 45pt」是因为**自然位置不是 12pt，而是 21pt**
（top margin 12 + topskip 相关约 9pt 浮动）。

### A.2 `\topskip=0` 使落位确定

```
\topskip=0pt + \vspace*{22.2pt} + \centerline{HEADER}  → HEADER 落在 y=33.3
预期 12 + 22.2 = 34.2                                  ← 误差 0.9pt（仅为字形 bbox 与行盒差）
```

**结论**：页首加 `\topskip=0pt\relax` 后，首行落位 = `top margin + vspace*`，
不再有 9pt 浮动，可精确按源 y 定位。

### A.3 实测效果（wz3 全量，850 页）

用上面的模型改 `build_geom.py`（`\topskip=0` + 书眉按源 y + 去掉 `_top_vs` 的 11pt 补差）：

| 页 | 源首行 | 改前产物 | 改后产物 |
|---|---:|---:|---:|
| p22 书眉 | 34.2 | 1.6 | **27.3** |
| p24 书眉 | 57.0 | 1.6 | **47.1** |

书眉位置明显改善，p24 的「书眉→首正文」间距 61.8 vs 源书 62.3（**差 0.5pt，几乎精确**）。

**但全库 pitch 从 80.5 掉到 78.2** —— 原因是 `\topskip=0` 同时把**无书眉页**的首行上移约 9pt，
而 `_top_vs` 没有同步补偿，导致那些页反向偏离。

### A.4 下次接着做的话

模型已经清楚了，剩下的只是**逐类页面的 vspace 补偿要同步**：

1. 页首统一 `\topskip=0pt\relax`
2. 有书眉：`\vspace*{hdr_y − 12}` + 书眉 + `\vspace{body_y − hdr_y − hdr_h}`
3. **无书眉**：`_top_vs = body_y − 12`（当前公式已对，但被 `\topskip=0` 改变后要重新核）
4. **无书眉且首行是标题/图版**：同上，但要确认 `HEAD_GAP` 不重复叠加

即「书眉/标题/首正文三类元素的 vspace 必须由同一个模型统一给出」——
这正是 #56「缺版面语义模型」的落点。
