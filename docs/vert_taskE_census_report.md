## 2. 判据（最终实现）

### 2.1 为什么不用简报里失败的五条路

- 不用「沿列 y 切墨段数 > 字数」（竖排汉字墨迹互相贴着，p1683 5 字只切出 2 段）；
- 不用「格数 − 字数 ≈ 1」（会混进 1529 处汉字漏字）；
- 不用「细长竖条 + 落在列框内」（汉字每一竖都符合，全书 15,000 假阳）；
- 不用固定阈值 185（暗页余量只剩 10 个灰阶）；
- 不用文字层上下文推断（p1742 的異體字表是排版内容，不是乱码）。

### 2.2 本实现（连通域 + 形状 + 位置 + 文本对账）

对每个竖排 OCR 列框 `(x0,y0,x1,y1)` + 文本 `t`（n 字）：

1. **字步进**（不用「框高 ÷ 字数」）：本页取「n ≥ 8 的竖排列的 框高/字数」的**中位**（= 邻列步进中位），
   样本不足回退全书同口径中位。实测：p1683 页 **19.3pt** / 全书 **25.44pt**。
   p1683 的框含 2 个漏识元素（破折号 + ⑩），「框高/字数」=30.2 是错的；邻列中位 19.3 才对。
2. **源图二值化**：逐页 Otsu（与 `build_vert` 的 NF 路径同算法、同口径），渲染 2px/pt（= OCR 的 2x px 坐标系）。
3. **连通域 + 聚簇**：列框外扩 0.3 步进后做 8 连通域，按 **y 区间重叠 ≥50%** 聚成「元素」——
   汉字的上/下/左/右部件因此合并成一个元素，不会把「每一竖」当候选。
4. **位置**：只取 y 序**第一个/最后一个元素**，且其中心落在列框**第一格或最后一格**（容差 0.3 步进）。
5. **形状**：
   - **dash**：宽 ≤ 7pt、高 ≥ 12pt、高/宽 ≥ 2.5、高 ∈ **[0.8, 1.8]×步进**、fill ≥ 0.45；
   - **ring**：0.6 ≤ 宽/高 ≤ 1.7、6 ≤ 高 ≤ 40pt、高 ∈ **[0.80, 1.10]×步进**、
     最大分量**中心填充 < 0.35**（圈内空）、**有洞**（hole ≥ 0.10）、**圈内有墨**（团块中心墨 ≥ 0.03，
     即圈码里的数字/点）、洞数 ≤ 3、**四边最小值 < 0.50**（方框汉字 回/日/時 的四边填充更高，被此条挡住）；
   - **other**：经双向标定无可靠判据 -> 关闭（§7）。
6. **OCR 文本对账**（形态 + 文本边字）：
   - dash 的边字必须是**汉字**（p1683 = `孟`）；`！` 等标点自身的竖条不是漏识；
   - ring 的边字不得是引号/汉字/ASCII；只收 `。！？` 与数字（句尾序号）；末格排除 `，、；：`；
   - 文本边字已经是圈码（`⑦/②…`）的 -> OCR 已识别，不报；
   - 方框汉字（回/日/時）靠上面的「四边最小值 / 洞数 / 中心墨」排除。

> 关于高度比：简报写的是 [0.8,1.2]「整格 ±20%」。p1683 的破折号实测 28-30pt，而**本页**邻列步进是 19.3pt
> （30/19.3 = 1.55）——源书这条破折号本身约 1.5 格（双破折号连写，与 wz7 p57 的 1.26 格同族）。
> 若用简报建议的「全书标定值 25.4」则 30/25.4=1.18 落在 [0.8,1.2]；本实现取更稳的 [0.8,1.8]，
> 已知正例必须报出，宁可放宽上限（下界 0.8 仍然挡住汉字竖向笔画）。

## 8. 已知边界与遗留

1. **只查首/末格**（简报要求）：列中间的漏识元素不在本普查范围。
2. **ring 的残余误报风险**：方框汉字（回/日/時/且）已由「四边最小值 <0.50 / 洞数 ≤3 / 中心墨」+ 文本边字挡住，
   但换字体/换书后圈号的环可能更粗（四边最小值 >0.50）-> 需要在新区块上重新标定；本册实测 0 个方框汉字误报。
3. **圈码的“数字已被 OCR 识别”情形**：如文本尾 `...11`，本普查把**圆圈**报为 ring（漏的是图形，不是数字）。
   这与用户的「句号下面直接是数字」一致。
4. **other 类关闭**：松判据全是汉字部件；需要 OCR 逐字框才能可靠区分。
5. **超长列/OCR 截断文本**（如 p1683 页上 `九月初頭…` 列的 OCR 文本只有 20/37 字）：字步进用本页邻列中位，
   不受该列框高影响；但该列的候选位置仍以 OCR 框为准。
6. **未改渲染端**：dash/ring 的渲染修复另开一轮（破折号已有 §1.0a4 的源图实测机制；圈点已有 `VIRT_PARA_MARK`）。
