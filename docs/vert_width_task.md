# taskJ：竖排字宽度还原 + 列内空隙（空格）检测

> 项目：/opt/test。用户实测反馈两项，均已量化：①"看着密密麻麻"= 重建**墨迹覆盖率比源书高 17-25%**（p10 0.171 vs 0.146、p14 0.154 vs 0.127、p100 0.151 vs 0.121；单列同向 +13~29%）——指向**字模横向宽度/字号偏大**；②p14/p15 问答体"問：""答："**后面应有一个空格**（源书空一格），我们的数据与渲染**都没有**（OCR 不保留此类空格）。

## 任务

### A. 字宽度还原（核心）
1. **先测量**（数据驱动，别猜）：
   - 源书：逐字墨迹 **宽/高比**（从源图墨迹测——复用你的 ink 设施；取 ≥50 个字样本，报告 宽/高 中位数；顺便报告源书墨迹高 vs 我们墨高的对比）
   - 我们的渲染：Noto Serif CJK TC 单字墨迹 宽/高比（同法）
   - **结论**：确认为什么覆盖率差 17-25%（是**字宽偏大**、**墨高偏大**、还是**步进偏小**；三者可分别量化：覆盖率 ≈ 墨宽×墨高 / (步进×列距)）
2. **按测量结论修**（二选一或组合，以逼近源书墨迹覆盖率 ±5% 为目标）：
   - **横向压缩字形**（如横向 scale ~0.9，保字高不变）——若源书字模确实更窄
   - **或** 减小字号 + 保持步进（字变小、间隙变大）
   - **或** 若是步进问题则调整列内字距分配
   - 注意：不能破坏此前成果（列底对齐/列顶贴框/标点挤格/字号保护）
3. **验收**：修后逐页对比墨迹覆盖率（p10/p14/p100：重建 vs 源书，差 ≤5%）；渲染 p10 局部放大对比图。

### B. 列内空隙（空格）检测与还原
1. **现状**：`data/wz6/wz6_spotting_lines.json` 里 '問：'/'答：' 无空格；OCR 不保留此类排版空格。
2. **检出方法**（数据驱动、不硬编码页号）：**从源图墨迹逐字聚类**——列内相邻字墨迹间距 > **1.3×中位步进** → 判定该处有一格空隙 → 渲染时插入**全角空格**（或按实测空隙宽度留白）。
   - 复用你已有的逐列墨迹设施（page_metrics / ink_extent 等）；对全书跑一遍，报告检出的空隙总数与分布（页数统计）。
3. **验收**：p14/p15 的 '問：'/'答：' 后出现空格（与源书对照图）；全书空隙检出清单落盘（如 `data/wz6/wz6_gaps_detected.json` 或报告内统计表）。
