## 1. 任务 A：无框伪槽格标定路径

| 步 | 做法 | 锚点 |
|---|---|---|
| 伪版心 | 本页**正文行**（长行 = 本页页高 × 0.120453，单行文本）并集的墨迹包围盒 —— **不用** wz6 的「左带小字一律算边注」判据（无版框书左侧就是正文列，实测 p406 最左列 OCR x0=76px < 全局左带 155px 会被误丢） | `nf_body_rows` |
| 伪槽格 | 伪版心内 `_ink_bands(cov=0.12)` 墨迹列带 → 格边界 = **相邻带心中点**（列间空隙中点），首末外扩半列距 → 格宽 = 列距（与框驱动槽格同语义：标点摆位 `PUNCT_DX` 的分母就是格距） | `nf_edges` |
| 短列补齐 | 列带数 < 正文行数时按「残余墨迹 x 投影」(cov_lo=0.04) 补带 —— 段尾/詩行短列覆盖率低于 0.12 会漏检，而列带数少于行数时 `page_puts` 把配不上的行**整列丢掉**（实测 p1205 丢 78 字） | `nf_fill_bands` |
| 槽统计 | run/槽顶/槽底/步进/字号**完全复用** §1.98 的 `_slots_of_edges` + `_metrics_finish`（框驱动与伪槽格同一套口径，故源侧标定样本可比） | §1.98 重构 |
| 不画框 | `frame_tex` 见 `g['virtual']` 直接返回空 —— **不凭空画**外框/内框/界行线 | `frame_tex` |
| 开关 | `NF_MODE = 抽样页一个版框都没测到(FRAME_REF is None) 且 VERT_NOFRAME != 0`；有版框书（wz6）与「有版框但无槽可配」的 §1.99 路径**一字不改** | §1.975 |

**OCR 坐标回源图坐标系**（本次新发现，见 §3）：无版框书先做逐页仿射标定（尺度 = 相邻间距比的中位、截距 = 中位差；
y 尺度 = 字步进比中位；枚举错位 d 抗端部多一条），把本页 OCR 行映射回源图坐标系后再交既有判据 —— 标定不过关（尺度不在 [0.7,1.6]、
残差 > 0.5 列距、或映射后正文落点与墨迹列带不符）则**保留原坐标**。

**标定趟 B 的源侧换了两处口径**（都只在 NF 生效，wz6 逐位不变）：

| 项 | wz6 口径 | NF 口径 | 为什么 |
|---|---|---|---|
| 源图二值化 | 固定 `< 150`（纸 253/墨 50 → 阈值恰在两峰中点） | **逐页 Otsu**（实测 wz7 阈值 134-148） | 灰底扫描纸 185-199/墨 40，固定 150 把边缘灰晕算成墨迹：同一页 a/h² 在 110→170 阈值下 wz6 只变 +38%、wz7 变 **+110%** |
| `XSCALE` | 面积/高² 口径 | **墨宽/墨高比口径**（`_calib_xscale_w`） | 面积口径对二值化阈值过敏（wz7 算出 **1.85** = 把字拉宽到列距 1.8 倍，直接崩版）；宽高比口径同扫描阈值下只变 ±5% |

## 3. 「页码 x 越出页幅」的根因（taskN 遗留）—— **坐标系问题，不是坏数据**

| 证据 | 实测 |
|---|---|
| p406 墨迹列心 vs OCR 行心 最小二乘 | `x_ocr = 1.203 x_源 − 184`（16 列配对，尺度 **+20%**） |
| 同一页字步进比 | OCR 行高/字数 ÷ 墨迹字步进 = **1.12**（y 方向 +12%） |
| p407（水平行、x 到 2648） | 该页整页落在 **90° 旋转坐标系**里：用 `y' = 1.129 X + (−1439)` 反解，「金瓶梅」落到源图 x1211-1254/y475-677（源墨迹实测 x1221-1253/y469-661，差 ≤ 10px）；页码「三六四」x'2476-2649 反解到源页 y2367-2520（源图该处正是竖排「三六四」） |

结论：OCR 服务把页面归一化到了**另一个画布**（x 尺度 1.07-1.20、y 1.12-1.16，逐页略异；个别页还带 90° 旋转），
所以坐标**合法地**大于页宽。处置 = 几何一律取源图墨迹（本管线既有原则）+ NF 页先做逐页仿射标定回源图坐标系；
不做「安全跳过」以外的数据修补，也不改 OCR 原始 JSON。

## 5. 遗留（如实）

1. **短列漏检的残余**：`nf_fill_bands` 只能补「残余墨迹还在」的列；源页 1205 与 1239 各有 1-2 列（78 / 40 字）
   仍未被检到 → 该列文字不渲染（`verify_vert` 记为非预期差异页，本次 24 页里 2 页）。
   下一版可做「按 OCR 行 x 中心补槽」（本次未做：OCR x 有系统缩放，注入槽位会把列摆偏，风险大于收益）。
2. **字号略大 5-10%**：字号 = 墨迹字高 / `INK_RATIO`，而源侧墨迹字高仍是 150 阈值口径（比「清晰边界」大 ~5%）；
   若要完全对齐需把 NF 的**渲染侧**墨迹也换成 Otsu 口径（会动 `page_metrics`/`col_puts` 的共享常量，本次未做）。
3. **`N_COL_FRAME` 在 NF 下仍是 12**：伪槽格不用它（槽数 = 列带数），只有 §1.99 兜底路径的「空闲槽位」用它，
   影响面小；若要改需同时改 §1.99 的槽位回退。
4. **OCR 帧标定约半数页可用**（facsimile 序页/旋转页/条数差太大者不采纳，保留原坐标）——
   这些页的**正文列位仍正确**（槽位来自墨迹），只有页码/书眉这类「按 OCR x 判边带」的行会受影响。
5. 页码/书眉渲染覆盖率受限于 OCR（100 页只认出 4 个页码行），见 §2.3。
