## 10. 方法与局限（v2）

- **行/列切分**：横排 = `page.get_text("rawdict")` 的 line（同 block 归段）；竖排 = 字符按 x 聚类列
  （容差 0.45×中位字宽；竖排标点 x 偏移实测 ±7pt）。行首/行末 = 首/末非空白字符。
- **F1 源位置闸门**：违规字符必须等于最相似 OCR 行（或同页 ratio≥0.45 相似行）的行首/末字符；
  否则 B。OCR 行合并/切分时用相似行兜底；OCR 误读「一」→引号的修复归 C_fixed。
- **F3 carry**：见 §5.3；K_weak/K_invalid 不计违规，但需人工复核（附录 C）。
- **F4 局限**：多段引文（§4.8.3.5）**未实现**合法性判定（spec 已删除该检查项），未配对 open 统一归 O 残差；
  O=1,636 是混合残差（t5 独立统计：立即下一行/列以开引号开头的仅 17 条）。
- **F6 复现**：md5 依赖参数（含 label）；同一命令两次运行一致（§3.3）。
- **其他**：竖排页眉/页码、横排元数据页会作为行/列参与审计（噪声已在 §7.2/§9 标注）；
  源图侧 C 检测是形状启发式（宽扁横条），C=234 是下界。
