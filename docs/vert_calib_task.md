# taskM：参数自标定改造（把 wz6 实测常数改成每本书自动标定）

> 项目：/opt/test。**用户质疑："我们要做的是系统，不是只针对这本书——所做的都有代码逻辑，可以适用到其他书籍吗？"** 审计结论：**机制大多是通用的，但有一批常数是从 wz6 源图实测后硬编码的**，换书必然失准。本轮把它们改成**建排前从源图/OCR数据/字体文件自动标定**。

## 审计结果（助手已核，行号为准）

### ❌ 必须改成自标定（wz6 专属实测值）

| 常数 | 现值 | 位置 | 来源 | 换书风险 |
|---|---|---|---|---|
| `XSCALE` | 0.87 | L115 | "源书比候选窄 1.48 倍"（wz6） | 别的书字面宽不同 → 压缩过头/不足 |
| `N_COL_FRAME` | **12** | L798 | "版框内框列数(印版常数)" | **别的书不是 12 列** → 内框左右缘推错（L1001-1004 用它反推 il/ir；L1237 `_grid_from_bands` 默认参数） |
| `PUNCT_SIZE` | 0.62 | L55 | "源书标点墨迹高仅正文字号 ~0.17em" | 标点大小/挤格位置失准 |
| `PUNCT_DX` / `PUNCT_DY` | 0.81 / 0.85 | L56-57 | "源书实测" | 同上 |
| `BR_SIZE_DEF` | 0.66 | L324 | "源书 ︵/︶ 标定" | 竖排括号大小失准 |
| `BR_SIZE` | {︗:0.55,︘:0.55,︹:0.49,︺:0.49} | L325 | "源书实测: 【】〔〕 明显更小" | 同上 |
| `GAP_HANG` | 0.85 | L161 | "源书实测" | 空隙/标点判定偏移 |
| `V_FRAME_GAP` / `V_FRAME_TH` | 3.2 / 3.4 pt | L794-795 | 缺测时的补位值 | ⚠️ **半自适应**（实测优先）→ 可保留为兜底，但须标注"兜底值" |
| `NOTE_STEP_RATIO` | 0.85 | L575 | 边注/正文步进比**上限** | ⚠️ 判据性上限，须复核是否对别的书偏紧 |

### ⚠️ 字体绑定（不是书绑定——可从字体文件自动算）

`INK_RATIO` 0.88 / `INK_ASC` 0.94 / `NOTE_INK_RATIO` 0.88 / `NOTE_INK_MAX` 0.94（L577/583/1201-1202）、`VERT_METRICS`（L314，竖排括号墨心 em 值）
—— L1883 注释已写明"按 Noto 标定"。**改法：用 fontTools 从当前 `VERT_FONT` 字体文件直接算**（em→字形 bbox→墨高/墨心），算不出才回落现值。这样换字体不需要人工重标。

### ✅ 已经是数据驱动（无需改，写入文档即可）

`TOP`/`RIGHT`（天头/版心右缘，OCR 统计）｜`NCOL`（列数 90 分位）｜`FS`/`PITCH`/`HCOL`/`TTOP`（中位统计）｜版框线与界行线检测（源图墨迹）｜`_grid_from_bands`（实测界行线栅格）｜**derot**（L1087 明写"数据驱动，不硬编码页号/常数"）｜列高/列距/列内字距（版框驱动+字数自适应）｜空隙检测（1.3×该列中位步进）｜字号保护（0.95×步进，相对量）｜页码序列（等差拟合+邻页插值）｜边注/书眉/页码定位（源图墨迹实测）｜退出码分级/临时目录分离（通用）

### ✅ 算法内部权重（尺度无关，通用）
DP 代价 `P_MERGE/P_PUNCT/P_SKIPN/SKIPR/GAP/TOT`（相对比较）｜`GAP_MAX=4`（防异常）｜`DEROT_MIN_ROWS/RMS_MAX`（判据）｜`PN_TOL/PN_GAP`（序列容差）

## 任务

新增**标定趟**（建排前，一次；结果可落盘缓存/日志，并在日志打印）：从**源图墨迹 + OCR 数据 + 字体文件**自动测出本书参数。

| 参数 | 标定方法（建议） |
|---|---|
| `XSCALE` | 源书正文**单字墨迹字面宽中位** ÷ 当前字体渲染同字**墨迹字面宽中位**（同一套墨迹口径）。wz6 应落在 0.87 附近（±0.05）即验证成功 |
| `N_COL_FRAME` | 由**实测**：内框宽 ÷ 列距（取整）；与界行线条数交叉校验；**实测优先，12 仅作兜底** |
| `PUNCT_SIZE` | 源书挤格标点**墨高中位** ÷ 正文字高（同一口径）→ 字号比 |
| `PUNCT_DX`/`PUNCT_DY` | 源书标点**墨心**相对前字格左缘/格顶的**相对位置**（以格距/步进为单位）统计中位 |
| `GAP_HANG` | 同 PUNCT_DY 口径（二者同源，可共用一次统计） |
| `BR_SIZE_DEF` / `BR_SIZE` | 源书各类括号**墨高中位** ÷ 正文字高，按括号类型分档（不足样本回落到实测中位） |
| 字体绑定组 | fontTools 从 `VERT_FONT` 文件解析（注意 .ttc 需按 index 取 TC face）；失败则回落现值并在日志标注 |

**保留 env 覆盖**：所有标定结果都可由既有（或新增）env 覆盖——**显式 env 优先于标定**；**不设 env 时行为 = 标定值**。

## 验收标准（硬）

1. **对 wz6 的自标定对账表**：每项列出「标定值 / 现值 / 相对差」——接近（如 XSCALE ±0.05、N_COL_FRAME 精确 12、PUNCT_SIZE ±0.05、BR_SIZE_DEF ±0.05）即为逻辑正确；**明显偏离必须查明原因**（是标定方法错，还是原常数本就不通用）
2. **wz6 产物不回退**：`verify_vert` PASS（231:1 / 字符量 / span 0 / 矢量 0）；覆盖率不降；与标定前产物做 diff，**差异限于"标定值 vs 原常数"的实际差别**（若差异 >5% 页面字符量变动须解释）
3. **测试全绿**（当前 249）+ 新增标定逻辑的单元测试（用合成/既有数据，不依赖网络）
4. **日志可见**：每次构建打印标定结果（便于其他书排障）
5. **文档**：新增 `spec/vertical/09_calibration.md`（每项参数的标定口径/兜底/env/实现锚点）+ 更新 `spec/vertical/README.md` 锚点表 + `docs/vert_calib_report.md`
6. 不动横排/四书；数据变更前备份；不 git reset；完成后 git add 不 commit
