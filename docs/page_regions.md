# XY-cut 空间区域检测（t365）

## 算法

同 y 合并前，对每页行 bbox 做空间分栏：
- 窄行（宽<0.65×页宽）找 x 空隙 >40px，左右各≥2行且 y 重叠>50%；
- 全宽行（≥0.65页宽）若在窄区下方（y≥上方末行−5）独立成「全宽下段」；
- 其余全宽行并入左区；无两簇 → 1区。

导出 `<out>.regions.json`；不改渲染。
