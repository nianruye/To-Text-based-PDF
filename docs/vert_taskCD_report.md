## 2. 根因（逐页，全部为实测）

### p563（修前 0 字）

源页是回目目录：8 条竖排回目列，每列在 OCR 里是**一条多块合并行**（列内回目/标题/页码被 OCR 用
`\n` 连接，如 `第六十三回\n親朋宿伴玉簫記\n西門慶觀戲感李瓶四六七`）。

- `nf_join_rows` 修前只用「**无换行**行」求步进中位。p563 唯一无换行行是 1 字页码「三」（`len < 2`
  被排除）→ 中位样本为空 → `return rows`，8 条列不拼接。
- 下游 `nf_body_rows` / `page_rows` 都按「带 `\n` = 多块合并残片」丢弃 → 正文行 0 条 →
  `_nf_frame` 返回 None → 掉 v2 流式 → v2 同样跳过 `\n` 行 → **整页 0 字**。

### p1171（修前 7 字）

目录页，同 p563 的多块合并行，但页上另有 6 条馆藏水印/条码行（页顶手写 `859.49/6996/879/v.3`、
页底横排 `国家图书馆/004757702`）。

- 修前中位样本 = 7 条无换行行，其中 6 条是水印（每字 4.1-27.5px），只有目录标题行 66.6px →
  中位被拉到 17.35px；真回目列 66.1px / 17.35 = 3.8 > 1.4 → 全部判「不拼」→ 只剩无换行的
  `詞話第三冊目錄` 7 字。
- 水印行还有第二重危害：页底条码行（x 641.6-833.3px）与第 7 回目录列（x 578.1-624.6px）外的
  x 带重叠，`_merge_col_rows` 会把「国家图书馆」并进邻列 → 整列错字（修前旧补丁实测产物出现
  `第七十三回…国家图` 这样的混合串）。

### p659（修前 220 字）

回目页：1 条大字回目列（列内 3 行：第四十一回 / 西門慶與喬大户結親 / 潘金蓮共李瓶兒鬥氣，
字高 38pt）+ 4 个诗列 + 9 个正文列（字高 23-26pt）+ 书眉/页码列。

- `_metrics_finish` 修前取 `hmax = max(槽字高)` = 38pt → 正文门槛 `0.75×38 = 28.5pt` →
  占多数的 14 条正文列（23-26pt）全部被判成「小字注槽」→ `page_puts` 只剩 2 个 body 槽
  （日志 `[正文列] p659 2 行 -> 2 槽`），9 条正文 + 4 条诗行改走 `note` 路径，按 9-23pt 错字号
  渲染 → 产物 220 字。
- 注：AB_FIX 只解决「行↔槽配对」；本页的问题是**槽本身被分错类**，在配对之前。

### p1742（修前 120 字）

竖排说明（4 列）+ 字表（10 列）。字表每列在源书里是 4 段上下叠放（如
`趨—趨—趨 / 踈—踈—疏 / 窺—桃 / 瞰—聰`），OCR 同样合并成一条带 `\n` 的行。

- 修前中位由 4 条说明行（每字 60.5-60.9px）+ 标题行（76.1px）决定 = 60.5px；
  字表列每字 97-141px → 比值 1.6-2.3 > 1.4 → 10 条字表行全部不拼 → 只剩 5 条（标题+说明）
  走 §1.99 框内兜底 → 120 字。

## 3. 改动（全部 env 开关，默认关 = 保持现行为）

| 开关 | 默认 | 作用 |
|---|---|---|
| `VERT_NF_JOIN_MED` | `0` | `nf_join_rows` 步进中位改取「按拼接后字数 >= 8 的行」（不足 3 条退回 >=2 字行）；只影响带 `\n` 的行 |
| `VERT_NF_JOIN_HI` | `1.5` | 仅 `VERT_NF_JOIN_MED=1` 时生效：拼接步进上界（修前 1.4 倍） |
| `VERT_NF_BODY_TIER` | `0` | `_metrics_finish` 的 `hmax` 改取「最高四分位的中位」；仅 NF 伪版心页 |
| `VERT_NF_DROP_MARGIN` | `0` | 剔除「整行在伪版心 y 之外 且（横排 w/h>=2.5 或无汉字）」的扫描水印/馆藏标签行 |
| `VERT_NF_MARGIN_AR` | `2.5` | 上述水印判据的行盒宽高比下限 |

`VERT_NF_JOIN_HI=1.5` 的依据（全书 1748 页模拟，JOIN_MED 口径）：窗口 1.4 → 1.5 只多拼 **3 行**，
逐行核对均为真列：

| 页 | 比值 | 文本 |
|---|---|---|
| p400 | 1.413 | `當局者迷，傍觀者清。` |
| p1511 | 1.488 | `第八十九回清明節寡婦上新墳吳月娘誤入永福寺三四一` |
| p1742 | 1.451 | `鬢髮鬢鬢賫賫齋迯逃澀澀`（本轮第 10 个字表列） |

`VERT_NF_BODY_TIER` 的数学性质：单字号页 top 四分位的中位 == max → 取值与修前**逐位相同**；
只有「少数槽明显大字号」时参照才下移，且大字号槽占 >= 25% 槽数时参照仍会被抬高（保留原有
「整页字号分层」的语义）。

水印判据的第二条「横排或无汉字」用于避免误伤真书眉/页码：本书书眉/页码是**竖排汉字**，
且 `special_rows` 的页边带判据仍然生效（p1171 页码「一」、p659 页码「九九」正常渲染）。

改动落点：

1. `nf_join_rows`（§1.975）：中位口径 + 上界（`globals().get` 读取，保证 AST 单测加载器在
   不注入新全局时仍按默认口径通过）；
2. `_metrics_finish`（§1.98）：`hmax` 四分位口径（`g['virtual']` 门控，有版框书/wz6 不进入）；
3. `_nf_margin_artifact()`（新函数）+ 建排主循环 `pm = page_metrics(...)` 之后、`_page_specials`
   之前整行剔除（必须在此之前：否则水印会被 `special_rows` 认成书眉/页码，或在 `page_rows`
   的行合并里并进目录列）。
