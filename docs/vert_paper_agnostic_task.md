# taskN：竖排管线纸型无关化（剩余 6 项人工依赖 → 相对量/自标定）

> 项目：/opt/test。承接 taskM（参数自标定）。用户要求："我们要做的是系统，不是只针对这本书——可以适用到其他书籍吗？" 并已提供第二本竖排书 **wz7《金瓶梅詞話》1748 页**（921.8×1443pt，**无版框线/无界行线**、约 16 列/页、书眉+页码在右上版心、页码与 PDF 页序有另一套编号）作为跨书验证样本。
> 本轮目标：把 taskM 报告 §6 列出的**剩余人工依赖**改成**相对量/自标定**，使管线不再绑定 wz6 的纸型与开本。
