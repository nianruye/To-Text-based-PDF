**③ 字体识别与分配**（用户提问——请做成程序化能力）：
- **必须程序化**（用户既定原则：视觉模型判楷/宋不可靠；"同类板块字体一致"优先于单字绝对正确）。
- 建议两步：
  1. **笔画特征**：对源图墨迹逐字统计「横笔画中位宽 / 竖笔画中位宽」比值等特征（宋体≈1:2~3、黑体≈1:1、仿宋≈1:1.2、楷体变化大且有笔锋）；
  2. **模板匹配**（更可靠）：把源书**若干字的墨迹**与**候选字体渲染的同字**做相似度比较（候选：Noto Serif CJK SC/TC（宋体系）、Noto Sans CJK（黑体系）、系统可用楷体（`fc-list :lang=zh` 查，如 AR PL UKai / Noto Serif CJK 无楷则说明）、仿宋（如有）），归一化后比 IoU/特征距离，取最像者。
- **分区判定**：正文 / 注释小字 / 标题 / 页眉页码 / 边注 各自独立判定（老书常见"正文宋体+注释/小字用另一种"）。
- **输出**：`docs/vert_font_id_report.md` 含每区的字体判定 + 证据（相似度数字/特征值）+ 样本字对照图。
- **应用**（若判定与现用字体不同）：按判定换字体渲染（同板块统一），**若系统无对应字体则如实报告并给选项**（如"宋体体系已是最接近候选"）。
- **验收**：判定报告 + （若换字体）p3/p4/p10 渲染对照图 + verify_vert PASS + 测试全绿。
