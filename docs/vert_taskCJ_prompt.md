## 我的诊断（请你验证或推翻）

代码 `src/pipelines/build_vert.py` 第 3012 行有 `_geom_ok(i, j)`：

```python
def _geom_ok(i, j):
    r, s = rows[i], slots[j]
    if pitch > 0:
        if abs((r[0] + r[1]) / 4.0 - (s['x0'] + s['x1']) / 2.0) > AB_XK * pitch:
            return False                      # ① x 中心距约束
    if s.get('top') is not None and s.get('bot') is not None:
        tol = 0.5 * (step or 12.0)
        if r[3] / 2.0 < s['top'] - tol or r[2] / 2.0 > s['bot'] + tol:
            return False                      # ② y 范围相交约束
    return True
```

**我判断：这两条正好治 p159 这个病，但它们只在 `geom=True` 时生效**（`geom = AB_GEOM or _toc`），而正文页走的是纯「按序/按格数」配对，**完全没有位置约束** —— 所以「畢竟…」那行被配到了一个 x 上存在、但 y 上不相交的槽。

**我倾向的修法（A 档）**：只把 ②「y 范围相交」硬约束加到正文页（不加 ① 的 x 距离约束，因为后者依赖 OCR 坐标标定质量）。
