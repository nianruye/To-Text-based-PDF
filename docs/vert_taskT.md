# taskT：标点视觉尺寸/格内位置按源书实测标定（用户多轮反馈"标点与字重合"）

> 项目：/opt/test。用户反复反馈"**标点还是跟字体重合了**"。助手已做两轮检测，**结论与陷阱**如下——请从这些事实出发，**不要再重复走弯路**。

## 已核事实（助手实测）

1. **`bbox 重叠` 检测是假象**：对 `tmp_vert/taskS/S300.pdf` 用 PyMuPDF 逐 span 比 bbox，报出 16215 处"标点与汉字 bbox 重叠"（最严重 30pt/整格）。**但实测**：p43 的 `'甚' bbox 高 85.5pt` / `'，' bbox 高 90.1pt`（**而字号只有 29.7/31.3pt**）——**PyMuPDF 给竖排 span 的 bbox 高度远大于字形**（≈3×字号），相邻字实际 y 间距 53pt（**正常，没重合**）。→ **判定"重合"必须用墨迹像素或字形范围，不能用 fitz span bbox**。
2. **抽查渲染无"压字"，但有别的差异**（vision 看 p43 与 p354 放大图的一致结论）：
   - **我们的标点比源书更小、更细**（源书标点虽也小，但与汉字笔画"融合"得更好）；
   - **我们的字距/行气比源书松**（源书更紧凑饱满）；
   - 标点位置贴前字右下（与源书相似），但间距感受不同。
3. **参数状态**：`taskS` 已标定出 `PUNCT_CELL=1`（源图侧 195 槽样本中位 0.990，"标点独占一格"）；构建日志对账表里**没有列出 `PUNCT_SIZE` / `PUNCT_DX` / `PUNCT_DY`**——**先确认这三项在 NF 路径上是否真的被标定/生效**（这是本轮的起点）。

## 任务

### A. 源书侧严格实测（源图墨迹，抽样 ≥10 页，含正文页与诗页）
对**标点集** `。，、；：？！`（以及 `「」『』` 若样本够）逐类实测：
- **标点墨迹高/宽 与 同页汉字墨迹高/宽 的比值**（中位 + 分布）；
- **标点墨心相对"前字格"的位置**（以格距/步进为单位：横向偏移、纵向偏移）；
- **标点与前字、后字的墨迹间隙**（pt）。
输出**逐类表**（不要只给总中位）。

### B. 我们侧同口径实测 + 差异表
对同一批页、同一套墨迹口径测量产物（`tmp_vert/taskS/S300.pdf`），产出**差异表**：源书 vs 产物（标点尺寸比、墨心偏移、前后间隙）。

### C. 按差异修（**保持"占格"语义**）
- 若**标点字形偏小** → 调标点字号（`PUNCT_SIZE` 应来自源书实测而非兜底 0.62——**先查明为何日志未列此项**）；
- 若**格内位置偏** → 修 `PUNCT_DX/DY`（按实测墨心，以格为单位）；
- 若**与前/后字间距偏** → 修标点的**格内排布**（占格标点应居中于自己的格；挤格标点才贴前字）；
- **`PUNCT_CELL` 的语义必须保持正确**（wz7 = 占格 1；wz6 = 挤格）。**改动后 wz6 的行为必须逐字节不变**。
- 若发现"我们整体字距比源书松"属**另一独立问题**（步进/字号口径），一并量化，**但不要顺手改**——先报告，给证据与建议。
