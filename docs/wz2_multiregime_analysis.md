# wz2 多规制混排分析（pitch 卡在 75.5% 的真正原因）

> 2026-11-20 ｜ 触发：T4 修完后 wz3 行距已到 0.0%，但 wz2 仍 5.2% 偏差

## 1. 现象

T4 修正后（`PITCH_RATIO=1.022`），随机抽页实测：

| 页 | 产物行距 | 源书行距 | 偏差 | 保真页 |
|---|---:|---:|---:|---|
| p4 | 23.3 | 23.3 | **+0.0%** | |
| p23 | 28.3 | 27.1 | +4.4% | |
| p31 | 25.9 | 26.2 | −0.9% | |
| p39 | 27.6 | 25.9 | +6.5% | |
| p42 | 27.6 | 26.0 | +6.0% | |
| **p50** | **30.5** | **25.9** | **+17.6%** | |

中位偏差 **+5.2%**（wz3 已达 0.0%）。

## 2. 根因：同书两种行距并存

源书 wz2 采样 15 页的行距分布：

```
26.2, 31.7, 31.7, 31.7, 26.2, 27.1, 26.2, 31.0, 31.7, 26.2, 26.2, 26.4, 26.2, 27.1, 26.2
中位 26.4 | 范围 26.2~31.7 | CV 9.1%
```

**两档行距差 21%**：
- **26.2pt** = 正文
- **31.7pt** = 注疏 / 校勘记（小字密排）

## 3. 逐页 _pp 量得准，但渲染对不上

`layout_model.page_pitch` 逐页量得**很准**：

| 页 | page_pitch | 源书实测 |
|---|---:|---:|
| p23 | 27.91 | 27.1 |
| p31 | 27.45 | 26.2 |
| p42 | 27.17 | 26.0 |

但产物 p50 的行距分布是**两段**：

```
前段 27.8pt（对应 _pp=27.17）✓
后段 30.9pt（注疏行，被撑大）✗
```

即：**一页内两种规制共用同一个 `_pp`**，正文段对上了，注疏段必然偏大。

## 4. 另一个叠加因素：`_strut` 的 descender 系数不是常数

现有公式 `_strut = bl - fnt*0.13`，其中 `0.13` 是按 **wz3 FONT=14.5** 标定的。
反推 wz2（FONT=15.7）各页的等效 descender：

| 页 | FONT | 实测 pitch | strut | descender | d/FONT |
|---|---:|---:|---:|---:|---:|
| p23 | 15.7 | 28.32 | 23.87 | 4.45 | 0.284 |
| p31 | 15.7 | 25.92 | 23.41 | 2.51 | 0.160 |
| p39 | 15.7 | 27.60 | 23.40 | 4.20 | 0.268 |
| p42 | 15.7 | 27.60 | 23.13 | 4.47 | 0.285 |
| **p50** | 15.7 | 30.48 | 23.13 | **7.35** | **0.468** |

**0.160 ~ 0.468，极不稳定** → 说明 `pitch = strut + descender` 这个线性模型
在混排页上不成立（注疏行的小字 descender 与正文字号不同）。

## 5. 保真页的干扰（次要）

`config/books/wz2.json` 的 `faithful_pages` 有 36 页。这些页是：
```
源图铺满 + 3Tr 不可见文本层按源坐标落位
```
视觉上完美，但 `verify` 量的是文本层的行距 —— 保真页的文本层是逐行 `\put`，
每行内容可能被拆成 2–3 个 span，**行距指标无意义**。

本轮已在 `_toc_like` 之外单独确认：184 个失败页中 **10 页**是保真页。

## 6. wz2 失败页最终构成

| 档次 | 页数 |
|---|---:|
| 保真贴图页（视觉已完美，指标无意义）| **10** |
| 轻 3–5% | **67** |
| 中 5–10% | **89** |
| 重 >10% | **18** |
| **合计** | **184** |

## 7. 可能的修法（均未实施，需评估）

| 方案 | 做法 | 风险 |
|---|---|---|
| **A. 按行分组各给 bl** | 把同页的正文行/注疏行分成两组，各用本组源 pitch | 中 —— 要改 `flush()` 的 para 分组逻辑，可能影响所有书 |
| **B. 放弃 `_pp`，改用逐行源 y 差** | 每行按与上一行的源 y 差直接给 vspace | 中 —— 逐行 vspace 会破坏 LaTeX 的分页 |
| **C. descender 改为按字号标定** | `_strut = bl - fnt*k(FONT)`，k 按实测标定 | 低 —— 只调系数，但要先证明线性成立（§4 显示不成立） |
| **D. 登记为已知限制** | wz2 转页级保真回退（当前 36 页），或接受 75.5% | 无 |

**倾向 D 或 A**：
- §4 已证明 descender 模型不成立 → C 走不通
- B 会破坏分页，风险高
- A 是正解，但要动核心渲染循环

## 8. 与 wz3 的差别（为什么 wz3 能修好）

| | wz3 | wz2 |
|---|---|---|
| 规制 | **单一**（正文一种行距 21.4pt）| **两种**（26.2 / 31.7pt）|
| T4 后偏差 | **0.0%** | 5.2% |
| 结论 | 全局系数足够 | 需要**分行组**处理 |

即：T4 的全局 `PITCH_RATIO` 对**单规制书**有效，对**多规制书**只能修好其中一档。
