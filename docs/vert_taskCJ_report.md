# taskCJ 报告：nf_edges 槽心公式修复（R3 实现）

> 前置诊断：[docs/vert_taskCJ_diagnosis.md](vert_taskCJ_diagnosis.md)（R2）
> 根因：`nf_edges` 把槽边界放在相邻墨迹列带心中点 -> 槽心被一侧空白拉偏 `(G_R-G_L)/4`
> 修法：B 档「槽窗口锚定到本列墨迹带中心」+ 稳健 pitch（最小 60% 差值中位）
> 开关：`VERT_NF_SLOT_ANCHOR`（默认 1；=0 复现旧口径）
> 状态：进行中（每完成一项补一节）

## 1. 改动清单

`src/pipelines/build_vert.py`：

| # | 位置 | 改动 |
|---|---|---|
| 1 | §1.975 `nf_edges` | 列距稳健化：`p_robust = median(最小的 60% 相邻带心差)`；仅当 `p_robust < 0.85 x p_median`（中位被 >= 1.5x 列距的空白污染）时替换，否则保持旧口径 —— 保证普通页首末槽外缘（pitch/2）逐位不变 |
| 2 | 新增 `_anchor_wins(edges, anchors, pitch)` | 纯函数：病态槽（宽 > 1.25x列距 且 中点偏离本列带心 > 0.25x列距）窗口收到 `带心 ± 半列距`，两端不小于带缘 ± 4pt |
| 3 | `_slots_of_edges` | 新增 `anchors/pitch` 参数；槽统计（run/top/bot）改用 `_anchor_wins` 的窗口；`slot['x0'/'x1']` 同步 |
| 4 | `_nf_frame` 返回值 | 增加 `'bands'`（最终列带按带心升序，与 `cells` 一一对应） |
| 5 | `page_metrics` / `page_metrics_rf` | NF 分支把 `gv['bands']`/`gv['pitch']` 传给 `_slots_of_edges`（有版框路径不传 -> wz6 逐位不变） |
| 6 | `_split_slot_y` | 子槽增加 `absub=True` 标记（供渲染端识别 y 拆分子槽） |
| 7 | `col_puts` | y 拆分子槽按本子槽实测墨高定字号（`_big_hm` 75 分位 / INK_RATIO）；细笔画/断裂 run 用子槽跨度反推兜底 —— 修掉 `(G_R-G_L)/4` 修复后书眉/页码被按页字号放大的副作用 |
| 8 | 开关 `VERT_NF_SLOT_ANCHOR` | 默认 1；=0 时稳健 pitch + 槽窗口锚定 + ysplit 字号修复全部关闭（精确复现旧口径，供 A/B） |

**未改**：`_align_rows_slots`、`AB_XK`、`verify_vert.py`、有版框（wz6）路径、`_toc_puts`。
