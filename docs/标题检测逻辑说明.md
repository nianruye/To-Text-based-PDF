# 标题检测逻辑说明

**核心设计**：用结构规则替代字体分类器，避免域偏差导致的误判。

---

## 一、调用前置条件

一行要进入标题检测，必须**同时满足 4 个条件**：

| 条件 | 含义 | 作用 |
|------|------|------|
| `key in content_page_keys` | 是正文页（非封面/CIP/版权页） | 排除前置页 |
| `not is_toc_page` | 不是目录页（无 `目录` 关键词或 `...数字` 模式≥3行） | 避免目录条目误判 |
| `not is_header` | 不在页眉区（`y_pt < HDR_REGION_Y` 且在 `page_headers` 合并索引内） | 排除页眉 |
| `not is_footnote_start(t)` | 文本不以 ①②③④⑤⑥⑦⑧⑨⑩ 开头 | 排除脚注 |

**说明**：
- `HDR_REGION_Y` 从 OCR 坐标动态计算（页眉底部 + gap × 1.5），通常为页高的 15% 左右
- 正文页判定：页面有大量全宽正文行（`is_content_page` 函数，line 152）

---

## 二、前置过滤（进入检测后先排除）

```python
if not (1 < len(t) < 45 and y_pt > HDR_REGION_Y):
    return None, 0

if is_toc_entry(t):  # 检测结尾是否有 ...数字 或 ……数字
    return None, 0
```

| 过滤条件 | 作用 |
|---------|------|
| `1 < len(t) < 45` | 排除空行、页码、超长行（真实标题不会超长） |
| `y_pt > HDR_REGION_Y` | 排除页眉区域残留 |
| `is_toc_entry(t)` | 排除目录条目（`r'[…\.]{2,}\s*\d{1,4}\s*$'`，点前导+页码结尾） |

---

## 三、检测优先级（首个命中即返回）

**优先级从高到低**，L1 → L2 → L3 → 视觉信号 → 无命中。返回 `(signal, md_level)`，其中 `md_level` 固定为 2（作为二级标题渲染）。

### 3.1 L1 章节级（最高层级，黑体）

```python
if re.match(r'^第[一二三四五六七八九十百千零\d]+[章节部分编篇]', t) and len(t) < 20:
    return 'L1', 2
```

**匹配示例**：
- 第一章、第3节、第二部分、第百章

**限制 `len<20`**：避免"第三章之后的论述..."这类正文句子误判。

---

### 3.2 L2 层级编号（黑体）

#### 3.2.1 层级编号（X.X）

```python
if re.match(r'^[\d]+(\.[\d]+)+', t):
    return 'L2', 2
```

**匹配示例**：1.1、2.3.1、1.2.3.4

---

#### 3.2.2 数字+分隔符

```python
if re.match(r'^[\d]+[.．、]', t):
    return 'L2', 2
```

**匹配示例**：1.、2．、3、

---

#### 3.2.3 专题标记

```python
if re.match(r'^专题[一二三四五六七八九十\d]+', t):
    return 'L2', 2
```

**匹配示例**：专题一、专题2、专题三

---

### 3.3 L3 中文数字标题（楷体）

#### 3.3.1 中文数字+分隔符

```python
if re.match("^[一二三四五六七八九十]+[.．、"“”‘’]", t):
    return 'L3', 2
```

**字符类说明**：
- `.` (ASCII 句号, U+002E)
- `．` (全角句号, U+FF0E)
- `、` (顿号, U+3001)
- `"` (ASCII 引号, U+0022)
- `"` (中文左弯引号, U+201C) ← **刚修复的 bug**
- `"` (中文右弯引号, U+201D)
- `'` (中文左单引号, U+2018)
- `'` (中文右单引号, U+2019)

**匹配示例**：
- 一"、二、
- 三"某某"、四"某某"（中文弯引号）

---

#### 3.3.2 中文数字括号

```python
if re.match(r'^[(（][一二三四五六七八九十\d]+[)）]', t):
    return 'L3', 2
```

**匹配示例**：（一）、（二）、(1)、(2)

---

#### 3.3.3 中文数字无分隔符（需高度确认）

```python
if len(t) >= 5 and re.match(r'^[一二三四五六七八九十百]+', t):
    _r3 = h / body_h_avg if body_h_avg > 0 else 1.0
    if _r3 > 1.15:
        return 'L3', 2
```

**匹配示例**：
- 二驳斥杜林对马克思学说的歪曲
- 一澄清杜林思想对19世纪后半期德国工人党

**双重确认**：
- 文本模式：以中文数字开头
- 视觉信号：高度比 > 1.15（避免"一般而言"、"一切..."等正文误判）

---

### 3.4 视觉信号（兜底，楷体）

#### 3.4.1 coord_heading（高大行）

```python
if (body_h_avg > 0 and h / body_h_avg > COORD_HEADING_RATIO
        and line_w_px > MIN_HEADING_WIDTH and len(t) <= 15
        and not is_body_fragment(t)):
    return 'coord_heading', 2
```

**判定条件**（全部满足）：
| 条件 | 值 | 作用 |
|------|-----|------|
| `h / body_h_avg > COORD_HEADING_RATIO` | floor 1.25 | 比正文高 >25%（floor 防止 OCR 噪声误判） |
| `line_w_px > MIN_HEADING_WIDTH` | 动态计算，约 400-500px | 排除窄行（如页眉） |
| `len(t) <= 15` | ≤15字符 | 标题不会太长 |
| `not is_body_fragment(t)` | 不以句号/问号/叹号/脚注标记结尾 | 排除句子结尾 |

---

#### 3.4.2 centered（居中短行）

```python
x_center = x_left + line_w_px / 2
page_center = page_width_px / 2
_r = h / body_h_avg if body_h_avg > 0 else 1.0

if (abs(x_center - page_center) < page_width_px * 0.1
        and 4 < len(t) <= 15 and _r > 1.1):
    return 'centered', 2
```

**双重确认**（避免窄正文误判）：
| 条件 | 值 | 作用 |
|------|-----|------|
| `abs(x_center - page_center) < page_width_px * 0.1` | 居中偏差 < 页宽10% | 真正居中 |
| `_r > 1.1` | 高度比 > 1.1 | 同时高大（窄正文可能居中但不高大） |
| `4 < len(t) <= 15` | 4-15字符 | 居中标题不会太长/太短 |

---

### 3.5 无命中

```python
return None, 0  → 作正文处理，字体为 songti
```

## 四、字体分配规则

```python
def get_heading_font(signal):
    if signal in ('L1', 'L2'):
        return '\\CJKfamily{heiti}'   # 黑体
    return '\\CJKfamily{kaiti}'        # 楷体（L3/coord_heading/centered）
```

| 信号 | 字体 | LaTeX 命令 |
|------|------|-----------|
| L1/L2 | heiti 黑体 | `\CJKfamily{heiti}` |
| L3/coord_heading/centered | kaiti 楷体 | `\CJKfamily{kaiti}` |
| 正文（无信号） | songti 宋体 | 默认字体 |

**设计逻辑**：
- 有阿拉伯编号/专题标记的 → 黑体（强调层级）
- 中文数字/纯视觉信号的 → 楷体（区别于正文宋体）

## 五、body_h_avg 计算（高度比基准）

```python
body_hs = []
for j in range(max(0,i-5), min(len(lines), i+6)):
    if j == i: continue
    tj = lines[j].strip()
    if not tj or len(tj) < 5: continue
    if j >= len(polys) or not polys[j]: continue
    if min(p[0] for p in polys[j]) > page_width_px * 0.4: continue
    body_hs.append(max(p[1] for p in polys[j]) - min(p[1] for p in polys[j]))
body_h_avg = sum(body_hs) / len(body_hs) if body_hs else h
```

**计算逻辑**：
- 邻近 ±5 行（±5 行内）
- 排除：自身、空行、短行（<5字）、右侧行（`x_left > 页宽40%`，可能是页眉/页码）
- 取平均高度作为正文基准，用于 `coord_heading` 和 `centered` 的高度比判断

---

## 六、关键阈值说明

| 阈值 | 值 | 来源 | 作用 |
|------|-----|------|------|
| `COORD_HEADING_RATIO` | 动态 + floor 1.25 | OCR 坐标计算，floor 防噪声 | 高大行判定 |
| `HDR_REGION_Y` | 动态（页眉底部 + gap×1.5） | OCR 坐标计算 | 页眉区下限 |
| `MIN_HEADING_WIDTH` | 动态，约 400-500px | OCR 坐标计算 | 排除窄行 |
| 居中偏差 | 页宽 10% | 固定 | 居中判定容忍度 |
| 标题长度上限 | 45（前置过滤）/ 15（视觉信号） | 固定 | 防止长句误判 |
| 高度比 floor | 1.25（coord）/ 1.15（L3 无分隔）/ 1.1（centered） | 固定 | 不同信号的门槛 |

## 七、为什么不用字体分类器

**之前的方案**：用 ResNet-18 分类扫描行裁切 → font → heiti/bold → 提升为标题

**问题**：
- 分类器在合成数据上 val_acc=99.22%，但真实扫描件上有域偏差
- 例子：`一"恩格斯问题"`（真实楷体）→ 分类为 songti conf=0.991
- 例子：`中得到进一步说明`（真实宋体正文）→ 分类为 heiti conf=0.99
- 后果：正文被误判为 heiti → 错误提升为标题

**根本原因**：合成训练数据与真实扫描件的纹理/噪声/对比度差异大，CNN 无法泛化。

**当前方案**：完全用结构信号（文本模式 + 视觉高度 + 居中位置），不依赖字体分类器，避免了域偏差。

## 八、刚修复的 bug（中文弯引号）

**问题**：`一"恩格斯问题"与科学社会主义` 未被识别为标题

**原因**：
- OCR 文本中的引号是中文左弯引号 `"` (U+201C)
- L3 正则的字符类 `[.．、""""]` 只包含 ASCII 直引号 `"` (U+0022)
- 编码不同 → 正则不匹配 → 降级为正文

**修复**（commit c496dd2）：
```python
# 修复前
if re.match(r'^[一二三四五六七八九十]+[.．、""""]', t):

# 修复后（加入 Unicode 引号变体）
if re.match("^[一二三四五六七八九十]+[.．、"“”‘’]", t):
```

字符类现在包含：
- `"` (ASCII, U+0022)
- `"` (中文左弯引号, U+201C)
- `"` (中文右弯引号, U+201D)
- `'` (中文左单引号, U+2018)
- `'` (中文右单引号, U+2019)

## 九、总结

**核心原则**：
1. **文本模式优先，视觉信号兜底** —— 有编号靠正则，无编号靠高度/居中
2. **多重门槛防误判** —— coord_heading（高+宽+短+非句尾）、centered（居中+高大）、中文数字无分隔（模式+高）
3. **字体分配与检测分离** —— 检测只返回信号名，字体靠信号查表
4. **完全弃用字体分类器** —— 避免域偏差导致的误判

**覆盖范围**：
- ✅ 章节/部分编号（L1）
- ✅ 层级编号、专题标记（L2）
- ✅ 中文数字标题（带分隔符/括号/无分隔符）（L3）
- ✅ 无编号高大行、居中短行（coord_heading/centered）
- ❌ 无编号且与正文视觉无异的标题（需用户提供 Markdown 标注）
