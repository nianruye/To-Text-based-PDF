# wz8_1 目录页码范围修正

## 现象

产物 p10 目录：

- 第一章目录行 `……1-` 留在正文，右侧单独 `12`
- 第二章 `……13-` 留在正文，右侧单独 `103`
- 后续同级条目被 `_TOC_PN` 回填，导致 `一殷代…`、`相对立…` 两行也显示页码 `1`

## 根因

- `TOC_ENTRY_RE` / 渲染形态①只接受 `……\d+` 单个页码，**不认 `1-12`/`13-103` 范围**
  → 范围行未被当目录条目，`1-` 留正文、`12` 被当尾数字
- 目录页已有页码行时仍走 `_TOC_PN` 回填
  → 多行条目的非末行被补上同一页码

## 修法

- `TOC_ENTRY_RE` 与形态① 页码组支持 `\d+[—–~-]\d+`
- 目录页存在显式点线页码行时，不再用 `_TOC_PN` 回填（`_toc_has_page`）
- 页码范围渲染为源书样式 `1—12` / `13—103`
- 目录条目 dotfill 正常展开；页码仍右对齐

## t323：两位数序号不可拆

```python
if re.match(r'^[一二三…]+[^\s、.．]', _tdisp):
```
