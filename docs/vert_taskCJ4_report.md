## 2. 机制假设判定

**用户的假设成立**（p1023/p1503/p1609 页码）：`_nf_rescue_rows` 的「已用列带」只看 x 带，
x 重叠即跳过，完全没看 y 段；而页码/书眉与正文列同 x 带、不同 y 段正是竖排常见版式。

**但 8 页不是同一机制**，另有两条独立机制（同一函数内）：

| 页 | 丢字 | 卡在哪一步 |

| p1023 / p1067 / p1145 / p1413 / p1577 | 3 字页码 | ① x 带已用（y 不重叠）→ 拒 |
| p1609「四三九」 | 3 字页码 | 同上（v6 也缺，既有遗留） |
| p1503「三」 | 1 字页码 | ① x 带已用 + ② 单字 `nr>=2` |
| p1609「第九十六回」 | 5 字 | ③ 宽窗统计把整列 21 run 当成本行 → 字号 1.40x 被 `_ok_stat` 拒 |
| p702「唱：」 | 2 字 | ④ 整页高覆盖率 2.16% < 4% → 列带检不出 |
