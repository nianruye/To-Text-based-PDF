三管线分叉关系

  • • v13 = 早期重排架构（reflow 拉伸），无位置还原/区域化
  • • geom = 逐行几何固定 makebox，支持 POSITIONAL/区域化
  • • classic = geom 的 fork，加古籍特色（墨高重叠/夹注/旁注）
  • • geom ↔ classic 前 800 行重合，行号平移 -2
  • • _esc_chars 三方分叉：v13 保留\{}，geom 单\%，classic 双\\%（bug）

测试与可疑行为

  • • test_cases 21 断言全压 build_classic，v13/geom 零保护
  • • verify_geom 无 PASS/FAIL 退出码，CI 拦不住回归
  • • unit/ 纯函数 121 passed（ast 提取绕开副作用）
  • • invariants/ 不变量 13 passed（截取子集跑管线）
  • • classic L202 _esc_chars 双反斜杠疑似 bug（古籍罕含%未暴露）
  • • line_font 引用未定义 FONT_HD（死代码）

数据流与外部依赖

  • • 输入：spotting_lines/coords + LAYJSON + PAGENUM/TOC
  • • 校准：est.json -> ratio.json（两趟比值查表，非最小二乘）
  • • 产物：/tmp/*.tex -> xelatex -> /tmp/seg2_line.pdf -> OUT
  • • 引擎：xelatex + PaddleOCR-VL-1.6 HTTP API
  • • 库：PyMuPDF(fitz) · PIL · opencc · 无 pdftoppm/tesseract
  • • 坑：fit_positional 调 python3 命中 mineru venv（无 fitz）
