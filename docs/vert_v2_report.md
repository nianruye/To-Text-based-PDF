## 一、实现方式

### 1. 版框线（§1.95，`frame_geom` / `frame_tex`，新增）
源书版框实测结论（全书抽样 + 逐页盘点）：
- **双边**：外粗线 2.5-4.5pt + 空隙 2.5-3.5pt + 内细线 0.5-1.5pt；内框高 799.0pt（min 796.5 / max 801.0，印版常数）。
- 内框左右两条竖线**同时是首/末界行线**；界行线 = 列间 1pt 细竖线，起止同内框上下线，列距 43.5pt（内框宽 521.8pt = 12 列）。
- **订口侧（装订边）只剩内细线**：外粗线被装订边/扫描裁切吞掉（实测每页 L 或 R 必有一侧缺，缺失侧逐页交替）。
- 横线（内/外）横跨整幅纸面到订口页边（书眉/页码带被上下横线包住），所以横线按**源墨迹实测 x 跨度**画。
- 书眉/页码在**框外**订口页边内（版心），与框内正文列无关。

检测判据（都带实测依据，写在代码注释里）：
- 横线：行墨占比 > 0.45（源书横线 0.58-0.99，正文行 ≤ 0.30）且墨迹横跨 > 0.55 纸宽；上下各取「外粗+内细」一对。
- 竖线：版心 y 区间内列墨占比 > 0.55（源书细线 0.70-0.99，正文列 < 0.55，marge 留够）。
- 剔除：扫描黑边（两端累计墨占比 > 0.8 的列区）、贴页缘 5pt 内的假线（p172/p210 实测有 cov 0.55-0.75 的裁切暗边）、厚度 > 6.5pt 的粗条。
- 结构闭合：有外粗线的一侧 → 内线 = 粗线内侧缘 ± 间隙；另一侧补横线端头；都缺则用实测最外细线，并用「列数×列距」（列数 = 抽样页中位）校验修正。
- 渲染：eso-pic **带星版** `\AddToShipoutPictureFG*` + `\put` + `\rule`（探针实测：tate 下 `\rule` 尺寸不旋转、`\put` 参考点 = rule 左下角、原点 = 页真左下角，源书 pt 1:1）。

### 2. 全书 231 页跑通（修了 4 个只在全书才暴露的缺陷）
| 现象 | 根因 | 修法 |
|---|---|---|
| 231 页跑成 **286 页** | tate 下累积列数超过 `\textheight` 会分页；中位 12 列而 13 列页有 44 个 | 容量改「最密页」（90 分位），并给每页列距封顶 = 该页内框宽 / 列数 |
| 同上，另有 1 页 | 註釋页列距只有正文一半（实测 p156 列距 21.5pt），按 47.6pt 排 20 列 = 952pt 远超页宽 | 每页列距 = 本页正文列 x0 差中位（差 >15% 时启用），数据驱动不硬编码页号 |
| 同上，再 1 页 | p74 的 OCR 把图表图例读成 194 字一行（含换行符） | `is_body_col` 增加「竖排列必单行」判据：含 `\n` 的 OCR 框一律排除（全书 7 条，全是残片/版心「第二卷·抗日戰爭時期」） |
| 231 页跑成 232 页 | 末页后仍发 `\newpage`，多一张空白页 | 末页不发 `\newpage` |
| 崩溃 `zero-size array` | OCR 行 bbox 越出页面时 `ink_extent` 裁剪窗口为空（p159 触发） | 空窗口直接返回 None |
| 每页第一列画到版框外 | `RIGHT = max(所有正文列 x1)` 被 OCR 边缘列 bbox 右扩污染（逐页 max 中位 1164px、max 1189px = 扫描黑边右缘 → 594.9pt，比版心真右缘（抽样页内框右线中位 563.1pt）偏右 ~32pt） | **版心右缘改源图墨迹实测**：抽样页「版框内最右细竖线」中位 = 563.1pt（`VERT_RIGHT_INK=0` 可回退对比） |

### 3. 页码序列校验/纠正（§1.87，`pn_parse` / `pn_sequence_fix`，新增）
- 页码文本解析（逐字数码 一八〇 / 计数式 三百〇五）→ 按页序分段（相邻有效页码页号差 > 6 断段）→ 段内等差数列拟合 `value = a*page + c`（a = 相邻斜率中位，短段借全局）→ 偏差 ≥ 2 判误读 → 用左右最近非误读邻页**线性插值**纠正（单侧则按斜率外推）。
- 所有解析成功的页统一规范成源书逐字数码（OCR 的 `0` → `〇`）。
- 阈值 PN_TOL=2 是有意的：源书若合法跳号（未编号插页），收紧到 1 会把整段误判成误读。
- 不硬编码任何页号；纠正记录逐条打印。

## 1. p159 整页丢失 —— 根因：OCR 返回了「旋转坐标系」

**根因（实测，非猜测）**：该页源书是竖排（版框内 4 列小字 35/11/35/24 字，版框整体右移、左缘为订口条），
但 OCR 服务把整页当**横排**识别，返回的坐标落在「页逆时针转 90°」的坐标系里：
- 该页 6 条行框全是「横看」（宽 1833px × 高 47px；竖排正文列必是纵长，高/宽 ≈ 20）；
- 页宽方向的值最大 2411px，远超页宽 1191px（= 2×595.3pt）。

**为什么整页空白**：6 行全部过不了 `is_body_col`（`h<300`）被丢弃；`第二卷\n抗日戰爭時期` 行另有含 `\n` 排除；
`三五` 行虽被页码逻辑认领（并已纠正成三三五），但 `ink_extent` 的窗口按原始 bbox 画，落在源图空白处 -> 无墨迹可测 -> 不渲染。

**印证方向**：按逆时针 90° 还原后，行框正落在源图墨迹字列上（残差 1.7px；顺时针方案 400px，方向判别由此确定），
且行文连读通顺：`…乘機反攻拿 | 破崙軍僅剩…逃去 | …繩捆索綁形同 | 囚犯略為…代替`。

**修法（§1.97 `derot_rows`，数据驱动、不硬编码页号）**：
1. **判据**：页内「横看」行（宽>300px 且 >2.5×高）≥3 条，且该页所有长行（宽>300px）都横看（混合页不触发）；
2. **标定**：源图墨迹字级组件按 x 中心聚类得竖向「字列」（同 `note_cols` 手法，能自动排除末页水印页这类非竖排页）；
   行（y′ 中心升序）与字列按序配对后最小二乘 —— 逆时针 `x = kx·y′ + bx`（字列按 x 降序配）、顺时针（按 x 升序配），取残差小者；
3. **文本方向**另用「中位比例 + 中位截距」标定 `y = ky·x′ + by`（OCR 盒沿文本方向松紧不一 10-30%，最小二乘会被带偏）；
4. 只在该页渲染时套用（全局拟合/版框检测/页码序列仍用原始行），不影响其它 230 页。

实测标定：`kx=-0.934 bx=1151.6 rms=3.41px / ky=0.780 by=273.5`。

**验证**：渲染图 + 文本提取双重复核 —— 输出 p159 现含 4 列正文（阅读序正确）+ 边注「第二卷 抗日戰爭時期」+ 页码「三三五」
（OCR 误读的三五经页码序列纠正）；列 x 483.8-563.3（源书 486-560）、字号 19.5-19.9pt（源书 ≈20.5pt）、页码/边注按源墨迹定位 x 23.9-40.2（源 24.5-34.5）。

## 3. 淡界行线兜底（p22/p32/p36 也画出 12 格版框）

**难点（实测）**：单阈值 + 「相邻差中位定列距」不成立 —— 阈值 0.30 时 p32 的 12 条候选里 5 条是正文列竖笔画碎片，
碎片多到把列距中位带偏（结果列距 36pt 而非 43.5pt）。

**做法（§1.95b `_grid_fit`）**：阈值降到 `VERT_LINE_COV_LO`(默认 0.25) 重扫得候选细线，然后**按版框是等距栅格**拟合：
1. 二维搜索 (列距 p ∈ 40-48pt，某条候选所在栅格) 下所有跨 13 条线的窗口；
2. 打分 = **(命中候选数, 窗口各线处墨覆盖率之和)** —— 命中数优先，覆盖率解平手
   （实测 p22 最左一条线淡到漏检时，栅格可整体右移一格而命中数不变；右移后最右那条落在版框外空白上(覆盖率≈0)，靠覆盖率判回正确位置）；
3. 对命中集合最小二乘精修 p/首线，生成 13 条线（漏检的按栅格位置补）；
4. 栅格命中时内框左右线直接取链首末线（比旧的「横线端头」估值可靠 —— 源书横线横跨整幅纸面含订口页边，p36 实测旧法会把右线高估 26pt）。

**验证**：p22 内框 x26.3-547.9（探针实测真值 27.5-548）、p32 x27.5-538.8（真值 21-543）、p36 x21.8-536.5（真值 21-543），
界行线各 11 条；全书版框页数 **225 -> 228**（仍无版框的 3 页 = p1 封面 / p2 前附 / p231 水印页，本就无版框）。
兜底只在主判据失败时触发，本次全书只命中 p22/p32/p36 三页，无其它页被误触发。
