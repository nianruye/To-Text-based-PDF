## 根因诊断

- p11 含 `CONTENTS`，旧 `_toc_pre_flow` 可解析；p12 无 `CONTENTS`，旧代码 `len(_cand)>=3 and not CONTENTS` 直接 `return None`。
- p12 未解析后，紧接的「游离纯数字行→上一条目页码片段」把独立页码 `49` 合并进**上一条/下一条**条目 `frags`；再走旧 dotfill 分支，产生：
  `491. 引起社会动乱 … . . . 49`
  即页码既是前缀（49+1.）又被当尾页码（点线后 49）。
- 修法：
  1. `_toc_pre_flow` 允许无 CONTENTS 的数字起始续页（p12）；
  2. 若 flow 已有 `toc_pre`，跳过「游离数字并片」；
  3. `toc_pre` 渲染改为三栏：页码右对齐 `18pt` + `\rule` 竖线 + 标题列；禁 dotfill。

## t296 定稿：标准目录格式 + 正确压字判据（GO）

### 正确压字判据

原「span bbox 纵向重叠=0」无效：CJK bbox 含 ascent/descent，18.7pt 字号 bbox≈47pt，而正常行距28pt，相邻行必然 bbox 重叠。真实压字判据：

```
两 span 中心 y 差 < 0.75×min(字号)  且  横向重叠 > 30%×较短者宽度
```

v23 实测：p11 **29 spans / 0 对**；p12 **41 spans / 0 对**。

### 最终标准格式（v23）

- 页首 `目录 CONTENTS`：目录22.7pt、CONTENTS 12.9pt + 字距；同一行。

- 固定行距：L1 1.5×字号、L2/L3 1.6×字号；无点线、页码不并入标题。
- 章组竖线：仍按条目分段，但每段 rule 高 4.2em（≈54pt）且用 `\smash\rlap` 零占高；相邻段实测 **y 区间重叠**（无可见间隙），见 p11/p12 裁片。
