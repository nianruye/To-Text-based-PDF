## 门禁判定口径

| verdict | 含义 | 处置 |
|---|---|---|
| `PASS` | 全部硬指标达标 | 可交付 |
| `PASS_WITH_DRIFT` | 页数差 ≤ 允许值（`--allow-page-drift`） | 可交付，差异需知悉 |
| `MANUAL_ONLY` | 有数据缺失或内容超人工阈值 | 需人工确认 |
| `REJECT` | 有硬指标未达标 | 不可交付，需修 |

**硬指标**（`verify_geom`）：页数 1:1、pitch ≥85%、页高误差 <5%、底部占位 <8%、overflow 0。

## 系统边界（重要）

**这个系统的真实定位**：

> 「**7 本调优书 + 一套能跑通新书的通用路径**」
>
> 新书能拿到 1:1 页数、可读产物、门禁报告；但**达不到调优书的 98%+ pitch**，
> 且每本新书可能暴露 1–2 类新的排版问题（wz8 暴露 3 类、wz9 暴露 12 项）。

**不是**「上传任意 PDF 就完美还原」。

要达成后者，需要按 [架构评估](architecture_assessment.md) 走三步改造，
其中第 2 步（判定带置信度 + 低置信降级）是关键 —— 但本次实测表明
**可靠的检测信号并不容易找到**（三项墨迹信号全部不成立）。

## 复现命令

```bash
# 横排（调优书）
/usr/bin/python3 src/tools/scan2pdf.py --input source_pdf/ghbq.pdf --book ghbq \
  --out /tmp/ghbq.pdf --data-dir output/ghbq_full/_ocr_ghbq --skip-ocr --layout --force

# 横排（新书，OCR 数据已在）
/usr/bin/python3 src/tools/scan2pdf.py --input uploads/wz9.pdf --book wz9 \
  --out /tmp/wz9.pdf --data-dir output/uploaded/_ocr_wz9 --skip-ocr \
  --pipeline geom --layout --allow-page-drift 2 --force

# 竖排
/usr/bin/python3 src/tools/scan2pdf.py --input source_pdf/wz6.pdf --book wz6 \
  --out /tmp/wz6.pdf --data-dir data/wz6 --skip-ocr --pipeline vert --force
```

**构建必须串行** —— 并行会因 `/tmp` 同名临时文件互相覆盖（实测 wz4 产出 0 页、wz3 12 页）。
