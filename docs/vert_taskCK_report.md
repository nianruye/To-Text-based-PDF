## 2. 根因

1. **「边缘小字」判据只看 x 边带，不看同列上下文**（甲类主因）。竖排书每章末页左缘是
   「第N回 + 回目上句 + 回目下句」的同一条物理列；`special_rows` 只按「短行 + x 在左右页边带」
   把「第N回」认成书眉。其余回目行经 `_merge_col_rows` 合成正文行后，槽跨度是该 x 带全部墨迹
   （含已认领行的墨），col_puts 按槽跨度摊字 -> 与 special 渲染在 y 上交错。p1555 的诗行首段
   （「佳人有意，」在右带内）同理。
2. **槽 top/bot 不随配对行的 y 段收口**（甲类 p997/p705）。同一 x 带里另一条 OCR 行（页码）的墨
   被算进槽跨度，正文行被摊到页码位置；`_ab=False` 的页（OCR 帧未标定）没有 y 拆槽可依赖。
3. **补救路径的 run 高下限 4pt 对细笔画数码失效**（乙类 p70/p623/p922/p1692）：页码字的笔画是
   2-4pt 横画，上半字被滤掉 -> top/bot 只剩 18pt -> F 估计与槽跨度矛盾 -> 字号保护压成 4pt。
   同时 `_ok_stat` 用同一过滤后的 nr 判断「像不像正文列」，把真页码带拒掉（p1692 选错带）。
4. **步进分类用 `len(t)` 逐字符计数**（乙类 p35 + 甲类 p1555）：竖排里西文词是侧排的一片、约
   占一格，但 OCR 文本逐字母计数 -> 列步进被低估 -> 正文列被步进分裂判成小字注；note_tex 再
   按墨迹子列配对，配到碎墨列就压成 9pt/1.5pt 步进。
5. **m['note'] 为空时仍允许步进分裂**（p1598）：槽统计已给出「本页没有小字号列」的证据，
   但行步进的离群（OCR 行盒对短列偏紧）仍把正文行送进 note 路径。

## 3. 修法

全部改动在 `src/pipelines/build_vert.py`，均以「无版框(NF)路径 / 伪槽格页」为作用域，
有版框书（wz6）走原口径（wz6 `vert.tex` md5 逐字节相同，见 §4.6）。

### 3.1 `special_rows`：同列成链的书眉候选不认领（甲类 p667/p705/p1029/p1555）

候选行若与同页另一行 **x 带重叠 >= 60% 小者宽**、**y 相邻间距 <= 2.5 x 邻行步进**、
且邻行是 >= 4 字的正文/回目行，则判为「正文列的一段」，不认领。该行随后由 `_merge_col_rows`
并入回目列，col_puts 按整列跨度/字号渲染（p667 F 36.7 -> 28.4；p1029 42.1 -> 31.1）。
只对 `_NF['on']` 生效。

### 3.2 行 ↔ 槽 y 跨度夹取（甲类 p997/p705）

配对后若本行 OCR y 带盖不住槽跨度（< 75%）**且**槽内确有一条与本行 y 段不重叠的其它 OCR 行
（x 带相交），把槽夹到本行 y 带 ± 半步进，并**同口径夹取 `runs`/`keep`**（否则 fit_gaps 仍按
页码那一段的 run 插格，实测 p997 会插 4 格把末字推到页码上）。p997 槽 233-1115 -> 233-833；
p705 槽 274.5-1178 -> 274.5-875.5；p623 标题槽 243-1145 -> 243-796.5。
只对伪槽格页（`m['g']['virtual']`）生效。

### 3.3 `_band_stats(min_h)` + 数码行 raw 统计（乙类 p70/p623/p922/p1692）

- `_band_stats` 增加 `min_h` 参数（默认 4.0 = 原口径）；
- `_nf_rescue_rows` 对**纯数码行**（全 `NUM_CHARS`）用 `min_h=1.0`：页码的细横画不再被滤掉，
  top/bot 取全笔画跨度（p70 1077-1116.5 / p623 1104-1145.5 / p922 1101.5-1164）；
  `_font_est` 的跨度兜底（span/n/0.9）给出 20.8-23.1pt，step 19.5-21.2pt；
- p1692 的真页码带（nr 由 1 -> 5）通过 `_ok_stat`，按「离 OCR x 心最近」选中 x628.3-642.8
  （距离 0.4pt）而不是 19.4pt 外的正文列带。

### 3.4 `_font_est` 跨度兜底按任务书收紧（乙类）

`F_run < 0.7 x 页字号` 时不再无条件用 span/n/0.9：只有 span/n 在页字号 0.6-1.5 倍内才用，
否则（含单字）退 0.9 x 页字号。避免退化跨度把字号估得更小。

### 3.5 `col_puts` absub 分支的跨度兜底（乙类，任务书要求的两处之一）

y 拆子槽里 `_big_hm` 不可靠（F_run < 0.5 x 页字号）且 span/n 在 0.6-1.5 倍页字号内 ->
`F = span/n/0.9`；单字 -> 页字号。与 3.3 的 `_font_est` 同判据、同口径。

### 3.6 步进分类的格数口径 `_step_chars`（乙类 p35 / 甲类 p1555）

连续拉丁字母串按 **1 格**计（其余字符各 1 格），用于 `page_rows` 的步进中位/分裂与
`note_rows` 的注行判据；只对 NF 生效。p35 的两条西文列步进 17.6/18.4pt -> 74-80pt，
分裂因 `_cap_ok` 不成立而回退为「全正文」。

### 3.7 m['note'] 为空时不做步进分裂（p1598）

槽统计没有小字号列证据时，行步进离群一律按正文渲染（p1598 19 行 -> 19 槽，10 字行按正文
字号/步进落位）。只对 NF 生效。
