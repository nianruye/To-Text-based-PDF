## 一、避头尾（列首标点）3100 处 —— 源书自身排印，**不该动**

### 规模

```
列首标点  3100 处 / 1229 页
  ，1348  。687  」502  ：262  ？104  ！98  、57  ；34  』6  ·2
```

### 判据一：边界处源图墨隙（确认不是我们把一列切成两段）

抽 20 处，量「同列上一段底部」到「本行顶部」之间源图的最长空白段：

```
源图墨隙 / 本列步进 = 1.13 - 2.65      20/20 全部 >= 1.0
-> 边界处都有真实空白，不是一列被切成两段
```

### 判据二：首格墨量（确认源书首格真的是标点）

**从全部 3100 处随机抽 30**（不是从「能配上同列上一段」的子集抽 —— 那样有偏差），
量该列首格墨量占比 vs 同列后续格墨量中位：

```
汉字格墨量占格  0.20 - 0.37
标点格墨量占格  0.03 - 0.10     差 3-10 倍，区分干净

样本（节选）：
  p98   。  首格 0.071  后续 0.275  比值 0.26
  p685  ，  首格 0.031  后续 0.233  比值 0.13
  p1094 ：  首格 0.032  后续 0.350  比值 0.09
  p1477 」  首格 0.337  后续 0.307  比值 1.10   <- 可疑（墨量像汉字）
  p1701 。  首格 0.172  后续 0.185  比值 0.93   <- 可疑

  比值 < 0.75（首格确是标点）：28 / 30 = 93%
```

### 结论

**93% 是源书自身的排印** —— 这本旧版书不讲现代避头尾规则。我们产物把标点排在列首，**与源书一致，是对的**。

此前把它记作「待修缺陷」是**判断错误**，现撤回。

**遗留小类**：约 2/30（外推 ~200 处）首格墨量反常（像汉字），可能是 OCR 行切分把标点挪了位置。**另立一类登记，只查不改。**

## 二、冒号后引号 —— 精确收窄到 **134 处高置信度**

### 重算规模（邻列搜索口径比之前的「379」更严）

```
冒号结尾的列  1208 处
  左邻列首已有 ﹁  ：666 处（对照组，源图确定有 ﹁）
  左邻列首缺  ﹁  ：542 处
     其中首字符 = 一   ：134 处   <- 高置信度候选
          其余        ：408 处
```

```
缺 ﹁ 组首字符分布：一 134 / 第 68 / 」22 / 道 8 / 金 6 / 當 6 / 不 6 / 又 6
对照组首字符分布：「 662 / 『 4
```

`第`/`道`/`金` 那些是真字（列举序号、对话开头），**不是缺引号**。真正可疑的是 **`一` 这 134 处** ——
正好对应已知 OCR 失效模式（AGENTS.md issue #33：竖排 `﹁` 被读成汉字 `一`）。

### 判据：三组首格源图墨迹签名对照

各抽 45 处，量左邻列首格（列框顶部 1 步进）：

```
组别              墨量中位   bias 中位   墨块宽高比中位
对照组（真﹁）      0.097     +0.18       1.11
实验组（首=一）     0.116     +0.15       0.87     <- 与对照组几乎一致
其它首字符          0.238     -0.19       0.81     <- 墨量 2.5 倍，bias 反号
```

```
墨量  对照组 0.097 vs 实验组 0.116   差 20%
      （而「其它首字符」0.238 = 对照组的 2.5 倍）
bias  对照组 +0.18 vs 实验组 +0.15   同号同量级
      （「其它」-0.19，反号）
```

### 结论

**这 134 处首格的墨迹签名与「确定是 ﹁」的对照组一致，与「确定是真字」的其它组明显不同**
-> 高置信度判定为 **`﹁` 被 OCR 读成 `一`**。

旁证：国标的「单引号一般在冒号后边」在本数据上 94.1% 成立（QQSF 阶段已验证），
而这 134 处的上下文正是「冒号列的左邻列首」 —— 位置先验完全吻合。
