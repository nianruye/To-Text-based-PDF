# 竖排"版框内规整化"改造任务简报（给 Claude Code）

> 项目：/opt/test。背景：wz6 竖排还原（`build_vert.py`）全书 231 页已交付，但**用户实测可读性差**，经量化诊断确认三个问题（数据见下）。**根因：当前排版基准 = OCR 盒长拟合**（松紧不一 + 扫描逐页错位）→ 列长参差、列区不贴框、边注挤进版心。**正解 = 每页源书版框实测作为排版基准**（版框驱动）。

## 诊断数据（实测，作为修复目标）

**p100（正文页）**：
- 重建：12 列，列底 y 极差 **80pt**（1063-1143）；列区 x 60-528；字号 sz 31.9-33.6
- 源书：列底 y 1174-1203（极差 **29pt**）；版框内框 x **24-546pt**、列距实测 **43.5pt**（当前用 OCR 的 47.6pt，差 9%）
- 差距：重建列底比源书高 ~50pt（没到底）、左侧空 36pt/右侧空 18pt（没贴框）

**p162（带边注页）**：
- 重建：边注（22pt 小字）排在 **x 132-348**（版心内部！）——源书该 x 区间是正文列（源书边注在版框外最左缘）
- 逐页错位（你上一轮报告过）：奇页内框顶 290/右 568、偶页 315.5/552；全局拟合单页最大偏差 ±18pt 水平 / ±26pt 垂直

## 任务：把文字严格放进每页版框（框驱动排版）

1. **逐页版框定位**：源图墨迹实测**每页**内框（顶/底/左/右）——处理奇偶页交替差异（复用你已有的 `lines.py`/`frame_extent.py` 方法 + 淡线栅格拟合兜底）。**每页独立**，不用全局拟合。
2. **列位 = 该页界行线栅格**：12 列 x 位置取内框内实测界行线（或内框宽等距），列距以实测为准（p100 为 43.5pt）。
3. **列高 = 内框高**（**本轮核心：列底对齐**）：所有正文列**顶部对齐内框顶、底部对齐内框底**；列内字距按该列字数自适应（字多的列字距小、字少的大）——这是竖排书"列底齐"的标准实现方式（源书即如此：各列字数不同但列高一致）。
4. **字号 = 内框高 ÷ 满列字数**（数据驱动，替换 OCR 盒长拟合值）；大字号标题列沿用既有封顶逻辑（≤列距×0.92）。
5. **边注/书眉/页码归位**：按**源图墨迹实测**定位——边注在版框外/版心内的真实位置（不得挤占正文列位）；书眉、页码同理。**边注与正文列 x 区间不得交叠**。
6. **保留既有成果**（不要重做）：eso-pic 带星版、书眉/页码/边注的文本来源与页符判定、derot_rows 旋转页、版框线绘制、页码序列纠正、JY1 修法、退出码分级处理。**本任务只改"排版基准"（框驱动）+ 边注/书眉/页码的位置映射**。

## 验收标准（量化，逐条给实测输出）

1. **列底对齐**：每页正文列底 y 极差 **≤ 10pt**（当前 80pt）——抽查 ≥5 页（含奇偶页各 ≥2）
2. **版框内**：所有正文列 x ∈ [内框左, 内框右]、列底 ≤ 内框底（无溢出）；列区左右余量 ≤ 8pt
3. **无重叠**：边注/书眉/页码与正文列 x 区间不交叠；同页 span 交叉检查
4. **字号**：与源书墨迹实测一致（±1pt）
5. **回归**：`verify_vert.py` 实测 PASS（231:1 / 字符量 / 越界 0）；209 测试全绿
6. **视觉**：渲染 p100、p162、p50 与源书并排对比图（自查通过后交付路径写入报告）

## 执行方式

- **分步自测**：每完成一个子步骤（版框定位→列栅格→列高对齐→边注归位）先渲染 1-2 页自测，**不要憋到最后**。
- 全书重跑一次做最终验证（231 页编译）。
- 报告写 `docs/vert_frame_driven_report.md`：诊断确认 / 实现 / 逐条验收数据 / 遗留。

## 约束

- 不改横排管线与四书数据；不动 OCR 数据；不做无关重构（search/替换类改动只碰渲染基准相关代码）
- 不 git reset；完成后 `git add` 但不 commit（主控统一提交）
- 复杂 shell 写成脚本文件执行
- 若某条验收无法达成，**如实报告差距与原因**，不要粉饰
