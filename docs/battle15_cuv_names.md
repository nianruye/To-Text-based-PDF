## 1. F1 根因与修复

**根因**：v45 的 `_fix_cuv_brackets` 在 `fix_split_brackets` **之后**执行。p727 的 `尾聲`（裸名）+ 下一列 `」〔〕「嘱付…`：`fix_split_brackets` 先把行首 `」` 归位到名行 → 名行变 `尾聲」`，`_is_cuv_name` 不再命中 → 空对被当噪声删除，名没被包上（日志仍把该对计为 move，导致「9 move 实际 8 落地」）。

**修复**（v46）：
1. `_fix_bare_cuv_names` 先给裸曲牌名补 `〔〕`（独立于空对）；
2. `_fix_cuv_brackets` **提前到 `fix_split_brackets` 之前**；
3. 空对移动后，若本行以 `」`/`﹂` 开头且紧跟 `「`/`﹁`/`〔`/`︹` → 删该孤引（源图名后无闭引号）；
4. 日志统计按 kind 分类输出（barewrap/move/del/drop_quote），不再把「补括号+删对」误计为 move。

**全书 move 类复核**：v45 的 9 个 move 目标（小桃紅/川撥棹/山坡羊/金字經/駐雲飛/江兒水/傍粧臺/尾聲/琥珀貓兒）在 v46 全部落地（`︹名︺` 实测 10/10，含 p830 黄鶯兒、p831 集賢賓）；p727 由「move 未落地」变为 barewrap 落地。**v46 日志：`[曲牌列] 68 = 裸名补括号 29 / 移名侧 3 / 删空对 30 / 删孤引 6`；`[引號判别·曲牌] 8 = 曲牌后 3 / 名后 5`** —— 与 §2/§3 一致。
