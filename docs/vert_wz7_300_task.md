## 任务 A：收 3 个遗留（taskO 报告记录）

1. **短列不渲染**（源页 1205/1239 各有 1-2 个短列，78/40 字）：根因是墨迹覆盖率低于阈值、残余补带也补不出 → 该列整列不渲染。
   - **要求**：修到这些短列能渲染（合法路径：放宽短列的覆盖率门限 / 用 OCR 列框兜底构造伪带 / 短列专用判据），**同时不得把非正文杂讯（页边碎墨、扫描噪点）误当正文**——二者必须同时满足；报告给出"修前不渲染 vs 修后渲染"的证据。
2. **字号比源书略大 5-10%**：根因是源侧墨迹字高仍用**固定阈值 150** 口径，而 NF 路径已改逐页 Otsu → 口径不一致导致字号偏大。
   - **要求**：把源侧墨迹测量**统一到逐页 Otsu**（与 NF 标定同口径），复测字号/覆盖率；报告列"修前/修后/源书"三列数字。
3. **页码行识别率低**（taskO：100 页里只认出 4 个页码行，判为"OCR 数据覆盖问题"）：
   - **要求**：在 300 页数据上**复核**这个结论——逐页统计"源书确有页码/书眉"与"我们检出"的数量对比，**明确区分**：(a) OCR 没识别出该行（数据问题）(b) 识别出了但我们的判据漏了（代码问题）。若是 (b) 则修；若是 (a) 则如实记录并说明可选的补救（如 layout 模式补 OCR / 其他）。
