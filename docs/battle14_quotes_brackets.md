## 2. 修复规则（文本层，`VERT_CUV_FIX=1`）

1. **空对**（`_fix_cuv_brackets`）：逐页逐行扫描空对；若**前一行是裸曲牌名**（2–6 汉字、无标点/括号、非页码）且空对在**列首（pos≤2，允许前一字标点）** → 名两侧加 `〔〕`（源图曲牌固定方括号；OCR 常把 `〔` 读成 `（`），删当前行空对；否则**删除**空对。逐条登记 page/row/pos/kind/pair/prev/ctx。
2. **`〕一`→`〕﹁`**（`_fix_yi_after_bracket`）：仅 `〕` 后；源图角形判据 + 位置闸门；1:1 替换（字符量不变）；`）一` 不处理（p1697 反例）。
3. **列首 dangling `〕`/`）`**：仍由既有 `fix_split_brackets`（236 处）处理；新规则移动括号后若残留「」」/「）」（如 p704 `山坡羊〕」：`）**本轮不删**——登记 §5。
4. 逐条清单：build 日志 `[曲牌空括号]`（33 条）与 `[引號判别·曲牌后]`（3 条）已含 page/row/pos/prev/ctx；本报告 §1 表即全量。
5. 开关：`VERT_CUV_FIX` 默认 `0`（wz6 等逐字节不变）；wz7 battle14 构建脚本显式 `=1`。
