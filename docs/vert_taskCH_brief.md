## ③ 根因证据链（p53 实测日志）

```
[无框伪槽格] p53 14 列(列距39.50) 字号28.9 版心 x155.0-785.0
[TOC判据] p53 行16 槽11 x组12 组均1.33 容差39.5 -> 否          ← 判据要求 >=1.4
[补列] p53 行16 > 槽11 -> 空档内补 3 条: 562-613 613-639 639-700
[兜底互斥] p53 詞話章回目錄…… 目标带 x639-700 已被正文列占用 -> 不落位
[正文列] p53 16 行 -> 14 槽
产物: x611.5 「導第讀二⋯⋯回⋯西門慶簾下遇金蓮…」   ← 導讀 与 第二回 被串进同一列
```

**核心矛盾**：

1. 第 ⑤ 步 `nf_join_rows`（L2023）**先把**「回次/回目上句/回目下句」三行合并成一行
2. 第 ⑦ 步 `_toc` 判据（L3594-3608）却要求 `R >= 1.3 * C` —— **合并后 R ≈ C，判据永不成立**
3. 于是目录专用路径（y 拆子槽 + 位置配对）**走不到**
4. 只能靠第 ⑧ 步「全列做槽」（L3641，taskCG5 补丁）和第 ⑨ 步「补列」（L3664，taskCG4 补丁）硬凑
5. 两个补丁的判据互相不知道对方 → **修好 p54 就弄坏 p563**

**结论：目录的特殊性散在 5 个步骤里各打一个补丁，必须收拢成一个分支。**

## ④ 修法方向

**把目录判定提到 `nf_join_rows` 之前，命中后走独立路径。**

具体：

1. **新增判定**（放在 L2023 `nf_join_rows` 调用之前）：
   判据**不依赖行数比**，改用：
   - 同 x 带内 ≥2 行的**占比**（目录页每列 2-3 行，正文页每列 1 行）
   - 且这些多行的**字号显著小于**本页正文（回次/页码是小字）
   - 且行高与列距的比值落在「小字行」区间

2. **命中后走独立路径**：按 **(x 带, y 层) 二维配对**
   - 行按 x 归列（容差 = 列距的 30%）
   - 列内按 y 归层（每层一个槽：回次层 / 回目层 / 页码层）
   - **不再走 `_split_slot_y`**（L2867），因为层是直接由行算出来的，不需要从墨迹反推

3. **删除两个补丁**：
   - L3641 `[全列做槽]`（taskCG5）
   - L3664 `[补列]`（taskCG4）
   删掉后 p54 / p563 必须仍正确 —— **这是本次重构的核心验收**

4. **普通正文路径（未命中目录判定的页）必须一字不动**
