# taskI：竖排书可读性修复（用户实测反馈 5 项）

> 项目：/opt/test。用户逐页实测了 `output/wz6/wz6_vert_full.pdf`，反馈 5 个可读性问题，均已量化诊断（见下）。**本轮修复以"逼近源书排版"为准**，逐项给实测输出。

## 诊断数据（已确认，作为修复目标）

**① 字间距太小/字与字重合（如 p10）**：
- 我们数据 p10 列字数 **23-28**，源书列只有 **25-26 格** → 28 字列的步进被压到 **28.5pt < 字号 32.7pt** → 字重叠。
- **根因与 ② 同源**：我们的标点**占整格**，源书标点**挤在上字格右上角不占格** → 列"格数"虚增。

**② 标点占格**（用户："源文里标点好像没有占一个字体，但你给我的是占一个的"）：
- 源书：句号/逗号挤格，不占额外格（竖排书标准）；我们：标点当普通字占 1 格。

**③ 『』等特殊符号未识别（p9）**：
- 用户对照：源书 p9「許多人以爲『不一定』；許多人以爲『斷不會』」；我们的 `data/wz6/wz6_spotting_lines.json` key `"8"` 里是「以爲不一定…以爲斷不會」（**『』全丢**）。
- 全书符号统计（我们 vs 用户提供的**网页端 OCR md**）：
  | 符号 | 我们 | 网页端 md |
  |---|---|---|
  | 『 | **5** | **51** |
  | 』 | 36 | 60 |
  | 「 | 85 | 130 |
  | 」 | 45 | 119 |
- **网页端 md 已存为对照源**：`data/wz6/wz6_web_ocr_reference.md`（ⓘ 内含 2 个与本书无关的 OCR 幻觉表格——2024 账目表/财务表，校对时忽略）。
- 怀疑：我们用的 `useLayoutDetection=False + promptLabel='spotting'`（spotting 行级模式）丢符号；网页端可能用了 layout 模式。

**④ p3 越框**：5 页 v2 流式回退，p3 有 4 处 span 越框 12.5pt（你上一轮报告过）。

**⑤（一）（二）括号**：用户反馈"源文与输出不一样"——需对照源图确认差异性质（字形/位置/竖排变体）后修或说明。

## 任务

### A. 标点挤格（最高优先，同时解决 ①）
- **排版计算**：列"格数" = 字数 − 标点数（标点集：`。，、；：？！` 及竖排变体 `︒︑`），步进 = 列高 ÷ 格数。
- **渲染**：标点**挤格显示**（在字格右上角，不占额外高度）——tate 下实现建议：标点用 `\rlap`/负间距/小字号+位移（先做探针实验确认 upLaTeX 竖排下标点压缩的正确做法；参考源书标点位置：贴前一字右上角）。
- **验收**：p10 的 28 字列步进 ≥ 字号（字不重叠）；渲染 p10 与源书并排对照（标点位置/密度一致）。

### B. 字号保护（保险）
- 任何列的**字号 ≤ 步进 × 0.95**（若某列格数仍多则字号自动缩小），杜绝重叠。

### C. 『』等符号缺失（数据层）
1. **先做参数实验**（不要直接重跑全书）：取 p9（key `"8"`）单页，分别用：
   - `useLayoutDetection=False + promptLabel='spotting'`（现行）
   - `useLayoutDetection=True`（layout 模式）
   - `useLayoutDetection=False` 但 `promptLabel` 换为其它值（如 `ocr`）——如 API 接受
   对比返回的 **符号保留率**（『』「」（）计数）+ **是否有行级 rec_polys**（现有代码依赖行坐标；layout 模式若只有整页块则需评估）。token 在 `/tmp/paddle_token`（已就绪）。
2. 按实验结果选最优参数；**若某参数既保符号又保行坐标** → 重跑全文 OCR（`data/wz6/wz6_spotting_*.json` 覆盖前先备份）并回归（verify_vert）。
3. **若都丢符号** → 用 `data/wz6/wz6_web_ocr_reference.md` 做**文本级校对补全**（模糊对齐后补『』等缺失符号；写脚本落盘到数据文件；报告补了多少处）。
- **验收**：『』数量接近网页端（51/60 量级）或明确说明为何不能达成。

### D. p3 越框修复
- 修 v2 流式回退页的越框（4 处 span 越框 12.5pt）——查明回退判据为何漏过这页。

### E. （一）（二）括号
- 对照源图（source_pdf/wz6.pdf 对应页）确认差异性质；能修则修，不能则明确说明。

1. **A/B**：p10 字不重叠（步进 ≥ 字号）；文中标点位置与源书对照一致（附对比图）
