## 修法方向（你可以调整）

**优先级 1 — 不丢字**：配不上的行，若其 x 落在某个**已用槽的 x 带内**但 y 与该槽已用段不重叠，应允许在该槽的**剩余 y 空间**渲染（这与 y 拆槽同源）。
