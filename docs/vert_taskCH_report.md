## 0. 结论

p48 的错误不是「目录分支没走到」—— v8 日志实测 p48 **已命中** `nf_toc_shape` 并走 `_toc_puts`
（`[目录分支] p48 列17 形态列15 ... -> 独立路径`）。真正的错误只有一处：
**「玳安嬉遊蝴蝶巷」被 §1.995 标题署名判据误认领**（因邻列墨迹并进墨带邻域窗，字高被量成正文
1.65 倍），从 `_toc_puts` 的输入里被剔除后由 `_display_put` 画在墨带中心 x588.9，而它应在
第五十回列的 x583.7 —— 于是夹在 610.6 与 569.7 两列之间，与「永福餞行遇胡僧」字压字
（审计 `x_overlap=10.68pt y_overlap=190.88pt`）。

修法：目录页的**网格行**（同 x 带内 >=2 层的行）不允许被标题/署名路径认领，一律交
`_toc_puts` 按层渲染；页边页码/书眉仍交 `special_tex`；真标题（「金瓶梅詞話總目錄」
「詞話第二冊目錄」）自成一带，不受影响。

- p48 产物：48 行 -> 17 列 326 puts（v8 = 47 行 319 puts），16 个回列每列三层同 x；
  「玳安嬉遊蝴蝶巷」x569.9 = 「第五十回」x569.9 = 「琴童潛聽燕鶯歡」x570.2；
  `vert_layout_audit --pages 48`：**列间重合 0 处**（v8 = 1 处）。
- p53 / p54 / p55 / p563：字符量与列序均与 v8 相同（222 / 379 / 180 / 180，0 逆序）。
- 1748 页逐页字符量与 v8 **完全相同**（无退化、无增加）；wz6 `vert.tex` md5 不变；
  440 测试全绿（430 基线 + 10 新增）。

## 2. 实现

### 2.1 目录页网格行不得被标题路径认领（`_page_specials`）

新增护栏：`g['toc']` 为真时，对已判成大字号的行再做两道过滤 ——

1. **网格行**：用 `g['toc_rows']`（原始 OCR 行）按 `0.30 x 列距` 归带；本行所在带内 >=2 行
   -> 是目录列的一层，不认领，交 `_toc_puts`。真标题行自成一带（p45「金瓶梅詞話總目錄」、
   p561「詞話第二冊目錄」实测组内 1 行），不受影响。
2. **页边行**：行心在伪版心 x 范围外（页码/书眉）-> 不认领，交 `special_tex`。
   （实测 p54 右下角页码「一〇」x838.5 在版心右缘外；网格行解锁后会成为唯一「大字号行」
   而通过稀少性护栏。）

效果（`VERT_PAGES=...` 单页构建实测）：

| 页 | v8 认领 | 改后 | 产物 |
|---|---|---|---|
| 48 | 玳安（误） | 0 条 | 48 行 -> 17 列 326 puts（+7 字） |
| 45 | 目錄标题 | 目錄标题（不变） | 26 行 -> 13 列 247 puts（不变） |
| 561 | 目錄标题 | 目錄标题（不变） | 47 行 -> 12 列 271 puts（不变） |

| 562 | 0（32 条被稀少性挡下） | 0（32 条网格行被新护栏挡下） | 49 行 -> 17 列 407 puts（不变） |

## 4. 遗留与偏差说明

1. **「全列做槽」未按简报字面整块删除**。它已不服务目录页（目录页在 `page_puts` 开头被
   `_toc_puts` 接管，走不到这条规则），但整块删除会回归**非目录页**页码列落位：
   实测 p969「四〇九」x106.4 -> x738.9、p491「四四七」x104.8 -> x563.1（p1736 不变），
   违反 ④.4「普通正文页一字不动」。故保留为非目录页「槽集补足」规则（与目录分支零耦合）。
   这是与简报 ④.3 的唯一偏差，数值证据见 §2.2。
2. **用户草稿脚本 `/tmp/check_p48v2.py` 的 `merged` 判据会误报**：它按字 origin x 聚列后，
   源书 p48 的一列天然含三层（18-21 字），`n > expect+9` 对任何正确产物都成立。
   正确的「三层不合并」证据 = 三个独立渲染槽的 y 跨度与层间空档（§3.A）+ 审计列间重合 0。
   脚本在仓库外，未改。
3. **构建 env 敏感性（既有，不是本轮引入）**：`VERT_BOLD=0.5` 会进入探针渲染
   （`_put_tex` -> `_vb`），使标定 `INK_RATIO` 0.866 -> 0.872（+0.006 = 描边 0.5pt / F40 的一半），
   逐页差 1 字（p147）；`VERT_TOC_RESCUE_OK` 对目录页已无影响（目录页改走 `_toc_puts`）。
   复现 v8 基线必须用默认 env（只设 `VERT_TMP`），`rebuild_v6.sh` 里的
   `VERT_BOLD=0.5 VERT_TOC_RESCUE_OK=1` 是旧交付口径，不宜用于本轮基线对账。
4. 目录页内长点线的格数还原（taskU §6 遗留）不受本次影响；p54 的页边页码「一〇」仍由
   `special_tex` 渲染。
