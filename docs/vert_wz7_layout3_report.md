## 2. 复核事实的再核实（全部用源图墨迹，不用 OCR poly）

复核方法：源图与产物都在**同一 clip、同一灰度口径**下量「墨迹 run」（源书 = 逐页 Otsu；产物 = 干净矢量页固定阈 150），
按词/片逐条对齐。脚本：`tmp_vert/taskR2/m_both.py`、`recon_p29.py`、`disp_recon.py`、`fax_stats.py`（命令见 §7）。

### 2.1 西文行：全角化复现 + 方向再确认

* 文本层证据（改前 `tmp_vert/taskR/R300b.pdf` p29）：`Ｗｅ` / `ｒｅｃｅｉｖｅ` / `ｇｉｖｅ.—Ｃｏｌｅｒｉｄｇｅ`
  = U+FF37/U+FF45（全角形式），字体名 `NotoSerifCJKjp-Regular`；字号 span 28.4。
* 字形口径（探针 `tmp_vert/taskR2/probe_font.py`，真 preamble 编译）：CJK 字体在 tate 模式下的 ASCII 墨迹
  **0.745em 宽 × 0.46em 高**（又宽又扁，占满全角格）；源书是 **0.68em 宽 × 0.66em 高**（比例拉丁）。
* 方向（复核项的「字母正立」说法**不成立**）：源图 600dpi 放大 + 逐 run 墨迹纵横比实测 —— 源书该行首字符是
  **54.0pt 长 × 3.0pt 粗的竖线**（= 侧排后的长横线），字母 `l`/`i`/`d` 的墨迹跨向与 `g` 的下沉方向也一致地
  指向页右/页左 ⇒ 源书该行是**整行侧排（逆时针转 90° 可正读）**，与 taskR 的实现方向一致（本项无需改）。
* 单位口径（本轮新发现）：源图坐标是 **bp**，TeX 坐标/字号是 **TeX pt**（1bp = 1.00375 TeX pt）——改前按 1:1 塞，
  744pt 长的行会沿行**缩 0.37%**（逐词误差从行首 -0.8pt 漂到行尾 -5.0pt）。本轮按 `× PT2BP` 换算，误差归零。

| 口径 | 源书 | 产物 | 比 |
|---|---|---|---|

| OCR poly 盒高 ÷ 2 字（复核项用的口径） | 135.4pt | — | — |

OCR poly（p29 侯健，`data/wz7/wz7_spotting_coords.json`）y 909.8-1180.4 = 270.7pt，把**两字之间 65pt 的空档**

### 2.4 「金瓶梅論」位置（复核项④）+ 新查出的竖直落位残留

逐字实测（源书 vs 产物，同一 clip）：列位 x **731.2-778.5 vs 731.2-777.2**（宽 47.3 vs 46.0），
逐字墨高 **44.2/44.2/45.0/19.5/25.5 vs 44.0/45.2/45.5/19.0/25.8**（同一 clip 内 5 条 run 一一对应），
逐字起点 330.0/379.5/429.8/479.2/499.5 vs 332.0/382.8/432.8/483.2/502.8 ⇒ **整体下移 2.0pt，无水平偏移**。
OCR poly 的「源书 56.5pt」同样来自 poly 盒（226.0pt ÷ 4 字）。

**真实残留**：标题/署名行的竖直落位偏低（抽查 6 行：p41「金瓶梅詞話序」+2.0、p41「毛子水」+2.0、p131 +2.2、p270 -2.0、p29「金瓶梅論」+2.0、p29「侯健」**+8.3**；全库显示行共 19 行/15 页），最大字号行「侯健」偏 8.3pt。
根因：`col_puts` 用标定常数 `INK_ASC`（全库字中位 0.954em）换算「墨顶 → 基线」，而竖排**逐字**墨顶比例自变 ——
由渲染实测反解：金 0.918em、侯 0.862em（同上表两个落位差），而两者轮廓 ymax 只差 0.008em（0.845/0.837），
说明这是 tate 定位（垂直原点）逐字效应，不能由轮廓直接推算。修法与代价见 §6 遗留 1（本任务如实报告 + 给选项）。

## 3. 实现（§1.995，锚点行号见 spec/vertical/README.md）

### 3.1 西文行（§1.995a，`_latin_tex` L3587 / `_lat_metrics` L3493 / `_tfm_widths` L3467 / `_lat_pieces` L3540 / `_assign_runs` L3554 / `_latin_put` L3521）

* **字体**：拉丁 TFM 字体 `ptmr8t`（env `VERT_LATFONT` 可换，`VERT_LATFONT_PFB` 指对应 Type1 字形文件）；
  度量走 Type1 轮廓 + **TFM 宽度表**（TeX 排版真正用的前进量；解析器 `_tfm_widths` 自校验：各表尾 = 文件长）。
  ASCII 在 T1(8t) 槽位 = 码位，非 ASCII（破折号）无 TFM 字形 → 自动回落 CJK 字体（竖排形态 = 竖线，与源书一致）。
* **逐片锚定**：词按空白切 → 词内破折号再切片（`_lat_pieces`）；源图可词/片的位置由「大空隙 = 词间」分组，
  词↔词组用宽度 DP 单调配对；片↔源图 run 段用 `_assign_runs`（宽度 DP）切分。
  **位置口径**：片沿行起点 = 该片实测墨迹起点 ×PT2BP − 本字体片首墨迹余量；
  片基线 = 该片实测墨迹下缘 ×PT2BP − 本字体墨迹下缘余量（**逐片**，源书该行自身不共线：两条破折号墨心差 3.3pt、
  逐字横差随 y 从 +3.7pt 漂到 0.0）。
* **字号**：行字号 = 源行墨迹横宽 /（拉丁字母串的 Type1 墨迹上下缘比）×PT2BP；破折号片字号 = 该 run 实测长 /
  （0.772em 探针长比）×PT2BP。
* **片内字距**：只补「本字体字形比源书窄」那部分，夹在 ±0.25em。
* 开关：`VERT_LAT=0` 关闭；`VERT_LAT_FONT=0` 回到 CJK 全角 ASCII 老口径（对照用，报告里 A/B 图即用它）。

## 6. 遗留（如实报告 + 选项）

1. **标题/署名行竖直落位 +2.0pt（多数行）/ +8.3pt（侯健）**。根因见 §2.4：`INK_ASC` 是全库字中位常数，
   竖排逐字墨顶比例自变（金 0.918 / 侯 0.862，轮廓无法预测）。
   **选项**：(a) 现状（残留 ≤ 8.3pt，占页高 0.6%，19 行受影响）；(b) 建排前对显示行**批量探针**（把各行首字按
   各自字号渲一页、量墨顶）→ 按实测落位，代价是 1 次额外编译（~2s）+ 需要把显示行检测提前到建排前一遍
   （当前检测依赖本页墨迹/槽格，需重构）；(c) 按字高比例给一个经验修正（会让部分行变差，不推荐，本任务未做）。
2. **拉丁字形与源书字体存在字形差异**：本轮用 TeX 的 Times（Nimbus Roman）。逐字实测源书字体的**下伸部更短**
   （`g` 墨高 0.594em vs Nimbus 0.666em），故 `g/p/y` 类字母略大 ~10%（其余字母 ≤ 5%）。属字体可得性问题；
   换字体只需 `VERT_LATFONT`/`VERT_LATFONT_PFB`（度量与渲染同步换），不需要改代码。
3. **源书该行自身倾斜**：两条同字形破折号的墨心差 3.3pt、逐字横差随 y 从 +3.7pt 漂到 0.0pt（≈0.3°）。
   本轮已把基线改为**逐片实测**，故每片都跟着源书走（Δ横心中位 -1.1pt，范围 ±2pt），
   但同一片内部的字仍共一条基线 —— 要完全贴合需逐字基线（收益 < 1pt，未做）。
4. 影印页判据对「扫描质量好的翻印页」可能不命中（它们每字墨迹面积不高）：本册的影印页是灰底低对比扫描，
   故判据余量 3.8 倍；换书需复跑 `fax_stats.py` 看分离度（报告给了脚本与统计口径）。
