# 字体宽度/字距测量报告（t369）

## 方法

`src/tools/glyph_width_probe.py`：源 PDF 150dpi 渲染，在 OCR 行 y 带内找墨迹 x 范围；产物取同文本行 span bbox；比值=产物宽/源墨宽。ghbq/wz1 各约1500/3300行，wz10约800行。

复现：
```
/usr/bin/python3 src/tools/glyph_width_probe.py --books ghbq,wz1,wz10 --json /tmp/glyph_width.json
```

## 宽度比

| 书 | n | 中位 | p10 | p90 |
|---|---:|---:|---:|---:|
| ghbq | 1505 | **0.940** | 0.935 | 0.972 |
| wz1 | 3363 | **0.957** | 0.946 | 1.010 |
| wz10 | 817 | **0.995** | 0.986 | 1.082 |

早期用 OCR poly bbox 直接比得到 ghbq0.897/wz10 0.891；改为源图墨迹后偏差缩小到 0.94/0.995，说明第一版测量混入了 OCR 框留白，不能直接当字宽结论。

## 根因排查

1. **字体选择**：`_latex_preamble.py` 统一 `Noto Serif CJK SC`（1em/字）；源书字体不同，ghbq/wz1 有约4-6%更宽字面/字距，wz10基本一致。不能通过换全局字体同时修正三本。
2. **CJKglue**：geom 默认 `0pt plus 0.5em minus 0.4em`（基础0）。已排除“基础字距缺失导致-11%”的初版结论；剩余 ghbq/wz1 4-6%与源书字体/字距有关。
3. **额外间隙**：产品文本层无统一 `\u3000`/`\enspace` 插入（目录特判除外）；不是正文差异来源。
4. **textwidth/MARGIN**：产物行宽受 `MEASURE` 影响；宽度比稳定，但行内每字宽主要跟随字体。
5. **两趟校准**：只调字号/高度，无字距参数；确认无字距校准。
6. **wz10 17%窄历史**：当前实测0.995，未复现；旧记录可能来自OCR框/换行测量。

**判定：未找到能同时解释三本、且不改页数的确定字宽根因。ghbq/wz1 的4-6%差异指向源书字体/字距，但全局改 CJKglue 或字体必然改断行/页数，按任务要求停止，不做特判。**
