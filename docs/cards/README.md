## 立即开始

第 1 步：复制 [01_架构梳理行动卡](01_架构梳理行动卡.md) 末尾的 Prompt，粘贴给 AI，让它只读 src/ 下所有 .py 文件。

第 2 步：拿到结构理解后，用 [02_特征测试行动卡](02_特征测试行动卡.md) 的 Prompt 生成特征测试。

第 3 步：测试全绿后，用 [03_安全重构执行卡](03_安全重构执行卡.md) Step 1 开始抽共享模块。

其余四份卡在重构过程中按需使用。
