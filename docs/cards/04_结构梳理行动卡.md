# /opt/test 结构梳理行动卡

> 什么时候用：代码已经拆成多个文件（src/pipelines/ 两个管线、src/calibration/ 两个校准驱动、src/tools/ 多个工具脚本），但你怀疑它们靠全局环境变量、subprocess 调用和共享数据格式暗中耦合——改一个文件，另一个莫名其妙坏了。

## 输入

`/opt/test/src/` 目录下的所有 .py 文件：
- `src/pipelines/build_classic.py`（1154行）
- `src/pipelines/build_geom.py`（1065行）
- `src/calibration/fit_positional.py`（97行）
- `src/calibration/fit_positional_classic.py`（97行）
- `src/test/test_cases.py`、`src/test/verify_geom.py`
- `src/tools/` 下的工具脚本
- `src/ocr/run_spotting_ocr.py`

## ⚠️ 前置门禁（依赖图要标注 fork 来源）

依赖图不只是 import 关系。build_geom 和 build_classic 是 fork 关系（classic 从 geom 复制出来，前 ~800 行重合），
但 Python import 系统感知不到这个血缘。依赖图必须额外标注：
- 每个文件从谁 fork 出来的
- fork 后各自新增/修改了哪些函数
- 哪些差异是有意的（古籍特色），哪些是 fork 时无意带过来的

不标注 fork 来源，重构时必然误把"分叉后各自演化的同名函数"当"重复代码"合并。

### 3. 隐藏契约清单

- **public import 路径**：`from src.pipelines.build_classic import ...`——目前没有外部 import，但一旦抽取共享模块（`src/utils/tex_escape.py`），这个路径就成了 public API，重构时不能随便改
- **命令行参数约定差异**：
  ```
  build_geom.py:     argv[1]=spotting_lines, argv[2]=spotting_coords, argv[3]=out.pdf, argv[4]=src_pdf
  build_pdf_v13.py:  argv[1]=src_pdf, argv[2]=out.pdf, argv[3]=spotting_lines, argv[4]=spotting_coords, argv[5]=titles, argv[6]=markdown, argv[7]=page_numbers
  ```
  顺序不同！相同的 argv[1] 在这条管线是输入 PDF，在那条管线是输出 PDF
- **输出 PDF 命名约定**：`成果_<book>_<version>.pdf`，verify_geom.py 和 test_cases.py 的路径硬编码依赖这个约定
- **坐标空间约定**：所有 spotting coords 基于 DPI=200，页面尺寸从 coords 推导（不从源 PDF 读取——因为 OCR 坐标空间可能与 PDF 尺寸不一致，如 wz1 coords=633pt 而 PDF=602pt）
- **GMPG 标记格式**：`GMPG\d+ZZ`，fit_positional.py 的 measure_heights 正则依赖这个格式。如果 build_ 脚本改了标记格式，校准驱动静默失败
- **事件/日志格式**：`print(f"[几何] cw={cw}...")`——verify_geom.py 或人类可能依赖这些日志输出来判断状态

## 完成标准

画出来的依赖图能解释：
- 为什么改 build_classic.py 的 _esc_chars → fit_positional_classic.py 的输出可能变
- 为什么漏设 PER_PAGE_PITCH → wz2 的 pitch 达标率会掉到 40%
- 为什么 fit_positional 两个版本必须同步修改（否则两条管线的校准逻辑分化）
- 为什么删 build_pdf_v13.py 之前必须先确认哪些调用方还依赖它

## 禁止事项

- 禁止只看 `import` 语句——`subprocess.run(['python3', 'build_geom.py'])` 也是依赖
- 禁止只看 Python 代码——环境变量通过 shell 传入，耦合在 bash 调用里
- 禁止假设「命令行参数顺序统一」——实际三条管线的 argv 语义不同
- 禁止忽略数据格式耦合——spotting JSON 的键结构改了，所有管线都崩
