## ⚠️ 前置门禁（重构前先锁 fork 差异）

geom 和 classic 前 ~800 行是 fork 关系（函数同名、行号平移 -2），但 fork 后各自新增了不同逻辑。
重构前用以下命令锁定当前差异，防止"统一代码"时意外抹掉有意为之的分叉：
```
diff <(python3 src/pipelines/build_geom.py ...) <(python3 src/pipelines/build_classic.py ...)
```
确认所有差异都是可解释的（古籍特色 vs 现代特色），而非意外分叉。

### 每一步的通用纪律

1. 开分支 `refactor/extract-<模块名>`
2. 先确认特征测试全绿（基线）
3. 抽代码
4. 跑全部特征测试 → 全绿才 commit
5. 故意改坏一处（如把转义表删一行）→ 验证对应测试变红
6. 撤回故意改坏 → 恢复全绿
7. PR 说明：
   - 行为不变（特征测试从 N 条全绿 → N 条全绿）
   - 锁住了哪些现状
   - diff 统计（新增/删除行数）
