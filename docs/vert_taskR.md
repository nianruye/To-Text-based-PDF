## 用户那页的事实（已核）

`data/wz7/wz7_spotting_lines.json` 的 `key28`（样本第 29 页 = wz7 源页 29）：
```
行0: '金瓶梅論'                                 ← 标题（源书：第二列顶端，字号≈正文）
行1: '侯健'                                     ← 作者署名（源书：**最右列顶端，约 2 倍字号**）
行2: '—We receive but what we give.—Coleridge'  ← 英文引语（源书：**整句侧排，逆时针旋转 90°，自上而下，字头朝左**）
行3..14: 正文
```
**现状**：这三行都被当作普通竖排列渲染 → 标题没放大/署名位置错、英文被按"每字符一格"竖拆、`—` 竖排成竖线。

## 任务

### A. 西文行（整行侧排）
- **检测**（数据驱动）：某行的拉丁字符占比高（阈值按实测分布选，报告给依据）→ 判为西文行。
- **渲染**：整行**按源书实测方向**旋转渲染（源书为逆时针 90°、自上而下、字头朝左——**须从源图墨迹/字形朝向实测确认，不要凭空假定**）；
  - **旋转实现必须用已验证的精确方式**（`\special{pdf:literal ... q K 0 0 1 0 0 cm}...Q` 一类），**严禁 scalebox 式数值逆矩阵**（历史教训：etrans 6 位有效数字截断 → 逐字累积漂移）。
  - 整行位置（起点/基线/字距）按源书该行墨迹实测。
- **验收**：p29 英文行与源书并排对照（截图）；破折号 `—` 显示为**横线**而非竖线。

### B. 标题 / 署名行（大字号）
- **检测**：该行字号（**源图墨迹实测**）显著大于正文（如 ≥1.4×）→ 判为标题/署名行；**不得用固定字号阈值**，按本书正文字号的比例。
- **渲染**：字号与位置**按源图实测**（现管线可能把大字 clamp/兜底压回正文尺寸——查明并让实测值生效）。
- **验收**：p29 的「侯健」（最右列顶端、约 2 倍）与「金瓶梅論」（第二列顶端、≈正文）与源书并排对照。

### C. 影印页整页贴图（**用户明确要求**）

- **做法**：整页贴源图（渲染源书该页作背景），**不重建**。
- **判据必须数据驱动、不得写死页号**（用户页号仅用于**验证判据有效性**）——建议组合：OCR 行数极少/为 0 + 源图墨迹特征（大块墨迹/无规整列带结构/连通域尺寸分布异常）+ 可选：该页文本量与页面积比异常低。
- **验收**：**源页 5-28**（用户点名）全被判为贴图页并正确贴图；**同时不得把正常正文页误判为贴图页**（给全书/300 页的判据命中统计 + 抽样对照）。
