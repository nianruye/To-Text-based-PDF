## 二、根因

### 2.1 任务一/二：`_dual` 判据只看条数，目录页被误当「双行小字页」

p53/p55/p561/p1172 的共同结构：每「回」占一列，列内**同 x 不同 y** 自上而下 = 回次 + 回目(1-2 行)
+ 竖排点线 + 页码。`page_rows` 合并后每列仍是 1-2 条行（回次与回目合成一行，页码因间隔远大于
2.5 步进而独立），于是：

```
p53:  R=21 行, C=12 槽  -> 1.7C=20.4 <= 21 <= 2.3C=27.6
p55:  R=16 行, C= 8 槽  -> 16 = 2C
p561: R=24 行, C=12 槽  -> 24 = 2C
p1172:R=32 行, C=16 槽  -> 32 = 2C
```

全部落进 `page_puts` 的「双行小字页」窗口 `1.7C <= R <= 2.3C`。`_dual` 的实现是**按 x 把每个槽拆成
左右两半**（竖排先右子列），再把行按序塞进子槽 —— 这对「一槽两列」的真双行小字页正确（p563/p1172
的双行形态本应如此），但目录页的多行是**同一 x 的上下分段**：左右子列的 x 只差半列距，行按阅读序
落进左右子列后，文本层就出现交错：

```
p55 修前: 第三二十九七九回李瓶兒私語翡翠軒潘金蓮醉鬧葡萄架
p53 修前: 七第第八三四三七回回王淫婆婦定背十件武挨大光偷計姦…
```

配套的第二、第三个问题：

1. **伪版心 y 窗太窄**：伪版心 y = 长行（回目）包围盒。p55 的 version y 窗是 404.5-895.4，回次在
   y234-383（框上）、页码在 y1246-1327（框下）——`_slots_of_edges`/`_split_slot_y` 的 `_slot_runs`
   窗口根本看不到这两段，槽 run 只有回目。
2. **竖排点线把整列连成一条**：目录列的回目与页码之间是点线（实测点径 4-5pt、点间距 5-10pt）。
   `_split_slot_y` 原口径把高 >= 2pt 的 run 都算「像字」，点线因此把所有段连起来，
   任何空隙都测不出 —— 即使把 y 窗放宽也拆不开。

### 2.2 任务三：p43「凡例」标题在伪版心 x 外，候选窗口先把它挡掉

根因链（与任务书一致，实测复核）：

1. `nf_body_rows` 只认长行（`(y1-y0) >= LONG_H_FRAC x 页高`，p43 阈值 ≈172.7pt）；凡例 2 字行高
   132.4pt -> 不进 body；
2. 伪版心 x 域 = body 包围盒（+ pad）-> 右缘 742.9；
3. 凡例 OCR 行心 (749.9+804.4)/2 = **777.15**；`_page_specials` 的候选判据是
   `in_l-6 <= 行心 <= in_r+6` -> 上限 748.9，标题被挡在候选之外，后续「大字号 + 稀少性」
   两道判据根本没机会执行（所以也没有任何日志）。

## 三、修法

### 3.1 目录页判据 + y 拆子槽（`VERT_NF_TOC`）

`page_puts` 在 `_dual` 之前先判目录页（只在 NF 伪槽格页）：

```
行心 x 聚类（容差 = 0.5 x 列距）
命中条件: C >= 4 且 R >= 1.3C 且 x组数 <= C+2 且 R >= 1.4 x x组数
```

- 真双行小字页的 2C 条行分居 **2C 个 x 心**（组均 ~1.0）-> 不命中，仍走 `_dual`；
  实测 p563（5 槽 9 行、x 组 8、组均 1.00）正确落选，产物逐字不变。
- 目录页每列的多条行**共享 x 心**（组均 ~2.0）-> 命中。

命中后：

1. **不拆 x**，槽集改用 `m['slots']`（含被判进 note 的導讀/目錄标题槽）；
2. 槽的 y 窗扩到「伪版心 ∪ 本页所有 OCR 行的 y 范围」（回次/页码在伪版心外）；
3. `_split_slot_y` 按新参数 `rmin = 0.30 x 字步进`（≈7.5pt）过滤点线后再判空隙；
   点线被当空白，回目与页码之间 400+pt 的空隙得以拆成上（回次+回目）/下（页码）两个子槽；
4. 子槽仍是既有 `ysplit=True` 口径，`col_puts` 按本子槽实测跨度铺满（未改渲染端）；
5. 配对走既有位置口径 `_align_rows_slots(geom=True)`（x 硬门限 2 列距、y 范围相交），
   而 TOC 页即使 OCR 帧未标定也启用 —— 伪版心由本页正文行盒定，行与列带同在 OCR 帧，
   实测 p53/p55 行心与列带心差 <= 0.5pt。

### 3.2 点线 vs 细横画（`_split_slot_y` 的 `rmin` 分支）

只按高度过滤会把页码「一/二/三」这些**单条横画**（高 1-3pt）当点线丢掉（第一版实测 p53
第八回「一三三」3 字漏渲染）。补一条 x 跨度判据：横画 x 跨度接近字宽（>= 0.5 x 步进）即保留；
点线是「小而方」的墨点（x 跨度 ~2-3pt），仍然被过滤。

### 3.3 版心外大字号短行单独补槽（`VERT_NF_TITLE_OUT`）

版心**不动**（不改 `_ink_bands` 扫描窗口、不改伪版心），只把 `_page_specials` 的**候选行心窗口**
向左右外扩 `1.5 x 列距`，且仅限短行（len <= 8）。外扩后仍要过既有的两道判据：

- 大字号：实测字高 >= 1.4 x 本页正文行字高中位；
- 稀少性：大字号行数 <= max(1, 25% 长行数)。

p43 凡例（2 字、字高 63.6 vs 正文 33.3 = 1.91 倍）通过，按标题署名路径逐字 `\put` 渲染
（x 带进 `_SPECIAL_BLOCK`，正常配对不再落位），因此只增这一行、不产生额外的列带。
