# 开发任务指令：构建双轨制 PDF 识别与排版还原系统

## 1. 项目背景与核心目标
我们需要重构现有的 `build_geom.py`（或核心排版还原模块），使其成为一个**通用的双轨制排版还原系统**。
系统需要支持用户前置选择 **“古籍模式”** 或 **“现代排版模式”**，并根据文档特征动态调整渲染策略。
**核心痛点解决**：
- **古籍模式**：解决 LaTeX 行盒不重叠导致 CJK 古籍“墨高重叠”失效、产生大量空白页或溢出的问题。
- **现代模式**：解决强行使用古籍绝对坐标导致现代文档（含公式、图片）行距穿模的问题。

## 2. 系统整体架构 (Routing Architecture)
请在代码中实现一个 `LayoutRestorationEngine` 类，包含一个路由分发方法 `process(document_data, mode)`。
- `mode = "ancient"`：进入古籍高保真管线。
- `mode = "modern"`：进入现代结构化管线。

## 3. 管线 A：古籍高保真模式 (Ancient Pipeline)
**输入**：OCR 行级数据 (spotting) + 版面分析数据 (layout)。
**核心逻辑**：先进行“版面规整度检测”，然后分发到不同的 LaTeX 渲染策略。

### 步骤 A.1：版面规整度检测 (Layout Regularity Check)
在生成 LaTeX 前，统计当前页所有正文行的 `y` 坐标差值（行距 Pitch）和行高（Height）。
- 计算行距的标准差（Variance）和行高的变异系数（CV）。
- **判定规则**：如果方差和 CV 低于设定阈值（如 `pitch_variance < 2.0`），判定为**规整古籍**（刻本/印本）；否则判定为**不规整古籍**（抄本/稿本/破损本）。

### 步骤 A.2：规整古籍渲染策略（P0 方案：网格流式排版）
**适用场景**：标准刻本、铅印本，具有固定物理网格。
**LaTeX 核心机制**：利用 TeX 底层参数强制忽略行盒碰撞，完美复现“墨高重叠”。
**请生成如下 LaTeX 导言区及渲染逻辑**：
```latex
% 导言区设置
\usepackage{xeCJK}
% 核心魔法：强制忽略行盒重叠，严格按 baselineskip 排布
\lineskiplimit=-\maxdimen 
\lineskip=0pt

% 页面环境设置 (假设源 pitch=35pt, 行盒高=37pt)
\newenvironment{ancientpage}{
    \baselineskip=35pt % 锁定目标 pitch
    \parskip=0pt
    \parindent=0pt
}{}

% 单行渲染宏 (strut 高度设为行盒高 37pt)
\newcommand{\renderline}[1]{%
    \noindent\makebox[\textwidth][l]{\rule{0pt}{37pt}#1}\par
}
```
**Python 生成逻辑**：遍历 OCR 行，直接输出 `\renderline{识别文本}`。双行夹注需打包进固定高度的 `\parbox` 中。

### 步骤 A.3：不规整古籍渲染策略（降级方案：绝对坐标定位）
**适用场景**：手写抄本、稿本、严重扭曲破损本（无统一基线）。
**LaTeX 核心机制**：放弃流式堆叠，使用 `textpos` 宏包按 OCR 提供的 `(x, y)` 绝对坐标“盖章”式渲染。
**请生成如下 LaTeX 逻辑**：
```latex
\usepackage[absolute,overlay]{textpos}
\textblockorigin{0mm}{0mm} % 设置坐标原点为页面左上角

% 单行绝对定位渲染宏 (参数: x坐标, y坐标, 行高, 文本)
\newcommand{\renderabsline}[4]{%
    \begin{textblock*}{\textwidth}(#{1}, #{2})
        \rule{0pt}{#3}#4
    \end{textblock*}
}
```
**Python 生成逻辑**：遍历 OCR 行，将像素坐标 `(x, y)` 转换为 LaTeX 单位（如 mm 或 pt），输出 `\renderabsline{x}{y}{height}{text}`。

### 步骤 A.4：古籍特殊元素处理
- **双行夹注**：利用 layout 数据识别连续的小字行，合并为一个 Block，使用 `\parbox[t][35pt]{0.5\textwidth}{\small 夹注文本}` 渲染。
- **印章/批注/插图**：从正文流中剥离，使用绝对坐标（同 A.3）叠加到页面上，避免打断正文网格。

## 4. 管线 B：现代结构化模式 (Modern Pipeline)
**输入**：OCR 行级数据 + 版面分析数据。
**核心逻辑**：放弃逐行物理坐标，进行“段落聚类”和“语义映射”，交由 LaTeX 引擎自动流式排版。

### 步骤 B.1：行级转段落聚类 (Paragraph Clustering)
**禁止使用 `\makebox` 和绝对 y 坐标！**
**Python 逻辑**：
1. 按 `y` 坐标对行排序。
2. 如果相邻两行的 `y` 差值小于 `行高阈值`（如 1.2 倍平均行高），且 `x` 坐标相近，则合并为同一个段落。
3. 如果某行 `x` 坐标有明显缩进（如大于 2 个字符宽度），则强制开启新段落。

### 步骤 B.2：语义标签映射与流式渲染
根据 layout 提供的 block 类别，映射到现代 LaTeX 语义环境：
- `title` / `paragraph_title` -> `\section{}` 或 `\subsection{}`
- `formula` -> `\begin{equation} ... \end{equation}` (需对 OCR 公式进行 LaTeX 转换)
- `table` -> `\begin{tabular} ... \end{tabular}`
- `image` -> `\includegraphics{}`
- 普通 `text` 段落 -> 直接输出纯文本，由 LaTeX 自动处理首行缩进（`\parindent=2em`）和行距（`\setstretch{1.5}`）。
