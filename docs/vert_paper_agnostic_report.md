## 2. 为什么这么定（实测依据，不是拍脑袋）

**2.1 页边带为什么是「页幅比例 ∪ 内框缘」而不是纯内框锚定。**
用 `tmp_vert/taskN/survey_frame.py` 对 wz6 逐页实测内框（226 页有版框）：

| 统计（wz6） | 值 |
|---|---|
| 书眉/页码行 `x0 − 本页内框右缘` | 中位 **+51px**、p10 +42、min −25；**2/110 条（2%）落在框内** |
| 左边注行 `内框左缘 − x1` | 中位 **+48px**、min 34；**0/123 条**伸进框内 |
| 本页内框右缘（px） | min 1080 / 中位 1123 / max 1155 |

→ 「书眉/页码在框外」在 wz6 上成立（98%），但**逐页内框波动 ±38px**（奇偶页扫描错位），
纯内框锚定会把 2 条书眉漏掉（分类翻转 → 产物变化）。故取**并集**：页幅比例带保底（wz6 精确等价）、
内框缘只在「比页幅带更靠内」时外扩（专门救「版心更宽」的书）。
`survey_flips.py` 逐条验证了 7 种候选门限在 wz6 上的分类翻转数：**R2（页幅比例）= 0 翻转**、
R3/R4（纯内框）= 少 2 条、R6（并集）= 0 翻转。

**2.2 版框线粗细为什么用「最大间隙」。** `survey_width.py` 实测 16 页：

| 组 | 厚度分布（pt） |
|---|---|
| 竖线组（212 条） | 0.5×46 / 1.0×146 / 1.5×5 / **3.5×11 / 4.0×4** |
| 横线组（60 条） | 1.0×4 / 1.5×26 / 3.5×1 / 4.0×23 / 4.5×6 |
| 最大间隙分割 | 细簇上缘 1.50 ↔ 粗簇下缘 3.50（间隙 2.00） |

→ 分界 `0.7×粗簇下缘 = 2.45`、上限 `1.5×粗簇上缘 = 6.75`。线厚只能是**半整数**
（`(x1-x0+1)/2`，x 是整数像素），而 2.45 与 2.4、6.75 与 6.5 落在**同一个半整数区间**内
（2.0 < 2.45 ≤ 2.5、6.5 < 6.75 ≤ 7.0 的边界都在整数点上）→ **分类完全等价**（见 §3 说明）。

**2.3 边注比上限为什么用「空档」。** 206 条左带候选行实测比值分布：注簇 0.25-0.61（密集）→
稀疏尾 0.761/0.778/0.797/0.808/0.833 → **空档** → 正文簇 1.068。兜底 0.85 落在空档 (0.833, 1.068) 内，
故**保留 0.85**（值面零漂移）。任务书建议的「p95×1.2 = 0.754」会落在注簇尾部**内部**，
把 0.761-0.833 的 5 条注误排除 → 与「零回归」冲突，故改为空档口径（理由与证据见 §3）。

   `PUNCT_SIZE/DX/DY`、`BR_SIZE*` 的源侧样本来自 `_calib_src_page`，它复用 §1.98 的**版框槽格**
   配对；无版框书 `page_metrics` 全 None → 可用 0 页 → 这 8 项回落**兜底表**（= wz6 实测值）。
   后果：wz7 的字宽/标点/括号字号仍按 wz6 的比例渲染，观感会偏。
   **后续方案**（本轮未做，避免与 taskN 六项清单外的改动混在一起）：给 `_calib_src_page` 加一条
   **无框伪槽格**路径 —— 版心 = 正文 OCR 行墨迹包围盒、槽格 = `_ink_bands(ink, il, ir, it, ib, cov=0.12)`
   的墨迹列带 + `_align_rows_slots` 配对（与 §1.99 `page_puts_loose` 同源），并用
   「本书是否存在实测版框」(`FRAME_REF is None`) 开关，保证有框书路径一字不改。
2. **`_grid_fit`/`_grid_from_bands` 的列距窗按页宽比例**（不是「内框宽÷列数」）：后者需逐页内框、
   且会把 wz6 上被拒页的判定改掉（有回归风险）。当前口径在 wz6 上精确等价，对「每页列数与 wz6
   差 30% 以上」的书需用 `VERT_GRID_P_*_FRAC` / `VERT_P_*_FRAC` 覆盖（spec §8.5 已记）。
3. **8 项判据类常数未改**（taskN 清单如此）：逐条标注见 spec §8.5。其中两处**严格说不是尺度无关**、
   已如实标注：DEROT 的字组件窗 15-130px（随字号）、`special_tex` 的 `gink=0.88×font`（字体绑定）。
4. **wz7 样本的页码行 OCR 坐标越出页幅**（实测 p28「三六四」x2476-2649 > 页宽 1843.6px）：
   `ink_extent` 的「窗口为空」判据会**安全跳过**（不崩溃、不误渲染），但也意味着这条页码不会被渲染 ——
   属**OCR 数据问题**（该书相关页的坐标不在页幅坐标系里），需重跑该书 OCR 或换坐标系，本轮如实记录。
5. **`N_COL_FRAME` 兜底 12 在无版框书上仍是 wz6 值**：只被框驱动路径消费（`page_metrics`/
   `_grid_from_bands`/`page_puts_loose`），无版框书这些路径不启用 → 不影响当前产物；
   若将来接 5.3.1 的伪槽格路径，则需同时把槽数改为**OCR 列位数**。
6. **字体选择仍人工**（taskN 明确本轮不做）：`VERT_FONT` 默认 Noto Serif CJK TC；
   选定后 `VERT_METRICS`/`PUNCT_INK`/`NOTE_INK_MAX`/`INK_RATIO` 等**已由 §1.956 自动重标**（taskM）。
