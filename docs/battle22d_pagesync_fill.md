## 0. 结论

- **动态 v2 达标**：**81/81 页 ±8%（100.0%）**，达标率 ≥90%；源填充均值 **0.501**、生成 **0.458**、绝对误差均值 **0.051**。
- **字号/行距**：F 范围 **10.00–28.35pt**（clamp 6.5–30）；行距 **1.35–1.65**（1.35–1.75 内）；64 页数学估算 F>14、60 页 >20；最高 28.35pt（p703）。

- **保留 v3**：p701 回前诗 5 行（源文 7+7 两句一行）、p713/p743 4 行、p771 5 行；页眉「原書 pXXX」；页脚/边注小字；81 页=源 81 页；跨页合并在重排 `book_v3.pdf`，页同步 1:1 不合并。

## 1. 输入与方法

- 输入：`tmp_vert/battle22c/structured_v3_reflow.json`/脚本、`pagesync_fill.csv`、v1 structured、`source_pdf/wz7.pdf` 页 bbox。
- 页同步：每源页=1 PDF 页，页面 892.5×1323pt（TeX 895.86×1328.0pt），页眉 `原書 pXXX`；保留 v3 的 poem/footer 元素。
- 动态算法：
  1. 用 t106 F=14 实测 `gen14` 与源填充 `target` 按 `F_est=14·sqrt(target/gen14)` 估 F（target<0.15 固定 10pt）。
  2. 初始行距 1.55；构建后测生成文字 block bbox 并集/页面积。
  3. 若 |err|>8%：先调行距（1.35–1.75，±0.10）；行距到界后按 `F*=sqrt(target/gen)` 调 F（clamp 6.5–30）。
  4. 实际 1 轮校正后 79/81 达标，最终按更新 F/LS 重建达 81/81；未用满 5 轮。
- 可读版：F=11、行距 1.35 固定；允许留白，仅作视觉对照。

## 2. 数学估算（逐页表见 math_estimate.csv）

- 81 页；`F_est>14` **64 页**、`>20` **60 页**、最大 28.35pt；与 t106 64 页不达标一一对应。
- 公式：`F_need = F_base·sqrt(target/generated_base)`；单栏水平文本面积随 F² 增长；行距作为第二自由度。
- 样例：p701 target .486/gen14 .197 → F_est 22.02；p703 .541/.132 → 28.35；p702 .678/.237 → 23.71。

## 6. 残留/权衡

1. 动态 v2 有大字号（最高 28.35pt）与行距 1.55，页面密度贴近源页但字号很大；适合“页同步保真”，不适合普通阅读。可读版 11pt 提供另一极端；中间态可后续按 F 上限/可读性曲线选择。
2. 页同步 1:1 与跨页合并不兼容；p701/p702 保持页边界，合并只在重排版。
3. 填充率用文字 block bbox 并集/页面积，是源/产物同口径的近似；不是墨迹像素覆盖率。
4. F_est 基于 t106 F=14 实测与 F² 假设，个别页行距/标题/图像影响，故用一轮校正；最终 81/81。
5. 图像页/页脚仍沿用 v3；OCR 文字/异体字未改。
