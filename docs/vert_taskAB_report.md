# 竖排行↔槽配对错位修复报告（taskAB）

> 对应缺陷：`build_vert.py` 的 `_align_rows_slots` 行↔槽配对错位 + 槽不按 y 拆分。
> 实现：Claude Code（commit `dfdc102` + `30754eb`），验收与报告：Hermes。
> 基线：tag `v6-baseline`。

---

## 一、两个缺陷与根因

### ① 书眉与页码共用一个槽（p86）

源页 86 的两条 OCR 行 **x 坐标完全相同**：

```
金瓶梅   bbox x1655-1708px  y634-890px     （3 字，源书字距 42.7pt）
四二     bbox x1655-1708px  y2363-2467px   （页码，2 字）
```

槽是**纯 x 带**，不按 y 切分 → 书眉(y317-445pt) 与页码(y1181-1233pt) 之间 **736pt 空白**
仍在同一槽内（日志 `[正文列] p86 19 行 -> 18 槽 (槽 run [5, 46, …])`，槽 0 的 run=5=3+2）。

后果：
- 渲染时按**整个槽**的墨迹范围算步进 → 「梅」被排到第 7 格（应第 3 格），**偏 127.4pt**（实测 25.5 / 127.4）
- 19 行只有 18 槽，多出的行被 DP skip → **页码「四二」完全没渲染**

### ② 列阅读顺序错乱（p513）

OCR 行序（阅读序，x 递减）与产物实际渲染 x：

```
OCR 行 18  x=192.6（页尾）   产物画到 x=766.7（页首）   偏 +574pt
OCR 行 19  x=147.6（页尾）   产物画到 x=576.4          偏 +429pt
```

根因：`_align_rows_slots` 只按「格数/run 数 + 位置先验」做 DP，**不知道行与槽的 y 关系**，
也不知道某行是书眉/页码还是正文；配合 ① 的槽未拆分，配对整体滑移。

## 二、修法（commit `dfdc102` + `30754eb`）

**方案 A —— 槽按 y 拆子槽**（`VERT_AB_YSPLIT`）
槽内对墨迹做 y 投影，若存在 **> 2.5 × 字步进** 的连续空白，且**没有 OCR 行跨越该空白**
（`_row_spans_gap` 挡误拆），则拆成多个子槽。书眉/页码/正文自然分开，行↔槽恢复 1:1。

**方案 B —— 位置口径配对**（`VERT_AB_GEOM`）
行与槽按 x/y 硬约束 + 位置代价配对（`AB_XK=2.0` 列距倍数门限、`AB_YK=1.5` 字步进权重），
两侧可跳过。

**补正（`30754eb`）** —— 实测发现的两个副作用：
1. 行序改按「x 带分组（相邻列心 < 0.4 列距算同带）+ 带内 y 升序」：书眉/页码行心可能差几 pt
   （实测 p87 差 6pt、p509 差 6pt），直接按 x0 降序会把页码排到书眉前面 → 拆槽后页码顶到书眉子槽上。
   **不做 round 分桶**（桶边界上的 6pt 差会落到相邻两桶，实测 p509）。
2. 位置口径下**不再剔除** §1.995 特殊行占用的槽：特殊行已从 `all_rows` 摘掉，对应子槽无行可配会被跳过；
   保留该槽才能接同列**剩余**的行（实测 p375 标题列三行里两行被特殊路径认领，剩下的「第二十二回」
   既无槽可配、又因字高 1.46× 正文被残余列补救的 0.5-1.35× 判据拒绝 → 整行丢失）。

### 开关（全部默认关，`VERT_AB_FIX=1` 才启用）

| env | 默认 | 含义 |
|---|---|---|
| `VERT_AB_FIX` | **0** | 主开关 |
| `VERT_AB_YSPLIT` | 跟随主开关 | 槽按 y 拆子槽 |
| `VERT_AB_ALLSLOTS` | 跟随主开关 | 保留特殊行占用的槽 |

## 四、已知遗留

1. **p513 列 x 仍偏 ~20pt**（约半列距）—— 从 574pt 降到 20pt，量级改善但未归零。
   疑与「标题列大字号抬高 hmax、body 槽只剩 2 个」有关（CC 首轮诊断结论）。
2. **p513 `﹁四六九` 列**：页码与引号混在一列（`x=663.5`）。此现象在 AB_FIX 之前就存在，非本轮引入。
3. **4 页特殊版式缺字**（p563 目录 / p659 回目 / p1171 分册目录 / p1742 古今字对照表）——
   属「列表型版式」问题，需另一轮修复。
4. **PDF 可搜索性**：文本层单字可搜、词组不可搜（逐字 `\put` 架构固有代价），按用户决定暂搁置。
