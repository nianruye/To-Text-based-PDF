# 垂直布局单页探针与 wz3 基准（t377）

## 用法

```bash
/usr/bin/python3 src/tools/vlayout_probe.py --book wz3 --pages 22,24,26 \
    --pdf deliverables/wz3.pdf --coords data/wz3/wz3_linelevel_spotting_coords.json \
    --lines data/wz3/wz3_linelevel_spotting_lines.json --dpi 200 --json /tmp/vl.json
```

输出每页：源/产物行数、按文本配对结果、逐段间距（源/产物/偏差）、未配对源行、产物多出行、最大偏差与 PASS/FAIL(≤3pt)。`--json` 保存同样结构。

## 元素类型

- 章标题：`^第[一二三四五六七八九十百千零0-9]+[章节编篇]`，或行高 > 1.5×本页正文行高中位；
- 书眉：文本在本页相邻页重复，或 y < 页高 10% 且行高 < 1.1×正文中位；
- 正文：其余。

## 已知不一致点

- 书眉：`build_geom.py` 的 `headers`/`_hdr_y` 决定页眉源 y；渲染端页眉仍从页顶附近输出，`_top_vs` 只扣 `_hdr_h` 与 11pt。
- 章标题：`HEAD_GAP` 在标题前后各加一次（L128/L1965/L2151）；标题在 y 方向的上/下间距没有独立源 y 锚点。
- 正文：`BASELINE`/`linespread` 控制正文行距；`_top_vs` 用首正文 y 与 `_hdr_y` 计算页首留白。
- 三者不是独立变量：页眉 y 变化会经 `_top_vs` 同时推首正文，标题又加 `HEAD_GAP`，所以无法只调一段。
