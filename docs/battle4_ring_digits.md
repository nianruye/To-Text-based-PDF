## 2. 方法

### 2.1 序列表约束（主判据，精确复现 27 处违反）

```
seq = 阅读序 OCR number 序列（367 项）
LNDS = 最长非降子序列（bisect 实现） -> 锚点（多数为 OCR 正确项）
对每个非锚点 i：
  lo = 左侧最近锚点的值；hi = 右侧最近锚点的值
  候选 = [lo, hi]（区间为空/无锚 -> 不确定）
  在候选内用「圈内模板相关分」排序；同分取离 OCR 最近者
  候选数 > 3 且模板分差 < 0.03 -> 不确定
```
实测：**27 处全局违反**（与任务书 ≥27 一致），涉及 53 个候选条目（含连续失配段）。

### 2.2 源图墨迹：圈内模板匹配（辅助判据）

- 裁片：以 `source_x/source_y` 为中心、`measure.w/h × 0.31` 为边长（内圆，避开圈环笔画），600dpi 取灰度，
  二值化后 resize 26×26，z-score 归一化。
- 模板自举：取**非锚点**的 `ring_digit` 条目（OCR 与序列一致者），按 `number` 聚类；同号多模板取最大相关。
- 局限（实测）：源页扫描约 **144dpi**（1pt≈2px），圈内数字高 ~15-20px；6/8/9/2 的孔洞/笔画差异在
  归一化后区分度低，模板分多为 0.0-0.4（真匹配与非匹配重叠）。**因此模板分只作辅助排序**，
  不单独作为改字依据；候选数 >3 的宽区间一律标不确定。

## 7. 高清可行性评估（480dpi 样本 p1682）

**样本**：`/opt/test/提取自wz7(12)_00.png`，4700×7225 RGBA，声称 480dpi，内容为 p1682（年表起始页，竖排正文）。

### 7.1 分辨率实测

| 项 | 144dpi 源（source_pdf/wz7.pdf） | 高清样本 | 倍数 |
|---|---|---|---|
| 圈码主块（环+数字） | 35×29 px（fill 0.30，p1682 五个 ⑧/⑨ 实测） | ~65-75 px（同型圆环，fill 0.3-0.5） | **~2.0-2.5×** |
| 圈内数字笔画宽 | 2-3 px | 5-7 px | ~2.5× |
| 圈内数字高（估） | 15-18 px | 32-40 px | ~2.2× |

> 注：样本 4700px 宽对应源页 921.8pt → 有效 ~5.1 px/pt（≈367dpi，非标称 480dpi；若按标称 480dpi 应为 6145px 宽）。
> 不论按 367 还是 480dpi 计，相对 144dpi 源图都有 **2.0-3.3×** 的线性分辨率增益。

### 7.2 易混数字可分性（6/8/9/2）

- 144dpi：圈内数字仅 15-18px 高、笔画 2-3px 宽；`binary_fill_holes` 的孔洞在 6/8/9 上常被抗锯齿糊掉（前轮模板分 0.0-0.4、6↔8/9↔2 不可分的主因）。
- 高清样本：笔画 5-7px，⑧ 的双环结构肉眼可辨（`tmp_vert/battle4/hires_c8_zoom.png`）；6/9 的孔位（上/下）与 2 的无孔形态在 26×26 归一化后仍有 2-3px 的结构差，模板相关分预计从 0.0-0.4 提升到可分区间（需 20-30 个高目标注模板验证，而非本轮自动模板）。
- 结论：**高清扫清除了「数字形状不可分」这一主要瓶颈**；剩余难点是两位数圈（左右分割）与扫描噪点，可用「高定模板 + 序列表约束」处理。

### 7.3 若提供 p1682–p1741 的 480dpi 页：能否支撑 352 处逐项判定？

**可以，条件如下**：
1. **页数与格式**：352 处圈码分布在 **50 页**（p1682–p1741 中的 50 页）；建议提供 **完整的 p1682–p1741 共 60 页**（含相邻页便于坐标对齐），480dpi **整页** PNG/TIFF（不要裁切；裁切样本无法映射 OCR 坐标），单页 ~2-5MB，合计 ~120-300MB。
2. **坐标基准**：整页图需带页码/可判定页序，且与 `data/wz7_full/wz7_full_spotting_coords.json` 的页面几何一致（或提供页面尺寸+扫描偏移）；这样才能把 352 个 `source_x/y` 映射到高清扫。
3. **模板**：从高清扫人工标注 **20-30 个两位数圈**（覆盖 0-9 各数字在十位/个位的位置）做自举模板；再用「模板分 + 年表非降约束」逐项判定，预期可把 352 处全部给出判定+置信（不确定项仍留白）。
4. **成本**：60 页高清扫 + 20-30 个标注 ≈ 1-2 小时人工；识别脚本可在现有 `ring_fix.py` 上改裁切源即可，不需改渲染端。
