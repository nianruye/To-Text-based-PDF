## 2. 根因一：映射方向写反（路径整体休眠）

`nf_fit` 拟合的是 **`OCR = k × 源图 + b`**（尺度 = 相邻间距比中位、截距 = 中位差）；
把 OCR 行搬回源图坐标系必须用**逆映射** `源图 = (OCR − b) / k`。修前该处直接写成 `k × OCR + b`
（同向再作用一次 = 尺度被平方、截距翻倍）—— 映射后的 x 域普遍越出纸幅，被下游
「映射后正文 x 不符」整条拦下：实测 `A0.log` 224/250 页是这个拒因，其中 193 页映射后 x 直接落在纸外。

修后（`nf_ocr2src`，开关 `VERT_NF_FIX_INV`，0 = 修前行为仅作 A/B 对照）：
命中率 2/250 → 8/250（A 行）→ 后续两项修完到 221/250。

## 3. 根因二：梳状简并 —— 残差判据不能选对「整列错位」

`nf_fit_align` 要解决「列带数 ≠ 正文行数」时按标配对的整段漂移（实测 p1207：17 带 vs 16 行，
按标配对累计漂移 3 列 → 拟合出尺度 2.4 的假值）。做法是枚举相对错位 `d ∈ [-3, +3]` 逐一对齐。

**为什么只按残差择优会选错**：竖排书的「行距」（OCR 行心间距）与「列距」（源图墨迹列心间距）是
**同一把梳子的等比放大**——实测 p30 行距 109px = 1.2224 × 列距 89.5px。于是任何「整列错位」的解都能
把残差压到 1-2px（梳状简并），残差对错位**不敏感**。

普查证据（`tmp_vert/taskQ/align_survey.py` → `align_survey.txt`，247 页逐页枚举 7 个错位候选，
每项打印 `k / rms / n / 映射行心域 vs 列心域失配`）：

```
p5   带 6 | d-2:k1.278 rms 0.3 n4 失配 962.6  d-1:k1.289 rms 3.3 n5 失配 476.1
            d+0:k1.290 rms 1.7 n6 失配   1.8 # d+1:k1.284 rms 0.7 n5 失配 483.9
p30  带17 | d-2:k1.222 rms 2.1 n15 失配 351.0  d+0:k1.218 rms 2.6 n17 失配  12.6 #
```
—— 每个候选的 `rms` 都在 0.2-6px（**分不出来**），而「映射后行心域 vs 列心域」失配差 2 个数量级
（1.8 vs 962.6）。实测 245 页里只有 **52 页**「残差最优解 = 位置最优解」；残差最优解的失配中位 **348px ≈ 4 列**。

错位的代价不是纸面上的小误差：伪版心的 x 窗直接由映射后的正文行给出，窗整体搬走会把真列挡在窗外
（实测 p30 右移 2 列 → 左边 2 列不在窗内 → 3 行无处配位 → **整页少 88 字**）。

**修法**（`NF_FIT_ALIGN_POS`，0 = 修前行为仅 A/B 对照）：择优键改为
`(映射后行心域两端失配之和, 残差中位, −配对数)` —— 绝对位置优先，残差只作同分次序。
命中率 8/250 → 145/250。

## 4. 根因三：标定落地时的窗缘与列带口径（收尾到 88.4%）

标定结果落到本页时还有两处口径差（`NF_FIT_LAND` / `NF_FIT_PAD`，0 = 修前行为）：

1. **窗要外扩一个列距**：窗 = 标定后正文行盒并集，但「行盒并集」不是「墨迹列并集」——边界列会
   探出窗缘（实测 p254 左端列 43.0-59.0 在行盒窗外 14.6pt），不外扩则整列检不出 → 行多槽少 →
   整列不渲染（p254 少 95 字 / p130 少 84 字）。
2. **列带重算要与标定前同口径**（检测 + 短列补齐）：只重算检测会白丢「补齐」出来的列
   （实测 p254：标定前 原带 15 + 补 1 = 16，只重算 → 14）。
3. **撑不起伪槽格就弃用本页标定**（退回未标定坐标系）：否则标定后的坐标会把整页建排搞崩。

命中率 145/250 → 222/250（加护栏后 221/250 —— 有 1 页的标定被护栏正确弃用）。

## 5. 遗留：p24「重试口径 vs 兜底口径」择优

`NF_RETRY_BEST`（0 = 修前行为仅 A/B 对照）：原实现里「行墨迹下限口径」的重试**一旦适配就无条件采纳**；
但该页若不采纳重试，实际会走 §1.99 框内兜底（同样是源图坐标系的绝对定位，两口径可比）。
改为**各算一次取渲染字数多者**（字数口径 = `len(puts)`，`col_puts` 与 `_nf_rescue_rows` 都是「一字符一 `\put`」；
只与兜底口径比，不与 v2 流式比 —— 流式放弃列位、字数天然最高，拿它当基准等于关掉整个重试机制）。

实测 p24（2 列大幅题字页）：重试口径 **82 字** vs 兜底口径 **103 字** → 采纳兜底。
该页字数 82 → **123**（并随 taskP2 的短列补救一起进 300 页验收）。

## 7. 开关（全部默认开 = 修后行为；关掉 = 逐位复现修前）

| env | 作用 | 关闭后果 |
|---|---|---|
| `VERT_NF_FIX_INV=0` | OCR→源图映射改回同向（修前 bug） | 命中率回落到 3.2% |
| `VERT_NF_FIT_ALIGN_POS=0` | 择优改回「纯残差」 | 命中率回落到 58%，190/245 页选错列相位 |
| `VERT_NF_FIT_LAND=0` | 标定落地改回「窗不外扩 + 只重算检测」 | 命中率回落约 1 页 + 边界列丢失 |
| `VERT_NF_RETRY_BEST=0` | 重试口径一旦适配就采纳 | p24 回到 82 字 |
| `VERT_NF_FIT_PAD` | 窗的外扩量（列距倍数，默认 1.0） | 调小会重新丢边界列 |
