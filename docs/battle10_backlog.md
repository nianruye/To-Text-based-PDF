## 3. 页边界合法性核对（阅读序）

阅读序 = 页升序、页内列 x 降序（x 越大越先）。从 fix JSON 的 ring 条目取相邻项：

| 位置 | 前一项 | 本项 | 后一项 | 页内/跨页 |
|---|---|---|---|---|
| p1720 x97.3 | p1720 x163.6=75 | **78** | p1721 x617.6=76 | p1720 **末列**（x 最小） |
| p1721 x617.6 | p1720 x97.3=78 | **76** | p1721 x585.1=76 | p1721 **首列**（x 最大） |
| p1721 x88.8 | p1721 x122.0=77 | **77** | p1723 x578.8=76 | p1721 **末列** |
| p1723 x578.8 | p1721 x88.8=77 | **76** | p1723 x544.2=78 | p1723 **首列** |

- 页内：p1720 75→78（升）；p1721 首 76→76→…→末 77（非降）；p1723 首 76→78（升）。
- 跨页：p1720 末 78 → p1721 首 76（−2）；p1721 末 77 → p1723 首 76（−1）。两处都发生在**页边界**，
  且下一页首项在页内继续上升 —— 与「年表在页边界回退/分段重置」一致，不是 OCR 把 78 读成 76、77 读成 76。
- 结论：两处保留原值；无需改判/落库。
