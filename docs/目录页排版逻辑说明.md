# 目录页排版逻辑说明

**更新日期**：2026-06-19
**适用脚本**：`build_pdf_v13.py`
**核心目标**：把 OCR 拆散的目录条目（文本 + 页码）重新配对，还原源文档的"文本……页码"三段式排版

---

## 一、问题背景

PaddleOCR-VL 把每条目录的**文本部分**和**页码**识别成两条独立的 spotting line：

```
OCR 原始数据（key=9）：
  文本列（x≈110-290）：          页码列（x≈1122）：
  导论                            11
  第一部分                        13
  历史考证（第一部分的续行）        14
  第一章...                        18
  ...
```

若直接逐行渲染，会导致：
- 页码丢失（只有少数 inline 条目如 `…20` 能正确匹配）
- 引导点（dotfill）缺失
- 缩进层级消失
- 孤立页码行散落

**解决思路**：用 Y 坐标把同一物理行的文本和页码重新配对。

---

## 二、目录页检测（`is_toc_page_by_ocr`）

**位置**：`build_pdf_v13.py:216`

目录条目短、宽度不足，会被 `is_content_page`（要求全宽行 ≥9 条）误判为封面过滤。因此在 `content_page_keys` 计算前，先用 OCR 数据识别目录页。

### 判定条件（满足任一即认定目录页）

| 条件 | 判据 | 依据 |
|---|---|---|
| 含"目录"标题 | 页面任意行含"目录"二字 | 最可靠 |
| 右列页码 | 右列（x > 页宽×70%）纯数字行 ≥5 条 | 成列页码是目录特征 |
| inline 条目 | 含 `…`/`.`+数字结尾的行 ≥5 条 | 如 `第二部分研究状况…57` |

### 输出

```python
toc_page_keys = [k for k in sorted(spot_lines.keys(), key=int) if is_toc_page_by_ocr(k)]
```

PDF3 结果：`toc_page_keys = ['9', '10', '11']`（3 页目录）

## 三、行分组配对（`group_toc_rows`）

**位置**：`build_pdf_v13.py:1022`

把目录页所有 line 按 Y 坐标分组，合并文本+页码。返回 `[(indent_em, text, page_num, y_center), ...]`

### 3.1 收集元数据

每条 line 记录 `(y_center, x_left, text, is_page_num, is_inline)`，按 y_center 排序（阅读顺序）。

- `is_page_num`：纯数字 + x_left > 页宽×70%（右列页码）
- `is_inline`：文本含 `[…·\.]+\d+` 结尾（如 `概况……25`）

### 3.2 三分类处理

| 类别 | 处理方式 |
|---|---|
| **页码行** | 收集到 `page_nums` 列表（Y 顺序） |
| **inline 条目** | 直接正则提取文本和页码，加入结果 |
| **文本行** | 收集到 `text_entries`，待续行合并后配对 |

### 3.3 续行合并（基于 X 坐标）

连续文本行中，若某行满足：
- x_left 明显更大（比前一行多 `INDENT_THRESHOLD_PX × 0.8`，即更缩进）
- Y 相近（与前一行差 < 60px）

→ 判定为**续行**，合并进当前条目。

**示例**：
```
第一章《社会主义从空想到科学的发展》写作的时代背景   (x=148, 主行)
及其问题意识                                         (x=284, 更缩进 → 续行)
→ 合并为一条：第一章《...》写作的时代背景及其问题意识
```

### 3.4 顺序配对

合并后的文本条目按 Y 排序，与页码列按 Y 排序后**一一对应**：

```
text_entries[i]  ↔  page_nums[i]
导论             ↔  11
第一部分历史考证  ↔  13
第一章...        ↔  14
...
```

> **配对依据**：OCR 保持阅读顺序，文本条目和页码在 Y 顺序上一一对应。
> （注：OCR 的页码 bounding box Y 坐标与文本有偏移，故用顺序配对而非就近匹配）

### 3.5 缩进层级

按 x_left 与 `BODY_LEFT`（正文左边距）的差值推导：

| 差值 | 缩进层级 | 渲染缩进 |
|---|---|---|
| < `INDENT_THRESHOLD_PX × 0.5` | 0 级（顶格） | 0em |
| `× 0.5` ~ `× 1.5` | 1 级 | 2em |
| `× 1.5` ~ `× 2.5` | 2 级 | 4em |
| > `× 2.5` | 3 级（续行） | 6em |

## 四、渲染（主循环 line 1134）

目录页跳过正常渲染流程，走专用分支。

### 4.1 渲染结构

```latex
% ── 标题（正确限定 centering 作用域，用大括号包裹）──
{\centering {\CJKfamily{heiti} 目录}\par}
\vspace{12pt}

% ── 每个条目 ──
{\rightskip=2.5em                          % 预留页码右侧空间
 \noindent \hspace*{Nem} 文本              % 缩进 + 文本
 \dotfill\nobreak 页码\par}                % 引导点 + 页码

% ── 末尾分页符 ──
\par\newpage                                % 与正常页一致，启动下一页
```

### 4.2 关键设计点（踩坑修复记录）

| 设计点 | 原因 |
|---|---|
| `\centering` 用 `{\centering ...}` 大括号包裹 | 未包裹会导致居中模式持续污染后续所有条目，破坏 `\dotfill`/`\par` 行为 |
| 每条目加 `\noindent` | 保证段落模式，`\par` 正常换行 |
| `\rightskip=2.5em` 预留空间 | 超长条目（如 `一澄清...有害影响`27字）会占满整行溢出，导致页码被挤到下一行且 dotfill 塌缩；预留空间让文本提前换行 |
| 页码用 `\dotfill\nobreak NUM`（去 makebox） | makebox 在孤立行行为异常 |
| 末尾 `\par\newpage`（不是开头 prepend） | 正常页面是末尾加 `\par\newpage` 启动下一页；目录页只在开头 prepend 会导致**最后一页目录无分页符**，后续正文流入目录页 |

### 4.3 渲染优先级

目录页判定在主循环最前（duplicate 检查之后）：

```python
if key in toc_page_keys:
    # 目录专用渲染
    ...
    all_tex.append(''.join(result) + '\\par\\newpage')
    continue   # 跳过正常渲染
```

## 六、已知局限与后续优化

| 局限 | 影响 | 可能改进 |
|---|---|---|
| 顺序配对偶有错位 | 个别页码配错（如二法文版 25 应为 27） | 改用 Y 坐标就近匹配（需校准 OCR 页码 Y 偏移） |
