## 2. 融合算法（`tmp_vert/battle18/fuse.py`）

1. **text_B**：B 页内行按原顺序（列右→左）拼接，去空白、统一竖排标点（﹁→「 等）；**清空对** `（）/〔〕/︵︶/︹︺`、去重 `「「/」」`。
2. **text_A**：A 的 `parsing_res_list` 块按 layout 顺序拼 text；同样归一化。
3. **字符级对齐**：去掉全部标点后对 A_body/B_body 做 `difflib.SequenceMatcher`，得 A_body 下标 → B_body 下标映射。
4. **只移植标点**：扫描 A 的 `「`/`」` 与 `〔名〕`（以及 `「名」`/`（名）` 形式——A 常把曲牌名读成引号/括号）；对每个 token 找其后（或前）最近的可映射 body 字符作为锚点，映射到 B 的位置：
   - 开引号：B 该位若为 `一`（OCR 误读）→ **替换** 为 `「`，否则插入 `「`；
   - 闭引号：B 该位已有 `」` 跳过，否则插入 `」`；
   - `〔名〕`：若 B 有 `「名」`/`（名）`/裸名 → 换成 `〔名〕`（名表 = 源文 7 名 ∪ A 的括号/引号/括号名）；不重复插。
5. **字符与顺序始终用 B**；A 仅贡献标点决策。

## 6. 结论：是否推全书

- **推前必须补两条规则**（否则残留会带入全书）：
  1. **闭号推断**：A 自身缺闭号（每页 1–2 处），融合无解；需按「`XX唱：`/章节尾/段落尾」补 `」`（源图墨迹可校验）。
  2. **字符级仲裁**：B 的字符错误（如 `思病`/`患病`、`澆瀉`/`澆澆`）融合不会修；建议用 A 的正文（LCS 1.000）做**同位置字符比对**，差异处回源图墨迹择优（或采用 A 字符 + B 的 poly 定位）。
