## ② 目标：用户最初报的 p48（截图圈了第四十九回 / 第五十回两列）

### 源书 p48 的真实结构（我已逐行核实，这是本次重构的关键事实）

p48 是**表格式目录**：每个回占**一个 x 位置、三个 y 行**。不是普通竖排。

```
回次行    y 235.7-379.4:  第四十九回        第五十回        第五十一回
回目上句  y 405.2-635.1:  西門慶迎請宋巡按  琴童潛聽燕鶯歡  月娘聽演金剛科
回目下句  y 636.6-893.8:  永福餞行遇胡僧    玳安嬉遊蝴蝶巷  桂姐躲住西門宅
       x 中心:            622.9-624.8       583.7-584.6     543.9-544.4
```

即**同一个 x 上有三块彼此独立的文字，靠 y 分开**。全书 48 个 OCR 行 = 16 个回 x 3 层。

### 我们现在的错误产物（v8 实测）

```
产物 x610.6: 「第四十九回西門慶迎請宋巡按」   <- 回次 + 上句 被合并成一列（13 字）
产物 x588.9: 「玳安嬉遊蝴蝶巷」              <- 第五十回的下句，被拆成独立列，x 偏到 588.9
产物 x569.7: 「第五十回琴童潛聽燕鶯歡」        <- 回次 + 上句 又合并成一列（11 字）
```

两个错误：
1. **同列的多层被合并**（回次 + 上句 -> 一列）
2. **被拆出来的层没落回原列**（应回 x583.7，实际 588.9）-> 夹在 610.6 与 569.7 之间 -> 视觉上字压字

审计工具报告：`p48 列间重合 x_overlap=10.68pt y_overlap=190.88pt`，`source_faithful=false`。

## ③ 根因（沿用 docs/vert_taskCH_brief.md 的分析，已被 p48 证实）

```
⑤ nf_join_rows(L2023) 先把三层合并成一行
⑦ _toc 判据(L3594) 要求 R >= 1.3*C —— 合并后 R≈C, 判据永不成立 -> 目录专用路径走不到
⑧⑨ 只能靠「全列做槽」(L3641) + 「补列」(L3664) 两个补丁硬凑, 两个补丁互不知道对方
   -> 修好 p54 就弄坏 p563
```

**目录的特殊性散在 5 个步骤里各打一个补丁，必须收拢成一个分支。**

## ④ 修法

1. **目录判定提到 `nf_join_rows` 之前**（L2023 之前）。判据不依赖行数比，用：
   - 同 x 带内 **≥2 行的占比**（目录页每列 2-3 层，正文页每列 1 层）
   - 且这些多层的**字号显著小于**本页正文
   - 且行高/列距比值落在「小字行」区间
   **先写探针**打印各分量在全书的实际分布，再定阈值（见「硬性作业规范」）。

2. **命中后走独立路径：按 (x 带, y 层) 二维配对**
   - 行按 x 归列（容差 = 列距的 30%）
   - 列内按 y 归层（层由行直接算出，**不再走 `_split_slot_y` L2867**）
   - 渲染时每层独立 `col_puts`，同列三层共用同一 x

3. **删除两个补丁**：L3641 `[全列做槽]`、L3664 `[补列]`。
   删掉后 p54 / p563 必须仍正确 —— **这是本次重构的核心验收**。

4. **普通正文页一字不动**：未命中目录判定的页，`VERT_NF_SLOT_ANCHOR` 路径保持 R3 行为。
