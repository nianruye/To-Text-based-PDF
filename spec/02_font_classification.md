# Spec: 字号分类 + 序号位置识别

## 目标
区分正文/注释/前言三类页面，各自字号；用序号位置（行首 vs 行中）辅助判别。

## 背景
- layout JSON 不区分正文/注释（都标 text）
- 行高判不准（前言行高波动、p5/p6 行高不同但字号同）
- OCR 识〔X〕为 [X]，需统一匹配

## 方案
### 三类字号
- **正文**（BODY_FONT）：满行26字 -> 18pt
- **注释**（NOTE_FONT）：满行32字 -> 14.7pt
- **前言**（满行27-31）：按满行算（470/cw）

### 序号位置识别
- 行首〔X〕/[X]（>=2个）-> 注释页（NOTE_FONT）
- 行中 $^{[X]}$（>=5个）-> 正文页（BODY_FONT）
- 前言（无序号特征）-> 按满行算
- 行高判兜底

### [X] 算字数
- cw 计算时剥 $ ^{} $ LaTeX 语法，保留 [X]（校注标记占版心宽）

## 输入
- spotting 行数据（文字 + x0 + 行高）
- 满行字数（cw）

## 输出
- 每页 PF（正文字号）
- _page_seq_start[key]（行首序号数）
- _page_seq_mid[key]（行中标记数）
- _page_cw[key]（满行字数，保留 [X]）

## 约束
- 序号位置优先于前言/行高判
- [X] 和〔X〕都匹配序号正则
- 不影响目录页（_npairs>=5 跳过）

## 测试点
- p11 正文 BODY_FONT 17.3pt
- p15 注释 NOTE_FONT 14.6pt
- p5 前言 按满行 16.1pt
- p14 正文（有校注标记，非注释页）
