# 11. 短列检出（§1.976）+ 标点占格口径（§1.0a0）+ 引號修剪（§1.98）

状态：**implemented**（taskS，2026-10-16；wz7 300 页 `verify_vert` PASS、wz6 零回归）
完整报告：`docs/vert_wz7_linegap_report.md`。测试：`src/test/unit/test_vert_taskS.py`（22 项）。

## 目标

1. **短列不得被静默丢弃**：源书用「又曰：」这类 3 字短列做段落分隔，OCR 有该行、产物整列丢失
   （实测 wz7 源页 354：12 行对 10 槽，丢 2 列 6 字；全书 27 页受影响，最多 +43 字）。
2. **列内空隙（gap）按本书标定**：现状格口径（标点挤格不占格）是 wz6 排印习惯，
   在 wz7 上造成「字与标点重叠 / 标点后字被隔开 / 空格大小不一」。

## 输入 / 输出

* 输入：源图墨迹（`_nf_ink`，逐页 Otsu + 去印刷线）、伪版心窗、OCR 行（标定后源图坐标系）、
  已检墨迹列带、页内列距与列带参照字高。
* 输出：① 补出的短列列带 `(x0, x1, 字高)` → 进伪槽格（`nf_edges` → `_slots_of_edges`）；
  ② 标量 `PUNCT_CELL ∈ {0,1}`（标点是否独占一格）；③ 修剪后的槽顶/槽底（字列顶/字列底）。

## 约束（判据与不变量）

| 项 | 判据 | 值 | 依据 |
|---|---|---|---|
| 短列候选 | 版心内**非长行**（`(y1-y0) < LONG_H_FRAC×页高`）+ 单行 + 有文本 + x/y 中心在版心内 | — | 与 `nf_short_cols` 同一批行（OCR 有真实文本） |
| 窗内覆盖率（候选生成） | `≥ NF_SB_COV` | 0.05 | 实测短列 0.14（窗 = OCR 行 y 带 ±1.5 字步进，夹回版心） |
| 墨迹密度（挡碎墨/噪点） | `≥ NF_SB_DEN` | 0.12 | 实测短列 0.41；单个 5×5 噪点斑 0.01 |
| 字证据（挡非文字墨） | 整版心量该带 run ≥ 2 且字 run 高 ∈ `[0.5,1.35] × 本页列带参照字高` | — | 参照 = 已检列带（nr ≥ 5）的 `_big_hm` 中位；与 `_ok_stat` 同口径 |
| 不与已用列带重叠 | 与 `bands`/本次已收短列 x 区间不重叠 | — | 不叠字 |
| 字高口径 | `_big_hm` = run 高的 **75 分位** | — | 排标点碎片（「又曰：」4 run 中 2 条是 4.5pt 冒号点，全中位 11.75 → 字号偏小 40%）与并字长 run（萬萬并字 48pt → 「最大 run 比例」口径会把字高算成 48pt） |
| 标点占格标定 | `估计 = (N格 − (字数−标点数)) / 标点数` 的中位 ≥ 0.5 | PUNCT_CELL=1 | 实测 wz7 193 槽 → 0.990；wz6 178 槽 → −0.113（判 0） |
| 引號修剪 | 三条同时成立：run 高 < 0.6×字高、与邻字 run 间隙 < 0.5×步进、邻 run 是字 run 且文本首/末字不是 `PUNCT_HANG` | — | 实测诗引號 9.5pt/间隙 7pt；标点本来就小，靠第三条不误剔 |
| 短列与墨带 | §1.976 补出的槽**不进** `band_t/band_b` 的取中位样本 | — | 否则「上半/下半」下标挪一格 → 墨带底 1101→961 → 所有满列被判短列 |
| 短列与标定 | 短列**不进** `_nf_fix_page` 的「列带 ↔ 行」配对 | — | 混进 3 字列会把 x 尺度拟成 1.416（真值 1.332）→ 整页掉回未标定坐标系 |

## 测试点

1. `n_cells`/`char_cells` 在 `PUNCT_CELL` 两口径下自洽（且 `n_cells == max(char_cells)+1`）；
2. `_big_hm` 排标点碎片 / 排并字长 run / 长列上与中位等价；
3. `_trim_marks`：首引號剔、尾引號剔、末字是标点不剔、冒号点不剔、分离笔画小字不剔；
4. `_sb_band`：3 字短列检出（位置 = 窗内墨迹实测）、噪点斑拒、印刷竖线拒、与已用带重叠拒；
5. `_sb_pitch` / `_sb_ref_hm` 的口径与兜底。

## 验收（taskS 实测）

* key54（源页 354）：产物 229 字 = OCR 229 字（基线 223），两个 `又曰：` 落位 Δ ≤ 2pt；
  整页墨迹重合率（源墨被产物覆盖）±2px 48.0% → **68.3%**、±4px 62.1% → **84.8%**。
* wz7 300 页 `verify_vert` **PASS**（300=300 / 字符量 98.2% → **98.4%** / 越界 0 / 整页丢失 0）。
* wz6 `vert.tex` **逐字节相同** + `verify_vert` PASS（PUNCT_CELL 标定为 0 = 既有口径）。

## 开关（回退）

`VERT_PUNCT_CELL`（0 = 挤格口径）、`VERT_NF_SB_OWN=0`（关短列检出）、
`VERT_NF_SB_COV/DEN/PADX/PADY`（短列三条判据）、`VERT_GAP=0`（关空隙检测，仅对照）。
