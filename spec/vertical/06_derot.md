**状态**：implemented（wz6 实测命中 1 页；数据驱动，不硬编码页号）

**关联**：commit `ff4b5b7`（p159 整页丢失修复）
**相关工具**：`src/tools/test_ocr_orientation.py`（OCR 侧参数对比试验，见本文末）

## 目标

某些页 **OCR 服务返回的坐标落在「整页旋转 90°」的坐标系**里（不是页坐标系）→
该页行框全部过不了 `is_body_col` 被丢弃 → 重建 PDF **整页空白**。
本机制在渲染该页时把旋转坐标系还原回页坐标系（事后修补），源头上可另用 OCR 参数根治（见末节）。

## 背景：现象与根因（实测，非猜测）

**样本 p159**（key `158`）：
- 源书是竖排页（版框内 4 列小字 35/11/35/24 字，版框整体右移、左缘为订口条），
  但 OCR 把整页当**横排**识别，返回的坐标落在「页逆时针转 90°」的坐标系里；
- **行框全是「横看」**：宽 1833px × 高 47px（竖排正文列必纵长，高/宽 ≈ 20）；
- **坐标越界**：页宽方向的值最大 2411px，远超页宽 1191px（= 2 × 595.3pt）；
- **后果**：6 行全部过不了 `is_body_col`（`h < 300`）被丢弃；
  `第二卷\n抗日戰爭時期` 行另有含 `\n` 排除；`三五` 行虽被页码逻辑认领（并已纠正成三三五），
  但 `ink_extent` 的窗口按原始 bbox 画、落在源图空白处 → 无墨迹可测 → 不渲染。**整页空白**。

**印证方向**：按逆时针 90° 还原后，行框正落在源图墨迹字列上（残差 1.7px；顺时针方案 400px，
方向判别由此确定），且行文连读通顺：`…乘機反攻拿 | 破崙軍僅剩…逃去 | …繩捆索綁形同 | 囚犯略為…代替`。

## 方案（数据驱动，不硬编码页号/常数）

### 1. 触发判据（L747-749）

- 页内「横看」行（宽 > 300px 且宽 > 2.5 × 高）≥ `DEROT_MIN_ROWS`(3) 条；
- **且该页所有长行（宽 > 300px）都横看**（混合页如 p74「图例行 + 正文列」不触发）；
- 另有 `DEROT_ON`（`VERT_DEROT=0` 关闭）与 `src_doc` 存在性门控。

### 2. 标定（`_ink_char_cols` + 两个方向的配对最小二乘）

- **字列**：源图墨迹字级组件（15-130px 见方、面积 ≥ 60px）按 **x 中心聚类**得竖向「字列」
  （同 `note_cols` 手法）；只留竖向列（高 > 2.5 × 宽）—— 据此把「本来就不是竖排」的页
  （如末页水印页）挡在标定之外；少于 3 列放弃。
- **配对**：OCR 行按 y′ 中心升序，与字列按序配对：
  - **逆时针**：字列按 x **降序**配，`x = kx·y′ + bx`；
  - **顺时针**：字列按 x 升序配；
  - 取**残差小者**定方向（实测 p159：逆时针 rms 1.7px / 顺时针 400px）。
- **闸门**：`rms ≤ DEROT_RMS_MAX`(30px)（超限判「不是旋转坐标系页」，返回 None）；
  `0.5 ≤ |kx| ≤ 1.5`（同页坐标比例应 ≈ 1）。

### 3. 文本方向（行高）标定（L764-780）

另用「**中位比例 + 中位截距**」标定 `y = ky·x′ + by`：OCR 盒沿文本方向松紧不一（实测盒长比墨迹长 10%-30%），
最小二乘会被带偏，中位对松紧/离群点鲁棒。只取长行（span ≥ 100px）且比例 ∈ [0.2, 2.0] 的配对
（页码行等与长列同列，比例离谱，弃）。实测：`kx=-0.934 bx=1151.6 rms=3.41px / ky=0.780 by=273.5`。

### 4. 还原与作用域（L781-788）

- 每行：中心 `x = kx·y′+bx`、`y = ky·x′+by`；宽/高按同一尺度（`|kx|`/`|ky|`）换算；
- **只在渲染该页时套用**（L897-898：`all_rows[k] = dr`）——全局拟合（字号/列距/右缘）、
  版框检测、页码序列一律仍用原始行，**不影响其它 230 页的任何输出**。

## 输入 / 输出

- **输入**：该页 OCR 行 `(x0,x1,y0,y1,text)`（px，2x）+ 源页灰度图
- **输出**：还原后的行列表（同结构）或 None；stdout 日志
  `[旋转页修正] p159 判定逆时针(配 6 行 x 6 字列) kx.. bx.. rms.. ky.. by..`

## 约束

1. 不硬编码页号、方向、比例常数：方向由残差竞争决定，标定全来自本页墨迹；
2. 只影响触发页；未触发页零行为变化；
3. 依赖 `scipy.ndimage`（连通组件）+ fitz（源页灰度）。

## 验收方法

1. **渲染图 + 文本提取双重复核**：输出 p159 现含 4 列正文（阅读序正确）+ 边注「第二卷 抗日戰爭時期」
   + 页码「三三五」（OCR 误读的「三五」经 [05](05_pagenum_sequence.md) 序列纠正）；
2. 列位/字号对照源书：列 x 483.8-563.3（源 486-560）、字号 19.5-19.9pt（源 ≈20.5pt）、
   页码/边注按源墨迹定位 x 23.9-40.2（源 24.5-34.5）；
3. **不得误触发**：全书只 p159 命中（正常竖排页长行必纵长，混合页因「所有长行都横看」判据不触发）；
4. `verify_vert.py`：该页字符量不再是 0（117 字），全书无非预期差异页。

## 测试点

- p159 输出 0 字 → 117 字（修复前/后）
- 未触发页逐 span 与修复前一致（除 p22/p32/p36 版框、p194 列距等其它修复项）
- `VERT_DEROT=0` 时行为回退到「整页空白」（对照用）
