## 1. 目标（用户反馈）

① 源书列首的竖排引號 ﹁ 被 OCR 读成汉字「一」（用户「这个不是一」）；
② 用户所感「﹁ 占字格导致不齐」；③ 目录页阅读性差（回次与回目挤成一列）。

## 2. 契约 A：引號误识判别（§1.997 `nf_fix_quotes`）

- **输入**：无版框伪槽格页（`m['g']['virtual']`）的 OCR 行文本 + 源图墨迹。
- **输出**：1:1 字符替换 `一 -> 「/」`（字数/格数/列位/字距/字号**全不变**），逐处记录落盘 `qfix.json`。
- **判据（只用源图墨迹形状；相对本列字高 h_char，不写绝对 pt）**：
  1. 墨高 ≥ `QFIX_MIN_RATIO`(0.25)×h_char（汉字「一」只有笔画厚，达不到）；
  2. 墨宽 ≥ `QFIX_W_RATIO`(0.45)×h_char（排标点/碎墨）；
  3. 竖/横笔位置：`vpos ≥ 0.70 且 hpos ≤ 0.40` → 开口 ﹁；`vpos ≤ 0.30 且 hpos ≥ 0.60` → 闭口 ﹂；
  4. 墨高 ≤ `QFIX_MAX_RATIO`(0.60)×h_char（排"相邻字墨相碰"并成的长 run）；
  5. **位置闸门**：墨块顶相对"本字渲染格顶"的格内偏移 ∈ [`QFIX_POS_LO`, `QFIX_POS_HI`] = [-0.25, 0.85] 步进
     （渲染端按格号摆放，只有落在本字格内才等于"改的是本格字形"）。
- **定位**：复用渲染端同一套 `fit_gaps` DP 对齐（`_align` 只读旁路，不传则逐位同旧实现）；
  与渲染端两处有意不同：不套 `_trim_marks`（判别目标就是列首那条墨）、用全高 run 表（汉字「一」墨高 < 4pt 碎片下限）。
- **保守性原则**：任一条不成立 -> **不改**（宁少改不误改）；有版框书（wz6 类）**一字不改**。
- **不变量**：`len(t)` 不变、`n_cells(t)` 不变（「一/「/」 都不在 `PUNCT_HANG`）→ 布局输入不变。

## 3. 契约 B：引號占格口径（§1.976 `_trim_marks` ④）

- **源书实测（wz7，39 页全部列）**：引號小墨在**本格内偏下**（墨顶 = 本格顶 + 0.3-0.4 步进），下一字在下一格
  （Δnext 中位 0.72 格），与标点（0.68）**同族** → **引號占整格**。本项目 `PUNCT_HANG` 不含引號 = 一致。
- **契约**：文本首/末字是引號（`QFIX_QFAM` = 「」『』）时，列首/列尾的小墨**不剔**（那是该引號自己的墨）；
  文本首/末字是其它字（含 OCR 把引號读丢的情形）时，判据与 taskS 完全相同（不剔「一二三」这类本身墨小的正文字）。
- **影响面**：只无版框伪槽格路径（`_trim_marks` 仅 `page_puts` 调用）；wz6 不在影响面内（实测 `vert.tex` 逐字节相同）。

## 4. 契约 C：目录页（残余列补救路径 + 开关）

- **补救列带补 `runs`**：`_nf_rescue_rows` 落位时给槽带 `_slot_runs` 表 -> `col_puts` 的 `fit_gaps` 可检出列内空档。
- **补救 y 统计窗**：伪版心 y 范围 ∪ **该行自带 OCR y 带**（否则版心之上的短行被截顶）。
- **适配判据**：`VERT_TOC_RESCUE_OK`（默认 **0**）= 1 时，`ok` 追加 `len(pairs)+len(rescued) ≥ 0.8×R`。
  **默认关的理由**：开启后实测 4 页各少 10-30 字（补救"有墨才画" vs v2 流式按 OCR 行盒全画）——
  宁可版式差也不丢字。默认值下输出与旧实现**逐字节等价**（实测与基线文本层 diff 只有引號替换）。

## 7. 契约 D：目录页独立分支（taskCH / taskCH2）

- **判定**：`nf_toc_shape` 用**原始 OCR 行**（`nf_join_rows` / 列内合并之前）的列内分层形态，不看行数比
  （列内 >=2 层 + 首层 <=6 字且短于其余层 + 其余层字数中位 <=20 + 形态列 >=6 + 首层 y 顶跨 <= max(3% 页高, 40pt)）。
  命中 -> `g['toc']=True`、`g['toc_rows']=原始行`；`page_puts` 开头直接走 `_toc_puts`，
  不再进入 `_dual` / `_split_slot_y` / 槽补丁。
- **渲染**：行按 x 心归列（容差 `0.30 x 列距`），列内按 y 升序 = 层；每层一个**自带 OCR y 跨度**的槽，
  同列多层共用同一 x（p48 表格式目录：16 回 x 3 层）。
- **标题边界（taskCH2）**：真标题（「金瓶梅詞話總目錄」「詞話第二冊目錄」）仍由 §1.995 标题署名路径渲染；
  但**目录网格行**（本行所在 x 带内 >=2 行，`_toc_grid_layers`）不得被标题路径认领 —— 否则该层被
  `_toc_puts` 剔除后画在墨带中心、不回原列（实测 p48「玳安嬉遊蝴蝶巷」x588.9 vs 应 583.7 -> 字压字）。
  页边行（页码/书眉）交 `special_tex`。
- **补丁处置**：「补列」已删除；「全列做槽」不再服务目录页（目录页走不到），保留为**非目录页**的

- **不变量**：未命中 `nf_toc_shape` 的页不进入新护栏（`g['toc']` 为假），普通正文路径不变；
  wz6 有版框、不走 NF 路径，`vert.tex` 逐字节相同。
