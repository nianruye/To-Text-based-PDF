# 04 版框线（双边外框 + 界行线）

**状态**：implemented（wz6：228/231 页画出；3 页无框 = 封面/前附/水印页，源书本就无框）
**实现锚点**：`src/pipelines/build_vert.py` L405-425（常量）、L427-434（`_runs`）、L436-500（`_grid_fit`）、
L502-510（`_bar_px`）、L512-651（`frame_geom`）、L653-680（`frame_tex`）
**关联**：commit `ff4b5b7`（版框线 + 淡线栅格兜底）；检测实验脚本 `tmp_vert/frame_detect2.py` / `line_scan.py`

## 目标

还原源书的印版版框：**双边外框**（外粗线 + 空隙 + 内细线）+ **界行线**（列间细竖线），
并按源书墨迹实测位置绘制（不套用统一模板）。

## 背景（源书实测结论）

- **双边**：外粗线 2.5-4.5pt + 空隙 2.5-3.5pt + 内细线 0.5-1.5pt；内框高 799.0pt
  （min 796.5 / max 801.0，**印版常数**）。
- 内框左右两条竖线**同时是首/末界行线**；界行线 = 列间 1pt 细竖线，起止同内框上下线；
  列距 43.5pt（内框宽 521.8pt = 12 列）。
- **订口侧（装订边）只剩内细线**：外粗线被装订边/扫描裁切吞掉（实测每页 L 或 R 必有一侧缺，
  缺失侧**逐页交替**）。
- **横线横跨整幅纸面**到订口页边（书眉/页码带被上下横线包住）→ 横线按源墨迹实测 x 跨度画。
- 书眉/页码在**框外**订口页边内（版心），与框内正文列无关。

## 检测判据（都带实测依据）

| 元素 | 判据 | 源书实测分布 |
|---|---|---|
| 横线 | 行墨占比 > `V_H_COV`(0.45) 且墨迹横跨 > 0.55 纸宽；上下各取「外粗+内细」一对（7.5pt 内相邻两组配对，厚者为外） | 横线 0.58-0.99；正文行 ≤ 0.30 |
| 竖线 | 版心 y 区间内列墨占比 > `V_LINE_COV`(0.55) | 细线 0.70-0.99；正文列 < 0.55 |
| 外粗线 | 组厚 ∈ [`V_THICK_MIN` 2.4, `V_THICK_MAX` 6.5]pt 且落在内细线外侧 12pt 内 | 外框 2.5-4.5pt；内框/界行 0.5-1.5pt |
| 剔除 | 扫描黑边（`_bar_px`：两端累计墨占比 > 0.80 的列区宽度）、贴页缘 5pt 内的假线（p172/p210 实测有 cov 0.55-0.75 的裁切暗边）、厚度 > 6.5pt 的粗条 | — |
| 结构闭合 | 有外粗线的一侧 → 内线 = 粗线内侧缘 ± 间隙；另一侧补「横线端头 − 粗线厚 − 间隙」；都缺则用实测最外细线；再用「列数 × 列距」（`N_COL_FRAME=12`，印版常数）校验修正 | 内框宽 519.0-524.4pt |

**合理性闸门**：内框高 ∈ [700, 900]pt、内框宽 ∈ [400, 640]pt、跨度应为列距的整数倍
（偏离 > 0.22 列 → 判为检测失败返回 None，该页不画）。

**渲染**：eso-pic **带星版** `\AddToShipoutPictureFG*` + `\put` + `\rule`
（探针 `tmp_vert/probe_rule.py` 实测：tate 下 `\rule` 尺寸**不旋转**、`\put` 参考点 = rule 左下角、
原点 = 页真左下角，源书 pt 1:1）。

## 淡界行线栅格兜底（§1.95b `_grid_fit`）

**难点**：p22/p32/p36 界行线墨色很淡（覆盖率 0.35-0.49），主阈值 0.55 检不出 → 该页无版框 →
连带「列距按内框宽封顶」失效（p36 的 13 列伸到页左外）。而**单阈值 + 相邻差中位定列距不成立** ——
阈值降到 0.30 时 p32 的 12 条候选里 5 条是正文列竖笔画碎片，碎片多到把列距中位带偏（36pt 而非 43.5pt）。

**做法（按「版框是等距栅格」拟合）**：
1. 阈值降到 `VERT_LINE_COV_LO`(0.30) 重扫得候选细线；
2. 二维搜索（列距 p ∈ 40-48pt、某条候选所在栅格）下所有跨 13 条线的窗口；
3. 打分 = **（命中候选数, 窗口各线的墨覆盖率之和）** —— 命中数优先，覆盖率解平手
   （p22 最左线淡到漏检时栅格可整体右移一格而命中数不变，右移后最右线落在版框外空白上（覆盖率 ≈ 0），
   靠覆盖率判回正确位置）；
4. 对命中集合最小二乘精修 p/首线 → 生成 13 条线（漏检的按栅格位置补，墨迹参数取中位）；
5. 栅格命中时内框左右线直接取**链首末线**（比「横线端头」估值可靠 —— 源书横线横跨整幅纸面含订口页边，
   p36 实测旧法会把右线高估 26pt）。

**只在主判据失败时触发**：本次全书只命中 p22/p32/p36 三页（版框 225 → 228 页），无误触发。

## 输入 / 输出

- **输入**：源页灰度（`src_gray`，2x px）；页幅；`VERT_LINE_COV*` / `VERT_H_COV` / `VERT_FRAME_DEBUG`
- **输出**：`frame_geom(pi)` → dict（内框 in_l/in_r/in_t/in_b、外粗线 out_*、界行线 thin[]、横线跨 hx_l/hx_r、
  列距、扫描黑边宽）或 None；`frame_tex` → 一组 `\put(...){\rule{}{}}`

## 约束

1. **不硬编码页号**：全部判据为覆盖率/厚度/结构闭合 + 印版常数（12 列、799pt 内框高）；
2. 只画测到的：外粗线缺测（订口侧被吞）时不画，不用模板补（`frame_tex` L668-669）；
3. 版框检测结果同时被 [02_tate_layout.md](02_tate_layout.md) 的「列块总宽上限」复用（同一页只算一次）；
4. 开关 `VERT_FRAME=0` 关闭；`VERT_FRAME_DEBUG=1` / `VERT_JIE_LOG=1` 打诊断。

## 验收方法

1. stdout `[版框] p...` 日志逐页核对（内框 x/y、外粗线 L/R、界行线条数、横线 x 跨度）；
2. **边框复测**（输出墨迹 vs 源书实测，同坐标）：p4 内框 24.0-546.0 vs 源 24.2-546.0；
   界行线 11 条位置逐条吻合（65.7/108.9/152.6/195.2/238.9/283.1/326.2/369.9/413.5/457.2/501.4）；
   横线 309.7-312.2（源 309.5-313）、316.2（源 316）、1117.2（源 1117.5）；
3. 兜底页对照真值：p22 内框 x26.3-547.9（探针真值 27.5-548）、p32 x27.5-538.8（真值 21-543）、
   p36 x21.8-536.5（真值 21-543）；
4. `VERT_FRAME_DEBUG=1` 下无「误触发兜底」（兜底只在三页命中）。

## 测试点

- 228/231 页画出（无框 3 页 = 封面/前附/水印页）
- 订口侧外粗线缺失不影响内框定位（p115/p191 装订侧内线太淡 → 由「列数 × 列距」补）
- 扫描黑边/贴页缘假线不误判（p172/p210）
- 界行线数 ±1（源书本身缺线/多检一条，未做梳状补全）
