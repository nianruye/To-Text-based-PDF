## 目标

还原源书的印版版框：**双边外框**（外粗线 + 空隙 + 内细线）+ **界行线**（列间细竖线），
并按源书墨迹实测位置绘制（不套用统一模板）。

## 背景（源书实测结论）

- **双边**：外粗线/空隙/内细线宽度与内框高按源书实测（数值见 §参考基线）；内框高是印版常数，换书重标。
- 内框左右两条竖线**同时是首/末界行线**；界行线 = 列间 1pt 细竖线，起止同内框上下线；
  列距/内框宽/列数见 §参考基线。
- **订口侧（装订边）只剩内细线**：外粗线被装订边/扫描裁切吞掉（实测每页 L 或 R 必有一侧缺，
  缺失侧**逐页交替**）。
- **横线横跨整幅纸面**到订口页边（书眉/页码带被上下横线包住）→ 横线按源墨迹实测 x 跨度画。
- 书眉/页码在**框外**订口页边内（版心），与框内正文列无关。

## 检测判据（都带实测依据）

| 元素 | 判据 | 源书实测分布 |
|---|---|---|
| 横线 | 行墨占比 > `V_H_COV`(0.45) 且墨迹横跨 > 0.55 纸宽；上下各取「外粗+内细」一对（7.5pt 内相邻两组配对，厚者为外；7.5pt 为参数默认） | 见 §参考基线 |
| 竖线 | 版心 y 区间内列墨占比 > `V_LINE_COV`(0.55) | 见 §参考基线 |
| 外粗线 | 组厚 ∈ [`V_THICK_MIN`, `V_THICK_MAX`]（默认 2.4/6.5pt，参数默认非判据）且落在内细线外侧 12pt 内（12pt 为参数默认） | 见 §参考基线 |
| 剔除 | 扫描黑边（`_bar_px`：两端累计墨占比 > 0.80 的列区宽度）、贴页缘小边距（默认 5pt，参数默认）内的假线（p172/p210 实例见 §参考基线）、厚度 > `V_THICK_MAX`（默认 6.5pt，参数默认）的粗条 | — |
| 结构闭合 | 有外粗线的一侧 → 内线 = 粗线内侧缘 ± 间隙；另一侧补「横线端头 − 粗线厚 − 间隙」；都缺则用实测最外细线；再用「列数 × 列距」（`N_COL_FRAME` 印版常数；本书值见 §参考基线）校验修正 | 见 §参考基线 |

**合理性闸门**：内框高/宽落在源图标定区间（默认 [700,900] / [400,640]pt，参数默认）、跨度应为列距的整数倍
（偏离 > 0.22 列 → 判为检测失败返回 None，该页不画；0.22 为参数默认）。

**渲染**：eso-pic **带星版** `\AddToShipoutPictureFG*` + `\put` + `\rule`
（探针 `tmp_vert/probe_rule.py` 实测：tate 下 `\rule` 尺寸**不旋转**、`\put` 参考点 = rule 左下角、
原点 = 页真左下角，源书 pt 1:1）。

## 淡界行线栅格兜底（§1.95b `_grid_fit`）

**难点**：p22/p32/p36 界行线墨色很淡（覆盖率见 §参考基线），主阈值 0.55 检不出 → 该页无版框 →
连带「列距按内框宽封顶」失效（p36 的 13 列伸到页左外）。而**单阈值 + 相邻差中位定列距不成立** ——
阈值降到 `VERT_LINE_COV_LO`（默认 0.30，参数默认非判据）时 p32 候选含正文列竖笔画碎片，列距中位被带偏（实测见 §参考基线）。

**做法（按「版框是等距栅格」拟合）**：
1. 阈值降到 `VERT_LINE_COV_LO`（默认 0.30，参数默认）重扫得候选细线；
2. 二维搜索（列距 p ∈ 默认窗 40–48pt，参数默认；某条候选所在栅格）下所有跨 13 条线的窗口；
3. 打分 = **（命中候选数, 窗口各线的墨覆盖率之和）** —— 命中数优先，覆盖率解平手
   （p22 最左线淡到漏检时栅格可整体右移一格而命中数不变，右移后最右线落在版框外空白上（覆盖率 ≈ 0），
   靠覆盖率判回正确位置）；
4. 对命中集合最小二乘精修 p/首线 → 生成 `N_COL_FRAME+1` 条线（漏检的按栅格位置补，墨迹参数取中位）；
5. 栅格命中时内框左右线直接取**链首末线**（比「横线端头」估值可靠 —— 源书横线横跨整幅纸面含订口页边，
   p36 实测旧法会把右线高估 26pt）。

**只在主判据失败时触发**：本次命中页/版框页数见 §参考基线，无误触发。

## 输入 / 输出

- **输入**：源页灰度（`src_gray`，2x px）；页幅；`VERT_LINE_COV*` / `VERT_H_COV` / `VERT_FRAME_DEBUG`
- **输出**：`frame_geom(pi)` → dict（内框 in_l/in_r/in_t/in_b、外粗线 out_*、界行线 thin[]、横线跨 hx_l/hx_r、
  列距、扫描黑边宽）或 None；`frame_tex` → 一组 `\put(...){\rule{}{}}`

## 约束

1. **不硬编码页号**：全部判据为覆盖率/厚度/结构闭合 + 印版常数（列数/内框高见 §参考基线）；
2. 只画测到的：外粗线缺测（订口侧被吞）时不画，不用模板补（`frame_tex` L676-677）；
3. 版框检测结果同时被 [02_tate_layout.md](02_tate_layout.md) 的「列块总宽上限」复用（同一页只算一次）；
4. 开关 `VERT_FRAME=0` 关闭；`VERT_FRAME_DEBUG=1` / `VERT_JIE_LOG=1` 打诊断。

## 验收方法

1. stdout `[版框] p...` 日志逐页核对（内框 x/y、外粗线 L/R、界行线条数、横线 x 跨度）；
2. **边框复测**（输出墨迹 vs 源书实测，同坐标）：p4 内框/界行线/横线数值见 §参考基线；
3. 兜底页 p22/p32/p36 对照值见 §参考基线；
4. `VERT_FRAME_DEBUG=1` 下无「误触发兜底」（兜底只在三页命中）。

## 测试点

画框页数/无框页见 §参考基线
- 订口侧外粗线缺失不影响内框定位（p115/p191 装订侧内线太淡 → 由「列数 × 列距」补）
- 扫描黑边/贴页缘假线不误判（p172/p210）
- 界行线数 ±1（源书本身缺线/多检一条，未做梳状补全）

## 已知遗留

- **界行线 ±1 条**：部分页为 10 或 12 条（计数见 §参考基线；源书自身缺线/多检一条），未做列距梳状补全；
- 曾试「最长连续墨段」辅助判据（连段/文字列长度见 §参考基线）救淡页，
  反而把正常页 20+ 条界行线判掉且没救回淡页 → **撤回**，只用覆盖率 + 栅格兜底。
