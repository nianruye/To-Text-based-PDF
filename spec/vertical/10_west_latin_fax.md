## 10.1 西文行侧排（§1.995a）

**目标**：竖排书里的整行西文（如 wz7 源页 29 的 `—We receive but what we give.—Coleridge`）
按源书的样子渲染 —— 整行**侧排**（页面逆时针转 90° 可正读）、字母正立方向与源书一致、行位/字号/词距全取源图实测。

| 项 | 口径 | 锚点 |
|---|---|---|
| 判据（哪些行算「纯西文行」） | 拉丁字母 ≥ `VERT_LAT_MIN_CH`(4) 且 CJK 字 ≤ `VERT_LAT_MAX_CJK`(1) 且 拉丁占比 ≥ `VERT_LAT_MIN_RATIO`(0.7)。wz7 全书 4029 条 OCR 行里只有 1 条命中（p29，占比 0.91）；汉字列里夹西文词（占比 0.30-0.72）**不**命中（那类行是汉字列，整行旋转会错） | `latin_row` L3154 |
| 字号 | 源行墨迹**横宽**（垂直于行）/ 拉丁串的字体墨迹上下缘比（em）×PT2BP | `_latin_tex` L3587 |
| 词/片位置 | 源图 run 按「大空隙(≥0.5em) = 词间」分组，词↔词组宽度 DP 配对；片沿行起点 = 该片实测墨迹起点；**片基线 = 该片实测墨迹下缘**（源书该行自身不共线） | `_latin_groups` L3369 / `_align_words_groups` L3384 / `_assign_runs` L3554 |
| 片内字距 | 只补「本字体字形比源书窄」那部分，夹 ±0.25em | `_latin_tex` L3587 |
| 单位 | 源图量出的坐标是 **bp**，TeX 坐标/字号是 **TeX pt**（1bp = 1.00375 TeX pt）→ 源坐标 ×`PT2BP`（不做换算：744pt 长的行会缩 0.37% = 行尾差 5pt） | `PT2BP` L2155 |
| 字体（taskR2 口径） | 拉丁字母走 **TeX 拉丁 TFM 字体**（默认 `ptmr8t` = Nimbus Roman/Times）：半角比例宽度 + 文本层 ASCII。**改前**用 CJK 字体 → tate 模式把 ASCII 映射成全角字形（文本层 U+FF37、墨迹 0.745×0.46em） | `LAT_TFM` L3431 / `_lat_gs` L3438 / `_lat_enc` L3451 / `_tfm_widths` L3467 / `_lat_metrics` L3493 |
| 破折号（taskR2） | 破折号（`—―–`）**单独成片**：字号由该 run 实测长反算（字形长比 0.772em，探针实测），沿/横位取该 run 墨心实测（探针 0.411/0.243em）。源书两条破折号本身不等长（54.0/37.5pt），故**逐条**定 | `_lat_pieces` L3540 / `_latin_tex` L3587 |
| 旋转落点标定 | 建排前探针（真 preamble 编译一页）：① 40pt 'H' 的墨迹左上 → `KX/KY`；② 同页 40pt 破折号 → 长比/沿偏/横偏 | `_rot_anchor` L3260（常数 `_ROT_K` L3258） |
| 渲染形 | 单个 `\put`：`\special{pdf:literal direct q 0 -1 1 0 0 0 cm}` + 拉丁字体选择 + `q...Q`（精确整数矩阵，无数值逆） | `_latin_put` L3521 |
| 开关 | `VERT_LAT=0` 关闭；`VERT_LAT_FONT=0` 回 CJK 全角 ASCII 老口径（对照用）；`VERT_LATFONT`/`VERT_LATFONT_PFB` 换字体 | L3155-3160 / L3431 |

**验收**：p29 源书/产物墨迹逐词对账 —— Δ沿行起点中位 **0.00pt**、Δ沿长 **0.00pt**、Δ横心中位 -1.06pt（±2pt，
源书该行自身倾斜 ≈0.3°）；破折号长度 54.8/37.5 vs 源 54.0/37.5。命令见报告 §7。

## 10.2 标题署名行（§1.995b）

**目标**：字号显著大于正文的标题/署名行（如 p29「金瓶梅論」1.98×、「侯健」3.44×）不被 §1.99 框内兜底的
「1.35× 页字号」上限压回去，且字号/列位/列顶按**源图墨迹实测**渲染。

* 判据：该行源图墨迹实测字高 / 本页正文**长行(≥8 字)**字高中位 ≥ `VERT_DISP_RATIO`(1.4)；
  字高必须由**逐字 run**支撑（run 数 ≥ 0.6×排版格数，防粘连长 run 把整列连成一条）；
  稀少性护栏：大字号行数 ≤ max(1, 25% 长行数)（防整页字号分层的页被当成标题）。
* 渲染：`_display_put` 走 `col_puts` 同一套逐字渲染（标点挤格/横向压缩同源），字号/列位/列顶/步进取实测。
* 锚点：`_display_put` L3675 / `_page_specials` L3697（分类与占用带 `_band_blocked` L3689）。
* **已知残留**（taskR2 实测量化）：竖直落位比源书低 +2.0pt（多数显示行）/ +8.3pt（最大字号行「侯健」），
  根因 = `INK_ASC` 是全库字中位常数而竖排逐字墨顶比例自变（实测 金 0.918em / 侯 0.862em，轮廓无法预测）。
  选项见 `docs/vert_wz7_layout3_report.md` §6 遗留 1。

## 10.3 影印页整页贴图（§1.995c）

**目标**：源书里「翻印旧版的复印件」页（排版与本书现代排印完全不同、OCR 读不出内容）整页贴源图，**不重建**。

* 判据（两道独立闸，参考量全部取本书自身，不写死页号/绝对值）：
  ① 每 OCR 字墨迹面积 = 墨迹像素/(OCR 非空白字数+1) > `VERT_FAX_IPC_MULT`(2.5) × 全书正文页中位；
  ② OCR 非空白字数 < `VERT_FAX_CHAR_MULT`(0.5) × 全书正文页字数中位。
  正文页 = OCR 字数 ≥ `VERT_FAX_REF_MIN_CH`(100) 的页，样本 < `VERT_FAX_REF_MIN_N`(3) 则不判。
  口径：`FAX_SC`(0.75) 倍灰度 Otsu 阈值计数（判据只用比值，倍率越低越省时）。
* 命中统计（wz7 300 页，taskR2 复查脚本 `tmp_vert/taskR2/fax_stats.py`）：命中 **70 页**
  （p1-4 封面/空白、**p5-28 影印页全部**、其余为插图/图版/空白页）；命中页面积比 中位 748.7（8.1-2916.3），
  未命中页 最大 2.13（判据线 2.5 ⇒ 余量 3.8 倍）；命中页最大字数 123 ≪ 判据线 308.5 ⇒ 未误伤正文页。
* 贴图口径：直接取源页**内嵌图的原始字节**落 `TMP/fax/`（dvipdfmx 走 DCTDecode 原样嵌入：零重编码，实测
  p24 与源页逐像素差 0.000%）；源页无内嵌图（矢量页）才按 `VERT_FAX_DPI`(150) 渲染一次。
  落点用 dvipdfmx 的原样图片 special（`width/height` 按 TeX pt→bp 折算、put y 取负偏移），
  且必须用**带星**的 `\AddToShipoutPictureBG*`（无星版会逐页累积）。
* 锚点：`_fax_inkpx` L3807 / `fax_decide` L3826 / `fax_pages` L3848 / `fax_image` L3880 / `fax_tex` L3907；
  清单落盘 §2.55（`fax_pages.json`）+ 日志给 `--expect-low` 列表。
* **字符量口径**：贴图页不重建文本 ⇒ 这些页输出字符数 0，`verify_vert` 须用 `--expect-low` 声明（判据未放宽）。
* 开关：`VERT_FAX=0` 关闭；`VERT_FAX_IPC_MULT`/`VERT_FAX_CHAR_MULT`/`VERT_FAX_DPI`/`VERT_FAX_SC` 可覆盖。
