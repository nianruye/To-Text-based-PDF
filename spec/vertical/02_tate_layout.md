# 02 tate 布局语义与列参数拟合

**状态**：implemented（wz6 全书 231 页 1:1）
**实现锚点**：`src/pipelines/build_vert.py` L45-94（参数拟合 + 拟合日志）、L791-838（`page_tex` 每页列流）、
L663-682（版心右缘墨迹复测）
**关联**：commit `ddc8761`（参数自拟合）、`ff4b5b7`（每页列距/容量修正）

## 目标

把 OCR 的列级几何（每列 x0/x1/y0/y1 + 文本）转成 tate 参数，使输出的**列数/列位/列断点**与源书一致。

## 背景：tate 参数语义（与横排**不同**，实测，勿凭直觉）

| 参数 | 横排语义 | **竖排（tate）语义** |
|---|---|---|
| `\textwidth` | 版心宽 | **列高**（列内字数 × 字号） |
| `\textheight` | 版心高 | **列区横向容量**（列数 × 列距 + 余量） |
| `\topmargin` | 上边距 | 天头 − 102pt |
| `\oddsidemargin` | 左边距 | 决定**右缘**（见公式） |

**右缘定位公式**：`右缘 = 70 + \oddsidemargin + \textheight`
（由 e10c / exp13 / bv 三点回归标定）—— **改 `\textheight` 必须同步改 `\oddsidemargin`**，
否则列块整体位移（曾踩坑：标题排到页面外）。实现里两者成对更新（L83 / L682）。

**papersize 换算**：`\special{papersize=W,H}`，`W,H = 目标 pt × 1.00375`（dvipdfmx 按 bp 解析）。
同时必须 `\setlength{\paperheight}` 为真页高，否则 eso-pic 的 FG 锚点不落在页真左下。

**断列控制**：每列 `{\fontsize{字号}{列距}\selectfont 列文本\par}` ——
- **`\par` 必须在 `\fontsize` 组内**；组外会让新列列距坍缩到 35pt（实测）；
- 列内字步进 = 字号（em）；**列距 = `\fontsize` 第二参数（baselineskip）**；
- 大字号列：字号 ≤ 列距 × 0.92（`fmax = PITCH*0.92`，防侵入邻列）；
- 字距宽的标题：用「字号 + 字间全角空格」表达（`step > 1.3*字宽` 时插 `　`）。

## 参数拟合（L45-88，全部数据驱动、无硬编码）

| 参数 | 来源 | wz6 实拟合值 |
|---|---|---|
| 字号 `FS` | 正文列「盒高 ÷ 字数」中位（px ÷ 2） | ~34.4pt |
| 列距 `PITCH` | 前 40 页相邻正文列 x0 差中位（60-160px 窗口） | ~47.6pt |
| 列高 `HCOL` = `\textwidth` | 正文列盒高中位 | ~863.7pt |
| 天头 `TTOP` | 正文列 y0 中位 | ~318.6pt |
| 列数 `NCOL` | **最密页**列数（90 分位），非中位 | 12-13 |
| `\textheight` | `NCOL × PITCH + 12`（余量） | — |
| 右缘 `RIGHT` | 源图墨迹实测定（见 §1.96） | 563.1pt（旧 OCR 拟合 594.9pt ✗） |

**列容量必须按「最密页」而不是中位**：tate 下累积列数超过 `\textheight` 会**触发分页**——
实测中位 12 列、13 列页有 44 个，按中位排全书 231 页跑成 **286 页**。

**每页列距自适应**（L800-806）：註釋页字号与列距只有正文一半（实测 p156 列距 21.5pt），
按全局 47.6pt 排 20 列 = 952pt 远超页宽 → 溢页。判据 = 本页正文列 x0 相邻差中位，与全局差 > 15% 时用本页值。

**列块总宽上限**（L821-833）：源书正文列都排在版框内，故
`Σ 列数 × max(列距, 该列字号) ≤ 内框宽`（不动点迭代 4 轮）。
正常页（11-12 列、字号 < 列距、不折列）退化为旧判据 `列数 × 列距 ≤ 内框宽`，逐位一致；
p194（19 行 21 列、39pt 字号 + 插入空格的标题栏折列，实占 574pt > 内框 523pt）靠此收紧到 22.4pt 列距。

**折列判据**（L808-819）：tate 下列长 > `\textwidth` 会折列，实测阈值 ≈ 1.15×`\textwidth`
（普通栏 850-907pt 不折；标题栏插入全角空格后长度翻倍必折 → 计入占列数）。

**末页不加 `\newpage`**（L907-908）：否则多出一张空白页（231 → 232 页）。

## 输入 / 输出

- **输入**：每条 OCR 列 `(x0,x1,y0,y1,text)`；`src.pdf`（页幅、版框内框宽）
- **输出**：每页一串 `{\fontsize{f}{列距}\selectfont 列文本\par}`，从右到左（x0 降序）

## 约束

1. 列分类 `is_body_col`（L34-43）：列高 < 300px 非正文；`x0>1100 且短` = 书眉/页码；
   `x0<100 且 字步进<55` = 左侧小字边注；**含 `\n` 的 OCR 框一律排除**（竖排列必单行；
   含换行的是多块合并残片，实测全书 7 条，其中 p74 图例幻觉 194 字会撑出整页）；
2. 不硬编码页号/书参数：全部中位数/分位数拟合；
3. `VERT_PAGES` 只影响输出页选择，不改变拟合（拟合始终用全书数据）。

## 验收方法

1. `verify_vert.py`：页数 1:1、逐页字符量与 OCR 对照（非预期差异页 0）；
2. 抽页对照源书：列数、列 x 位置（第 1 列吻合、最左列偏差 ≤ 半列）、每列断字位置；
3. 版框页：列块不伸出版框内框（越界 span = 0）。

## 测试点

- 231 页（= 源）输出；无溢页/空白页（`verify_vert.py` a）
- 註釋页（实测 p156）列距取自本页、不溢页
- p194（字号撑宽 + 标题栏折列）不越界
- 末尾页不产生空白页

## 已知遗留（预存在，见 `docs/vert_v2_report.md` 五）

- **正文列长于版框内框**：全书普遍（实测 p4 正文到 y1171.5 而内框下缘 1113.1）。
  根因：`\textwidth` 由 OCR 盒长中位拟合（863.7pt），而 OCR 盒沿文本方向系统性偏松约 8%
  （真值 ≈ 800pt = 内框高）。改动会改变全书断列/页数，本轮未动。
- **列距口径差**：全局列距 47.6pt（OCR 列 x0 差）vs 源书版框实测列距 43.5pt，差 ~9% →
  列块自右向左累积偏移（第 1 列吻合、最左列差 ~40pt）。若要更高保真，应以版框界行线列距重拟合。
- **逐页版面错位**：奇/偶页扫描错位（奇页内框顶 290 / 偶页 315.5），列块用全局拟合值 →
  单页最大偏差 ±18pt（水平）/±26pt（垂直）。逐页 `\setlength{\textheight}` 位移探针结果自相矛盾
  （tate 分页语义未查清），未启用。
