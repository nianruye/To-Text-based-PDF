## 目标

把 OCR 的列级几何（每列 x0/x1/y0/y1 + 文本）转成 tate 参数，使输出的**列数/列位/列断点**与源书一致。

## 背景：tate 参数语义（与横排**不同**，实测，勿凭直觉）

| 参数 | 横排语义 | **竖排（tate）语义** |
|---|---|---|
| `\textwidth` | 版心宽 | **列高**（列内字数 × 字号） |
| `\textheight` | 版心高 | **列区横向容量**（列数 × 列距 + 余量） |
| `\topmargin` | 上边距 | 天头 − 偏移（实现默认 102pt，非判据；换书由源图标定） |
| `\oddsidemargin` | 左边距 | 决定**右缘**（见公式） |

**右缘定位公式**：`右缘 = 基准偏移 + \oddsidemargin + \textheight（基准偏移实现默认 70；非判据）`
（由 e10c / exp13 / bv 三点回归标定）—— **改 `\textheight` 必须同步改 `\oddsidemargin`**，
否则列块整体位移（曾踩坑：标题排到页面外）。实现里两者成对更新（L98 / L102 与 L691-711）。

**papersize 换算**：`\special{papersize=W,H}`，`W,H = 目标 pt × 1.00375（单位换算契约值，非本书判据）`（dvipdfmx 按 bp 解析）。
同时必须 `\setlength{\paperheight}` 为真页高，否则 eso-pic 的 FG 锚点不落在页真左下。

**断列控制**：每列 `{\fontsize{字号}{列距}\selectfont 列文本\par}` ——
- **`\par` 必须在 `\fontsize` 组内**；组外会让新列列距坍缩到 35pt（实测）；
- 列内字步进 = 字号（em）；**列距 = `\fontsize` 第二参数（baselineskip）**；
- 大字号列：字号 ≤ 列距 × 0.92（`fmax = PITCH*0.92`，防侵入邻列）；
- 字距宽的标题：用「字号 + 字间全角空格」表达（`step > 1.3*字宽` 时插 `　`）。

## 参数拟合（L41-113，全部数据驱动、无硬编码）

| 参数 | 来源 | wz6 实拟合值 |
|---|---|---|
| 字号 `FS` | 正文列「盒高 ÷ 字数」中位（px ÷ 2） | 见 §参考基线 |
| 列距 `PITCH` | 前 40 页相邻正文列 x0 差中位（窗口 60–160px，参数默认） | 见 §参考基线 |
| 列高 `HCOL` = `\textwidth` | 正文列盒高中位 | 见 §参考基线 |
| 天头 `TTOP` | 正文列 y0 中位 | 见 §参考基线 |
| 列数 `NCOL` | **最密页**列数（90 分位），非中位 | 见 §参考基线 |
| `\textheight` | `NCOL × PITCH + 12`（余量；12 为实现默认，非判据） | — |
| 右缘 `RIGHT` | 源图墨迹实测定（见 §1.96） | 见 §参考基线 |

**列容量必须按「最密页」而不是中位**：tate 下累积列数超过 `\textheight` 会**触发分页**——
按中位排全书会溢页（页数/列数分布见 §参考基线）。

**每页列距自适应**（L1271-1277）：註釋页字号与列距只有正文一半（实测见 §参考基线），
按全局列距排 20 列会远超页宽 → 溢页。判据 = 本页正文列 x0 相邻差中位，与全局差 > 15% 时用本页值（15% 为相对量）。

**列块总宽上限**（L1297-1306）：源书正文列都排在版框内，故
`Σ 列数 × max(列距, 该列字号) ≤ 内框宽`（不动点迭代（实现默认 4 轮，非判据））。
正常页（常见列数/字号关系见 §参考基线；字号 < 列距、不折列）退化为旧判据 `列数 × 列距 ≤ 内框宽`，逐位一致；
p194（标题栏折列，实测见 §参考基线）靠此收紧列距。

**折列判据**（L1282-1293）：tate 下列长 > `\textwidth` 会折列，实测阈值 ≈ 1.15×`\textwidth`
（普通栏 850-907pt 不折；标题栏插入全角空格后长度翻倍必折 → 计入占列数）。

**末页不加 `\newpage`**（L1390 / L1400）：否则多出一张空白页（页数见 §参考基线）。

## 输入 / 输出

- **输入**：每条 OCR 列 `(x0,x1,y0,y1,text)`；`src.pdf`（页幅、版框内框宽）
- **输出**：每页一串 `{\fontsize{f}{列距}\selectfont 列文本\par}`，从右到左（x0 降序）

## 约束

1. 列分类 `is_body_col`（L53-62）：列高 < 小字阈值（实现默认 300px，非判据）；`x0 > 边缘阈值（默认 1100）且短` = 书眉/页码；
   `x0 < 边缘阈值（默认 100）且字步进 < 阈值（默认 55）` = 左侧小字边注；**含 `\n` 的 OCR 框一律排除**（竖排列必单行；
   含换行的是多块合并残片，实测全书 7 条，其中 p74 图例幻觉 194 字会撑出整页）；
2. 不硬编码页号/书参数：全部中位数/分位数拟合；
3. `VERT_PAGES` 只影响输出页选择，不改变拟合（拟合始终用全书数据）。

## 验收方法

1. `verify_vert.py`：页数 1:1、逐页字符量与 OCR 对照（非预期差异页 0）；
2. 抽页对照源书：列数、列 x 位置（第 1 列吻合、最左列偏差 ≤ 半列）、每列断字位置；
3. 版框页：列块不伸出版框内框（越界 span = 0）。

## 测试点

- 页数 = 源（本书 231 页，见 §参考基线）；无溢页/空白页（`verify_vert.py` a）
- 註釋页（实测 p156）列距取自本页、不溢页

- 末尾页不产生空白页

## 已知遗留（预存在，见 `docs/vert_v2_report.md` 五）

- **正文列长于版框内框**：全书普遍（实测例见 §参考基线）。
  根因：`\textwidth` 由 OCR 盒长中位拟合（实测值见 §参考基线），而 OCR 盒沿文本方向系统性偏松约 8%（实测）
  （真值见 §参考基线）。改动会改变全书断列/页数，本轮未动。
- **列距口径差**：全局列距（OCR x0 差）vs 源书版框实测列距（数值见 §参考基线），差约 9% →
  列块自右向左累积偏移（第 1 列吻合、最左列差见 §参考基线）。若要更高保真，应以版框界行线列距重拟合。
- **逐页版面错位**：奇/偶页扫描错位（奇/偶页内框顶（数值见 §参考基线）），列块用全局拟合值 →
  单页最大偏差见 §参考基线。逐页 `\setlength{\textheight}` 位移探针结果自相矛盾
  （tate 分页语义未查清），未启用。

## 框驱动列位/列顶（§1.98，2026-10-15 第二轮）

**实现锚点**：`build_vert.py` L819-1260（`page_metrics` L888-975、`col_puts` L1103-1146、`page_puts` L1148+、
`page_rows` L1057-1098、`note_puts_frame` L1199-1222）。测量与逐条验收数据见
`docs/vert_frame_driven_report.md` §7-§11。

口径（全部源图墨迹实测，逐页独立）：

1. **列位** = 该页内框的墨迹列带栅格（`_ink_bands` + `_grid_from_bands`，实测列距见 §参考基线），
   字列居中于槽内 → 列区左右缘与内框左右缘余量各约 5–6.5pt（见 §参考基线）（源书同为字宽<列距的居中排法）。
2. **列顶** = 本槽实测墨迹顶：源书多数正文列贴墨带顶、少量段首缩进（比例/缩进见 §参考基线）。
   不用「顶贴墨带顶/上列墨底+步进」等启发式（实测偏差见 §参考基线）。
3. **列底**：满列（本槽实测底贴墨带底；比例见 §参考基线）按 (槽高−单字墨高)/(字数−1) 定步进，夹在常规步进的 0.75–1.30 倍（无量纲） → 两端贴源书；短列（段尾/标题）不拉伸（源书亦然）。
4. **测量三坑**（复现时必须同口径，否则两侧数字不可比）：
   ① 槽顶/底只剔「贴扫描窗口边」的版框线 run（长 run 剔除只用于字号估计，原口径把若干槽顶/底截断（见 §参考基线））；
   ② 细碎 run（「三」「一」的分离点画、省略号点）按 0.7 步进贴回最近字 run；
   ③ 槽顶/底用深墨掩膜（深墨阈值见 §参考基线）避开扫描透印（浅阈值下透印与本文粘连（p90 实例见 §参考基线））。
