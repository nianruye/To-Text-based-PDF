# 14. 列尾闭引号 ﹂ 的格位形状纠错（taskCM）

状态：**implemented**
实现：`src/pipelines/build_vert.py` §1.998（新）；调用点 `col_puts`（列尾替换/补字）
测试：`src/test/unit/test_vert_taskCM.py`（22 项）；报告 [docs/vert_quote_shape_report.md](../../docs/vert_quote_shape_report.md)

## 1. 目标（用户反馈）

用户对照 wz7 源页 444：「源书有的呀，而且我发现好多这种诗句都没有闭引号，是 OCR 本来就没有识别出来吗」。
源书诗句列尾是 `…衙。﹂` / `…鍾馗。﹂`，OCR 把 ﹂ 读成 **`。`** 或 **`一`**，渲染端照 OCR 文本画 -> 闭引号整列缺失。
本 spec 在**渲染端**用「该字画在哪一格」这一权威信息回源图量墨迹形状，只改码位 / 补一个字，不动版面。

## 2. 契约 A：取样（§1.998 `_qsf_pick_tail` / `_qsf_run_feat`）

- **只无版框书**：`_NF['on'] and src_doc is not None`；有版框书（wz6）整段不执行（零回归）。
- **列尾候选**：只处理文本末字 ∈ {`。`, `一`} 的列。
- **认列**：槽格是标定后的均匀栅格，**可能有整列偏移**（实测 p444 列墨迹 x519-543 被排进槽 529-555，偏 +11pt）。
  故不能按槽带裁（会把引号竖臂切掉 -> 退化成 `bar`）；也不能放宽到整页（邻列连续正文会把 y 投影连成整段）。
  做法：在槽中心 ±1 列距的 x 窗内，按 x 投影（4pt 桥接同列笔画缝隙）取**离槽中心最近**的墨迹 x-run = 本列。
- **认字**：本列 x 带内做 y 投影 -> 墨迹 run 列表；从下往上找第一条**小墨**（`QSF_MIN_RUN` 2.5pt ≤ 高 < 0.6 步进），
  最多看 4 条（排碎墨噪点）；每条在自身 y 带内**重算 x 带并重算 y 范围** -> 单字形包围盒。
- **槽底外扩**：取样 y 窗 = `[槽顶 - 0.5 步进, 槽底 + QSF_TAIL_DN(1.3) 步进]`。实测 wz7 p444 的 ﹂ 墨迹
  在 slot bot 之下 0.7-1.1 步进（阈值 185 下仅 1.3-8.5pt，不进 `_slot_runs` 的 dink 统计 -> slot bot 少算一格）。
- **单字形 sanity**：较长边 < `QSF_MIN_GLYPH`(0.20)×步进 = 碎墨，不参与分类（实测 p444 列 b 下方 2 步进处
  一条 2.5×4.5pt 噪点会被四角特征误判成 corner）。

## 3. 契约 B：形状判据（`_qsf_analyze` / `_qsf_classify`）

与 `tmp_vert/cj5/shape_clf2.py` 逐字相同（8 个已标真值反推，**不改阈值**）。在墨迹包围盒内归一化：

| 类 | 判据 | 含义 |
|---|---|---|
| `bar` | 宽高比 ≥ 1.8 且 高 ≤ 0.30×字格 | 汉字「一」：单条长横，无竖臂 |
| `corner` | 四角极差 ≥ 0.35 且 最大角 ≥ 0.40 且 中心 ≤ 0.45 | 直角引号：一个实心交点 + 两臂 |
| `ring` | 中心 ≤ 0.35 且 四边最薄 ≥ 0.05 且 四角极差 < 0.35 | 句号：闭合圆环，四角均衡 |
| `other` | 其余 | 不动 |

阈值可用 `VERT_QSF_*` 覆盖但**默认值即真值反推值**；`QSF_MIN_GLYPH` / `QSF_MIN_RUN` 是取样 sanity，不是分类判据。

## 4. 契约 C：动作（`_qsf_decide`）

| 尾格形状 | 文本末字 | 前一条墨 run | 动作 |
|---|---|---|---|
| corner | `一` | 任意 | **replace**：`一 -> 」`（1:1，渲染为 ﹂） |
| corner | `。` | `ring` | **append**：保留句号，补一个 `」`（源书是 `。﹂` 两个字形；OCR 只给了句号） |
| corner | `。` | 其它 | **replace**：`。 -> 」`（这个句号本身就是引号误读） |
| ring / bar / other | 任意 | 任意 | **不动**（宁少改不误改） |

- **replace**：在 `col_puts` 的逐字循环里只改 `ch`；`n_cells`/`step`/`top`/`k` 全不变。
- **append**：既有字的 k/step/top 全不变；在循环结束后追加一个 `\put`，落位用**源图实测墨顶**（合并列被均分
  压缩，渲染格位比源墨高 1-2 格）。文本层顺序仍是「。﹂」。
- 替换/追加都用 `」`（渲染端 §1.0c 转竖排形态 ﹂ 并按 `BR_SIZE` 标定字号；PDF 文本层即 U+FE42）。
- 逐处记录落盘 `qsf.json`（页 / 列 x / 末字 / 尾墨 y·w·h / 四角特征 / 动作）。
