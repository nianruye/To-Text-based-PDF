# 08 标点竖排形态（括号）+ OCR 列拆分归位

> 状态：**implemented**（2026-10-15，taskK）。实现锚点 `src/pipelines/build_vert.py` §1.0c / §1.0d。
> 验收：p3 源-产物对照图（`docs/vert_punct_font_report.md` 附图）+ 全书抽查 ≥5 页 + `verify_vert` PASS + 全量测试。

## 1. 目标

用户逐页对照反馈：「源书 p3『（一九三八年五月）』的括号形态与我们不同」。
实测确认两件事：①**形态**：源书竖排括号是**旋转 90 度的竖排专用形态**（圆弧开口朝下/朝上）；
②**字号**：同一页两处括号字号不一致（22.4pt vs 29.8pt），根因是 OCR 把括号对拆到了相邻两列
（详见 §4）。

## 2. 输入 / 输出

| 项 | 输入 | 输出 |
|---|---|---|
| 形态映射 | OCR 文本里的全角括号 `（）「」『』【】〔〕《》〈〉` | 渲染时替换为竖排码位 `︵︶﹁﹂﹃﹄︗︘︹︺︽︾︿﹀`（U+FE35…U+FE40） |
| 字号 | 正文字号 F | 括号字号 = F × 0.66（`︗︘︹︺` 取 0.55/0.49，源书实测更小） |
| 位置 | 传入的格左缘 x / \\put 基线 y | 按字形在 em 盒内的**墨心**摆回格心（开口形墨心在盒下半、闭口形在上半） |
| 列拆分归位 | 页内 OCR 行文本（阅读序） | 行首闭括号移到上一行行尾（只改文本，不动几何） |

## 3. 约束

- **不改横排管线**（`build_geom.py` / `build_classic.py` / `build_pdf_v13.py`）与四书。
- **不动既有正确功能**：标点挤格（§1.0）、字宽压缩（§1.0a，仍用 `q/K 0 0 1 0 0 cm…Q`，
  绝不引入 `\scalebox`/btrans/etrans）、列内空隙（§1.0b）、版框驱动、边注归位。
- `VERT_BR=0` 可关闭形态替换（回退对照）；`VERT_BR_SIZE` 可覆盖默认 0.66。
- 页内字符总量守恒（归位只搬字不删字）→ 不影响 `verify_vert` 逐页字符量口径。

## 4. 实测依据（探针与数据）

探针：`tmp_vert/taskK/{shape_census,probe_vertcp,inkcols,colmap,glyph}.py`；报告：`docs/vert_punct_font_report.md`。

1. **形态**（30 页抽样、176 个「小墨迹块」保宽高比模板匹配）：`（`→U+FE35 命中 25 例
   （IoU 中位 0.596，次优候选仅 0.11）、`）`→U+FE36 命中 27 例（0.574）；`「」`命中直角形 `﹁﹂`
   （p7 放大对照确认）。源书 `︵` 墨迹 17.5×7.0pt，同列汉字墨高约 28pt（= 0.23 倍）。
2. **字号**：Noto Serif CJK TC 的 `︵` 墨迹 = 0.936×0.286 em；取 0.66F 时墨迹 18.2×6.4pt
   （源书 17.5×7.0，宽 +4%/高 −9%），是「宽高同时最接近」的单一缩放。
3. **码位可用性**：Noto Serif CJK TC 提供 U+FE17/18/35/36/39/3A/3D/3E/3F/40/41/42/43/44 全套
   （fontTools cmap 实测 + 用真 preamble 编译实测可取字）；`pxchfon[3]` = TTC 第 4 面（TC）。
4. **字号不一致根因**（p3）：OCR 把 `（一九三八年五月` 与 `）問題的提起` 拆成两行 —— 闭括号被挂到
   下一列行首（违反竖排「行头禁则」）。两列在源书里字号本就不同（日期行小字：墨高 22.0pt vs
   正文 29.5pt，我们渲染 25.0 vs 33.5 ✓ 与源书一致），但括号分属两列后看起来「同页括号不一样大」。
   全书同型 9 例（p3/p43/p155/p161/p162/p192/p193/p199/p201）。
