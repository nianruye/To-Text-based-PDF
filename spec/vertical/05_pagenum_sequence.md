# 05 页码序列校验与纠正

**状态**：implemented（wz6 全书：123 页有页码，纠正 19 处）
**实现锚点**：`src/pipelines/build_vert.py` L298-311（常量/字表）、L313-330（`pn_parse`）、
L332-334（`pn_text`）、L336-378（`pn_sequence_fix`）、L380-384（日志与 `PN_FIX` 导出）
**关联**：commit `ff4b5b7`（§1.87 新增）

## 目标

OCR 把页码读错是常态（源书页码是**逐字数码**，如「一八〇」「三二一」）。
本机制用**全书页序**做上下文校正：不信任单页 OCR，用邻页拟合值纠正误读，
再统一规范成源书数码风格渲染。

## 背景（实测误读样本）

| 页 | OCR 文本(值) | 纠正值 | 说明 |
|---|---|---|---|
| p16 | 一九二一(1921) | 一九二(192) | 多读一位 |
| p25 | 101(101) | 二〇一(201) | OCR 把「二〇一」识成阿拉伯数字 101 |
| p48 | 二三四(234) | 二二四(224) | 源图 4 条横笔 = 二 + 二 + 四（像素级复核） |
| p97 | 二十三(23) | 二七四(274) | 整段形态误判 |
| p143 | 一九(19) | 三一九(319) | 缺首位 |
| p198 | 三十四(34) | 三七四(374) | 同上 |

## 方案（数据驱动，不硬编码页号）

1. **解析**（`pn_parse`）：页码文本 → 整数。两种形态：
   - 形态① **逐字数码**（源书主流：一八〇/一七九；OCR 常把 `〇` 读成 `0`）：全数码 → 按位拼接；
   - 形态② **计数式**（如 三百〇五）：含 十/百/千 → 逐位累加。
2. **分段**：按页序，相邻有效页码的页号差 > `PN_GAP`(6) 处断段（容忍缺页码页）。
3. **段内等差拟合**：`value = a*page + c`，其中 `a` = 段内相邻页斜率中位；
   样本 < 4 的短段借**全局斜率**（全局斜率 = 全书相邻有效页码页斜率中位，截距取中位）。
4. **误读判定**：与拟合偏差 ≥ `PN_TOL`(2) 判误读 → 用**左右最近的非误读邻页线性插值**纠正；
   单侧则按斜率外推；段内无参照时用拟合值。
5. **规范化**：所有解析成功的页统一成源书逐字数码文本（`pn_text`：0 → 〇），供渲染（[03](03_marginalia.md)）。

**`PN_TOL = 2` 是有意的**：源书若有**合法跳号**（未编号插页），收紧到 1 会把整段误判成误读。

**纠正记录逐条打印**（L383-384）：`p48 OCR 二三四(234) -> 二二四(224)`。

## 输入 / 输出

- **输入**：`special_rows(k)` 里 `kind='pn'` 的边缘小字行（见 [03_marginalia.md](03_marginalia.md)）
- **输出**：`PN_FIX = {页序号(1-based): 渲染文本}`、`PN_LOG`（纠正记录）、`PN_INFO`（有效页数/全局斜率/截距）
- 调用方 `special_tex`（L172-173）在渲染页码时替换文本

## 约束

1. **不硬编码页号**，也不引入外部页码表（对比横排的 `PAGENUM_GLOBAL_TABLE`——竖排用序列自洽性纠错）；
2. 只在「解析成功」的页码上工作；解析失败的页不渲染页码（不猜）；
3. 修正的只是**渲染文本**：拟合（版框/墨迹）仍用原始 OCR 行，互不干扰。

## 验收方法

1. 日志逐条核对（本次 19 处，拟合 `value = 1.000*page + 176.0`）；
2. **像素级字形复核**：裁源图页码区，逐字与输出字形对照 —— 抽查 p48 实为「二二四」、
   p49 末字为「五」→ 二二五，与纠正值一致；
3. 输出页码行位置/字号仍走墨迹实测（不受文本替换影响）。

## 测试点

- 全书页码单调递增（段内无跳变）
- 阿拉伯数字形态（101）被正确识别为逐字数码误读并纠正
- `PN_TOL` 容忍 ±1（合法跳号页不被误判）
- 无页码页（缺页码/OCR 未识别）不产生渲染片段

## 已知遗留

- **页码行合并页**（p3 等）：OCR 把「书眉+页码」合成一个 `h ≥ 300` 的框 → `special_rows` 丢掉该页页码
  （见 [03_marginalia.md](03_marginalia.md) 遗留），该页无页码渲染，序列纠正对它不生效。
