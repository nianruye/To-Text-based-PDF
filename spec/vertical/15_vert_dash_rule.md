## 1. 目标（用户反馈）

用户拿 wz7《金瓶梅詞話》p57（「論金瓶梅這部書——導讀」）对照源书，两次指出：

1. 「但是真的破折号 应该是一个竖线 ，但是你给我的PDF中是两个横线 如p57」；
2. 「源书就是一条竖线 而不是两条竖线拼接的」。

即：竖排破折号必须是**一条连续竖线**，既不能是横排字形 U+2014（横线），
也不能是两个 U+FE31 竖排字形拼接（两者之间留 0.142 em 的 side bearing 缝）。

## 2. 契约 A：破折号 -> 整格矢量竖线（§1.0a4）

- **输入**：`col_puts` 逐字循环里的破折号类码位（`DASH_CHARS` = `—`U+2014 / `―`U+2015 / `–`U+2013）。
  `_put_tex(ch, ..., rule_h=<本列 step>)`；`rule_h is None` 时与旧实现**逐位相同**。
- **几何**（`_put_tex` 内，单位：`x_pt/y_pt/rule_h` 为页面 bp，`\put` 坐标 = bp × `PT2BP`）：
  - 竖线高度 = `rule_h` = 本列**排版 step**（不是字号 F —— 竖排一格的 advance 是 step，各列不同）；
  - 竖线底端 = 基线下 `(step - INK_ASC*F)` -> `\rule[lift]{w}{h}` 的 `lift = (INK_ASC*F - step) × PT2BP`
    （可为负），使线精确落在 `[T+k·step, T+(k+1)·step]` 格区间；
  - 相邻两个破折号的两条 rule 首尾坐标相同（高度恰为一格）-> **无缝连续竖线**；
  - 线宽 = `DASH_RULE_W × F`（默认 0.040 = 字体 U+FE31 墨宽比，`VERT_DASH_RULE_W` 可覆盖）；
  - 线心 = 列心 `xc = x_put + xs·F/2`（横向压缩前字盒左缘 + 压缩后字盒半宽）。
- **文本层**：保留原字 `—`（**不换成 U+FE31**），用 PDF 文本渲染模式 `3 Tr`（不可见）包住 ->
  可搜索 / 可选中 / `verify_vert` 字符量不变；画面由 rule 承担。**没有丢字**。
- **不变量**：字数、格数（`n_cells`）、step、列位、字号、基线位置全部不变；只多一条矢量图元。

## 3. 契约 B：影响面与开关

| env | 默认 | 含义 |
|---|---|---|
| `VERT_DASH_RULE` | `nf` | `nf` = 只对无版框伪槽格页（`m['g']['virtual']`）生效；`all`/`1`/`on` = 全部竖排列；`0`/`off` = 关（与旧实现逐字节等价） |
| `VERT_DASH_RULE_W` | `0.040` | 线宽 / 字号（字体 U+FE31 墨宽比） |

- **默认 `nf` 的理由**：本轮硬验收要求有版框书（wz6）`vert.tex` **逐字节零回归**；
  wz6 有 19 个 `—`（9 页），若无条件改画 rule 必然改 tex。`nf` 下 wz6 走旧路径（横线字形），
  实测 `vert.tex` md5 = `ae9d2f5259e12cff19e680b2a771b37d`（= 改动前基线）。
- **西文侧排不受影响**：`LAT_DASH` / `_latin_put` 走旋转排版路径，不经过 `_put_tex`；
  `_esc_ch` 也不再做任何破折号字形映射（它同时被 `_latin_put` 调用）。
  实测 p29（整行侧排拉丁文）开/关 `VERT_DASH_RULE` 的 `vert.tex` **逐字节相同**。
- **有版框书强制启用**：`VERT_DASH_RULE=all`（会改变 wz6 产物，仅调试/后续统一时使用）。

## 5. 已知遗留

1. **线长 vs 源书**：产物按验收「满两格」画（127.44pt），源书同位置实测竖线 80.25pt
   （破折号字形在小格内自带 side bearing，线两端各内缩约 20-26pt）。
   若要与源书等长，需要按「连续破折号 run」配对后只画一条并按源图墨迹定两端（简报的选项 B），
   本轮按简报推荐选项 A（每字满一格）实现。
2. **线宽**：默认 0.040 em -> p57 实测 2.77pt；源书同位置线粗 5.25pt（扫描书线粗 ≈ 本管线字画笔 4.1pt 的 1.28 倍）。
   产物整体字重只有源书约 69%（taskT 遗留，`VERT_BOLD` 未启用），故按比例线宽并非完全同观感；
   可用 `VERT_DASH_RULE_W` 调整（如 0.052）。
3. **数据侧误读**：patched 数据仍有 88 对 `——` + 87 个单 `—`；其中「闭引号/句号后紧跟」的单 `—`（24 处）
   与 `p59`「。」—斯」、`p118`「。」——我便」实测源图**没有破折号**（是引号 ﹂ 的直角笔画被读成 `—`），
   与已删的 1019 处同类。本任务只改渲染，不删数据；建议单独做一次数据审计。
4. **有版框书**：默认 `nf` 下 wz6 的 19 个 `—` 仍是横线字形；要统一须 `VERT_DASH_RULE=all`
   （会使 wz6 产物变化，违背本轮「零回归」验收，需用户拍板）。
