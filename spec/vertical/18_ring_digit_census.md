## 1. 方法与判据（通用）

### 1.1 对象与术语

- **ring（圈码）**：源图上**一个整格大小的紧凑墨块** = 圆环 + 圈内数字连成一片；数字 1–99（当前机制支持 1–99，
  >50 无标准 Unicode 圈码，渲染时用 `○` + 小号数字合成）。
- **situation 1**：OCR 已把圈内数字读进列尾文本（`text` 末尾 1–2 位数字），但没画圈 → 落库时把尾部 **d 位数字换成 1 个占位符**
  （d=1：`sl` 长度 0；d=2：`sl` 长度 **−1**；当前数据的位数分布见 §2）；渲染层字符量另计。
- **situation 2**：整格漏识（OCR 文本没有该数字）→ 落库时在列尾**追加**占位符；文本长度 +1。
- **step**：本页**长列**（字数 ≥ 阈值）的「列框高 ÷ 字数」中位数；短列不参与（短列的框高/字数不是步进）。
- **阅读序**：页升序；页内列 x **降序**（x 越大越先）；年表段内序号应非降（**领域假设**，不是所有书都有年表）。

### 1.2 数据契约（`docs/vert_taskF_missed_fix.json` 的 `class="ring"`）

| 字段 | 类型 | 必填 | 含义 / 不变量 |
|---|---|---|---|
| `class` | str | 是 | 固定 `"ring"`（与 `dash` / `missing_char` 并列） |
| `page` | int | 是 | 1-based 源页号；必须在 `1..len(keys)` 内 |
| `col` | [x0,y0,x1,y1] | 是 | 该列 **OCR 列框（PDF pt，页左上原点）**；运行时把 OCR coords（144dpi px）`/2` 转到同一 pt 坐标系，用**小容差**与当前列框匹配；**当前实现为固定 0.6pt（`_apply_missed_fix` L542；实现默认，参考值非判据），参数化 planned** |
| `source_x` / `source_y` | number | 是 | 圈心（PDF pt，页左上原点）；必须落在该页纸幅内 |
| `number` | int | 是 | **最终读数** 1–99（经 §1.3 序列校验/人工后的值；不是 OCR 原值） |
| `situation` | int | 是 | `1` = 文本尾已有 OCR 数字（替换）；`2` = 整格漏识（追加）；其他值不落库 |
| `text` | str | 是 | 该列 OCR 文本（situation 1 末尾 1–2 位数字；situation 2 为上下文）；用于列匹配/证据/去重 |
| `measure` | dict | 否 | 检测主块特征 `{w,h,hole,edge,ctr,fill,ar,crit,dpi}`；供人工复核/回归 |
| `how` | str | 否 | 来源标记（如 `ring_digit` / 人工普查 / API 条带） |
| `cp` | any | 否 | 候选/来源附加信息（历史字段） |
| `ring_fix` | str | 否 | 修正批次/来源（如 `battle4:t18`），便于追溯 |
| — | — | — | **无 `ch` 字段**；渲染占位符 `chr(0xE100 + number)` 是运行时内部值，**不写进 fix JSON** |

**不变量**：

- `situation=1` ⇒ 数据层应保证 `text` 末尾是 1–2 位数字（`[0-9０-９]`，排除纯 `0`/`〇` 的页码/卷次）；**代码不强制**：无尾数字时打日志并改走 situation 2 追加（fallback，见 §1.3 第 4 步）。`situation=2` ⇒ 无该尾部数字。
- 每个 ring 恰好**一个占位符**：situation 1 用 1 个占位符替换 **d 位**尾部数字 → `sl` 长度 **1−d**（d=2 → −1；d=1 → 0）；situation 2 追加 1 个 → `sl` **+1**。
- **渲染层字符量另计**：≤50 为 1 个圈码字形（净 `1−d`；d=2 → **−1**，d=1 → 0）；>50 为 `○ + d` 位数字（净 **+1**）。
- 同一 `(page, col, number)` 不重复；同一格不得有两个 ring；去重键按 `(page, 列框小容差, number)`。
- 落库只改**占位符/列尾数字**，不改其他字、列位、字号；`number` 是最终值，OCR 原值只用于 situation 1 的尾部定位。
- **本书 367 条是数据，不是契约**；换书按 §1.3 第 1 步重新生成自己的 ring 条目。

### 1.3 五步流程（每步：输入 / 判据 / 输出 / 失败处理）

#### 第 1 步：检测（census）

- **输入**：OCR `lines` / `coords`（coords 为 144dpi px，运行时 `/2` 转 PDF pt）、源 PDF、可选已有 fix JSON（只作锚点/对照）。
- **候选生成**：
  1. **situation 1 候选**：列尾文本以 1–2 位数字结尾（排除纯 `0`/`〇` 的页码/卷次）；
  2. **situation 2 候选**：整格漏识（来自独立普查/TaskE/API 条带/人工点名），没有文本尾数字；
  3. 不设「年表页白名单」——是否圈码由源图形状决定，不靠页号。
- **窗口**：列末**一格** `[y1 − step, y1]`（y1 = 列框下缘）。**不要用列末两格**（会裁掉短列/把邻字带进来）；
  step = 本页长列中位（见 §1.1）。窗口左右各留**一个小边距**（相对 step，不用固定 pt）。
- **源图墨迹**：`gray < median(gray) − 局部偏移`；偏移由本页灰度分布自标定（**不写死灰度差**）。
  取窗口内**面积最大的连通域**为主块；不是「任一通过尺寸窗的分量」（反例：手写页码窗内的碎片会假阳）。
- **主块特征（全部相对量）**：

  | 判据 | 形式 | 作用 |
  |---|---|---|
  | 宽/高尺寸窗 | **设计目标**：`w ∈ [w_lo,w_hi] × step`，`h ∈ [h_lo,h_hi] × step`（短列 h 下界可放宽）；**当前 `ring_judge P_V2` 仍是 wz7 pt 绝对值**（§3#1/§4；实现默认，参考值非判据），相对化 planned | 圈码 ≈ 整格；普通数字/两字竖叠更小，手写页码块更高 |
  | 四边有墨 | `edge ≥ edge_min`（四条边带的最小墨占比） | 挡只有数字、没有圆环的块 |
  | 圈心有墨 | `ctr ≥ ctr_min` | 挡空圈 `〇`/页码 |
  | 非实心 | `fill ≤ fill_max` | 挡实心团块/涂黑 |
  | 长宽比 | `ar ∈ [ar_lo,ar_hi]` | 挡长条/粘连 |
  | 主块独有 | 仅取面积最大的连通域 | 挡窗口内碎片假阳 |

  `w_lo,w_hi,h_lo,h_hi,edge_min,ctr_min,fill_max,ar_lo,ar_hi` **每本书用源图正/反例标定**；
  wz7 的标定值/实测见 §2（仅参照）。
- **输出**：候选 ring 列表 `{page, col, source_x/y, features, crop}`（此时还没有可靠 `number`）。
- **失败处理**：无源 PDF/窗口无墨/无可判主块 → 跳过并记日志；候选边缘不确定 → 标 `uncertain` 留人工，**不静默丢弃**。
  v1 的 `hole` 判据只保留作回归对照，**不作为新书判据**（两位数圈心被数字填满，`hole` 会整类漏检——这是 battle1 的根因）。

#### 第 2 步：读数（三层方案）

> **总原则**：读数输入必须是**带上下文的窄条带**（圈 + 上下各 2 字，约 5 格），**不能只喂孤立圆片/内圆裁片**。
> 实测教训：孤立裁片会把圆环读成 **E / ETI** 等字母（模型看不到「这是一个句末圈号」的上下文），
> 或把 `6/8/9/2` 混淆；**带上下文条带是硬要求**，不是优化项。

**Layer 1 · 模板匹配兜底（本地、只接高置信）**

- 输入：圈内圆裁片（避开环笔画），由高置信锚点（OCR 与序列一致项）自举按数字聚类模板。
- 判据：归一化相关取 top-1；**只接受高置信/与第二名有明确间隔者**；低分/无同号模板 → 不判，交给 Layer 2。
- 输出：`number` + 模板分 + `basis=template`。
- 失败处理：wz7 的模板 top-1 准确率见 §2（仅参照）→ 模板**不足以逐项定值**；本轮把它定位为
  **离线兜底/交叉校验**，不作为唯一读数层。换书重标定模板；模板库必须按书重建。

**Layer 2 · PaddleOCR-VL 带上下文条带（主力）**

- 输入：**圈 + 上下各 2 字**的窄条带（约 5 格；目标圈居中；不是孤立圆片，也不是整列）。
  这样模型能同时看到「句末/年表 + 圈位 + 相邻字」，把圈号当**行文中的字符**读，而不是孤立图形。
- 通道：已有 API 通道——`src/tools/api_candidates_all_run.py`（`PaddleOCR-VL-1.6`，
  `https://paddleocr.aistudio-app.com/api/v2/ocr/jobs`；token 从环境/`/tmp/paddle_token` 读取，**不入库**）。
  条带拼版沿用 `src/tools/api_candidates_all_build.py` 的现有条带拼版通道（每页多条、每批多页；实现默认值见 §2 成本参考）；圈码专用条带构造器
  （5 格、圈居中）为 **planned**（复用同一 API，参数化页高/条带高/页脚留边）。
- 判据：解析 `texts/polys`，取圈心附近 1–2 位数字；数字必须落在目标圈内/最近；两位数字拆分一致；
  与 Layer 1/OCR 原值冲突 → 不直接采信，交 Layer 3。
- 输出：`number` + API 置信/条带证据 + `basis=api_strip`。
- **成本**：见 §2 的 wz7 参考基线；换书按「圈数 ÷ 每页条带数」估算，token 按页计。
- 失败处理：API 不可用/超时/低置信 → 退 Layer 1/3；条带不含目标圈 → 重裁；**不得用孤立裁片补读**。

**Layer 3 · 序列校验 + 人工兜底（只看可疑项）**

- 输入：Layer 1/2 的候选 + OCR 原值 + 全部 ring 的阅读序。
- 判据：见第 3 步；序列给区间/锚点，人工只处理**违反、低置信、类型冲突**的少量项。
- 人工读图：源图**高倍裁片**（倍率按源扫描分辨率选择，至少能分辨圈内数字笔画；wz7 参考见 §2），看**圈内数字左右位 + 笔画开口/闭合**；
  每条留 crop；**不是逐条全读**（wz7 battle5 只人工 21 条，见 §2）。
- 输出：最终 `number` + 置信 + `basis=sequence+manual`；仍不确定 → 不落库。

#### 第 3 步：序列校验（非降 + LNDS 锚点）

- **输入**：第 2 步的候选读数 + OCR 原值 + 全部 ring 条目（阅读序）。
- **阅读序**：页升序；页内列 x 降序。
- **主判据**：年表段内序号**非降**；用最长非降子序列（LNDS）取锚点（多数 OCR 正确项）。
- **非锚点**：取左右最近锚点的值 `[lo, hi]`；候选值必须落在区间内，用 Layer 1/2 的分排序；
  区间为空/无锚/候选多且分差小 → `uncertain`，**不硬改**。
- **页边界/分段例外**：源图四个数字都清晰时，允许「页边界合法回退/分段重置」（如 wz7 p1720–1723 的
  78→76、77→76，见 §2）；记录例外 + 源图 crop，**不得为满足非降而改源图数字**。页内仍按非降校验。
- **领域假设**：非降只适用于「年表/连续编号」段；其他书若没有该语义，**关闭/配置**此约束，只做人工/API 读数。
- **输出**：最终值/置信/依据；失败 → 人工/不落库。

#### 第 4 步：落库与渲染

- **输入**：第 3 步的最终 `number`/置信/依据 + 检测阶段的 `col/source_x/y/text` 证据。
- **落库**：`class="ring"`，`situation` 1/2；`number` 为最终值；`col/source_x/y/text` 证据齐全；
  `situation=1` 的文本尾数字只用于定位，替换为占位符；`situation=2` 追加占位符。
- **运行时**（`_apply_missed_fix`）：按 `(page, col)` 分组；与当前列框小容差匹配（当前固定 0.6pt，L542；实现默认，参考值非判据）；page 越界/列未匹配 → 跳过 + 日志，
  **不做部分落库**；一个 ring 只产生一个占位符。situation=1 若文本尾无数字 → 打日志并**改走 situation 2 追加**（fallback）。
- **渲染**（`_ring_put`）：
  - `number ≤ 50`：Unicode 圈码字形（①–⑳ / ㉑–㉟ / ㊱–㊿），整圆、不做横向压缩；
  - `number > 50`：`○` 字形 + 小号数字（源书 >50 无标准圈码）；
  - 字号 = `RING_SIZE × 正文字号`（比例，不写死 pt）；圈心 = 该格中心；
  - 文本层输出圈码字形（≤50 Unicode 圈码；>50 为 ○+数字合成），占位符只用于运行时分支、**不落 fix JSON**；不改其他字/列位。
- **失败处理**：`number` 超出支持范围/无字体字形 → 合成圈或跳过并登记；渲染越界/重叠 → 回到检测/人工。

#### 第 5 步：验证

- **输入**：v42/vN 产物、fix JSON、源图裁片、verify 报告。
- `verify_vert`：页数 1:1 / 整页丢失 0 / 越界 span 0 + 矢量 0；字符量按**实际渲染字形**计，按位数写清：
  - situation 1：`sl` 长度 `1−d`（d=2 → **−1**，d=1 → 0）；渲染 ≤50 为 1 字形（字符量净 `1−d`：2 位 **−1**、1 位 0）；>50 为 `○+d` 位（字符量净 **+1**）。
  - situation 2：`sl` +1 占位符；渲染 ≤50 净 **+1**，>50 净 **+3**（○+2 位）。
  - 以 verify 实际值为准；不要假定固定 +1/0。
- 逐条/抽样：源图 crop 与产物圈码字形对照（按条目数/可疑项比例抽样，含 >50 合成圈、页边界项）；文本层/占位符核对。
- 回归：无版框有版框书零回归（`vert.tex` 逐字节）、pytest（`ring_judge` 纯函数测试）；
  判据未放宽（`verify_vert.py` 不变）；token 不入库。
- **失败**：任一门禁失败 → 不落库/重建；页边界例外必须带源图证据，不得用「序列非降」掩盖读数错误。

### 1.4 参数表（全部相对/自标定）

| 参数 | 形式 | 来源 |
|---|---|---|
| `step` | 本页长列「框高/字数」中位 | 每页/每书自标定 |
| 尺寸窗 | 设计目标 `[w_lo,w_hi]×step`、`[h_lo,h_hi]×step`；当前 P_V2 为 wz7 pt（§3#1；实现默认，参考值非判据） | 每书正/反例标定 |
| `edge_min` / `ctr_min` / `fill_max` / `ar_lo,ar_hi` | 无量纲比值 | 每书正/反例标定 |
| 灰度阈值 | 设计目标：局部中位 − 相对偏移；当前固定 `median − 20`（§3#3；实现默认，参考值非判据） | 按扫描灰度自标定 |
| 检测 DPI/矩阵 | ≥ 2×源像素/step 的过采样 | 按源扫描分辨率选择 |
| 模板接受阈值 | top-1 分 + 与第二名的间隔 | 每书模板库标定 |
| 序列区间/候选数 | 相对条数/分差 | 每书/每段配置 |
| `RING_SIZE` | 圈码字号 / 正文字号（比例） | 每书标定 |
