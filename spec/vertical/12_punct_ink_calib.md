# 12. 标点墨迹口径标定（尺寸 / 格内位置 / 锚点）

状态：**implemented**（taskT，2026-10-16；wz7 300 页 `verify_vert` PASS、wz6 逐字节零回归）
完整报告：`docs/vert_punct_ink_report.md`。测试：`src/test/unit/test_vert_taskT.py`（12 项）。

## 目标

用户多轮反馈「**标点还是跟字体重合了**」。本轮把标点的**墨迹尺寸 / 格内位置 / 墨心锚点**三项
从「口径混用」改为「源书墨迹实测 + 与渲染同源」，并给出两侧同口径的量化对账。

承接 [11_short_col_punct_cell.md](11_short_col_punct_cell.md)：taskS 已定 `PUNCT_CELL`（标点是否独占一格），
本轮修的是**在同一格口径下**标点摆在格里的哪个位置、多大、以及锚点偏移取自哪个口径。

## 输入 / 输出

* 输入：源图墨迹（`_nf_ink`，逐页 Otsu + 去印刷线）、槽/行列栅格（`page_metrics` + `_align_rows_slots`）、
  OCR 行文本、格号（`char_cells`）、探针渲染（`_calib_probe`，同 preamble 真编译）。
* 输出：四个标量/表 —— `PUNCT_DY`（墨心相对**前一字格顶**的偏移，步进为单位）、
  `PUNCT_DX`（墨心相对槽左缘，格距为单位）、`PUNCT_SIZE`（标点字号/正文字号）、
  `GAP_HANG`（标点墨顶相对前字格顶，`fit_gaps` 的预测锚点）、
  `PUNCT_INK`（标点字形墨心相对 `\put` 锚点的偏移表，em）。

## 口径（两侧必须同源）

两侧都按「**墨迹像素**」量，不用 PDF 文本层：

* 源书侧：2x 灰度 + 逐页 Otsu（`_nf_ink`）+ 去印刷线 → 连通域（scipy `label`，默认 4 邻域）。
* 产物侧：同 PDF 按 2x 渲染 + 同一套 Otsu/去线/连通域函数（`_nf_delines` + `label`）——
  两侧**只有被测墨迹不同**：槽格/行配对/文本/格号全部取自源图几何，故差异可比。
* **判据量**：标点墨迹 bbox（高/宽）、墨心（bbox 中心）、与前/后字墨迹的**最短二维距离**
  （`distance_transform_edt`，0 = 相碰）、墨心相对前字墨心的偏移（步进为单位）。
* **禁用**：PyMuPDF 的 span bbox 判重合 —— 竖排 span 的 bbox 高 ≈ 2.74×字号（与码位无关），
  用它判「重叠」会报出 1.6 万处假重叠（用户侧第一轮检测的假象）。

## 已知遗留（不在本轮范围）

1. **字重**：产物单页墨迹像素约为源书的 69%（扫描件的墨更粗 + 阈值把灰晕算进墨迹）；现有开关
   `VERT_BOLD`（描边加粗，默认 0）可调，本轮不动。见报告 §6.1。
2. **列内步进**：实测同列平均步进 源书 31.76pt vs 产物 31.48pt（−0.9%），非「字距偏松」；报告 §6.2。
3. **正文墨高**：逐字墨迹盒高与源书相同（列剖面中位 27.0 vs 26.5pt）；报告 §6.2。
