## 目标

竖排书的**框外小字**三件套——书眉（篇名）、页码（汉字数码）、边注（版心外注文/题注）——
按源书**实测墨迹位置**逐字绝对定位渲染（不进正文列流）。

## 背景（三条实测事实，勿凭直觉）

1. **eso-pic 必须用带星号形式**：`\AddToShipoutPictureFG*{...}` = 仅本页；
   `\AddToShipoutPictureFG{...}`（无星）是**逐页累积** —— 第 N 页会把此前所有页的 `\put` 元素重画一遍
   （实测 probe：第 4 页出现「論持久戰 一八0 論持久戰 一八二」）。症状表现为书眉与正文重叠"发虚"，
   容易被误判成坐标错。诊断手段：`awk` 剥掉 vert.tex 的正文行只留 `\put` 层再编译（探针 PDF），
   文本提取即可看到累积。
2. **边缘小字坐标只能用源图墨迹实测定**：OCR bbox 对边缘小字偏移 **18-40pt**
   （p4 边注 OCR x54-104，实墨 x94-122；页码 OCR 偏低 45pt）。字号也不能按 OCR 字数反推（OCR 会漏字）。
3. **tate 下 `\put` 坐标轴**：先把 `\paperheight` 设为真页高，FG 锚点才落在**页真左下**；
   y 向上，参考点 ≈ 字墨迹底（baseline）；逐字手工断列（每字一个 `\put`）。
   标定：`X_CAL=0`（put x = 字盒左缘）、`Y_CAL=0`（put y = 墨迹底）。

## 方案

### 1. 书眉 / 页码（`special_rows` + `special_tex`）

- **候选行**：非正文长列（`h < 小字阈值`，实现默认 300px）、文本 2–10 字（参数默认）、位于左右边缘（`x0 > 边缘阈值` 或 `x1 < 边缘阈值`；默认 1100/100，非判据）；
  并剔除「被更长的同行竖向包含」的碎片（边注/长列断行残片）。
- **类型**：全数码字符集（`0123456789〇零一二三四五六七八九十百千`）→ 页码 `pn`；其余 → 书眉 `hd`。
- **坐标**：`ink_extent(pi, ...)` 在 OCR 行邻域（x ± 窗口、y −/+ 窗口；实现默认 70/250px，非判据）内取小字连通组件并集：
  门限宽/高/面积按源图字高自标定（实现默认 4–40px / 5–90px / ≥40px²，非判据）、不贴窗口边缘（裁剪碎片丢弃）、
  y 中心不落在同页其它特殊行的 OCR 区间内（p7「第二卷」/「抗日戰爭時期」紧邻，靠此分离）；
  另设上界 `floor`（已被上一特殊行占用）与整段墨迹高上限（OCR 行长 × 1.3，防并入邻行）。
- **字号 / 步进**：`字号 = clamp(墨迹高/字数/1.15, 9, 20)`（9/20/1.15 为参数默认，非判据），单字墨高 `gink = 0.88 × 字号`（0.88 为字体标定参数）
  （Noto CJK ink 比，probe 实测），`步进 = max(0.98 × 字号, (墨迹高 − gink)/(字数−1))`（0.98 为参数默认）
  → 整段墨迹上下缘与源书对齐。
- **渲染**：一次 `\AddToShipoutPictureFG*` 内多个 `\put(x, y){\fontsize{f}{f}\selectfont 字}`。
- 页码文本先过 §1.87 序列纠正（见 [05_pagenum_sequence.md](05_pagenum_sequence.md)）。

### 2. 边注（`note_rows` + `note_cols` + `note_tex`）

- **候选行**（`note_rows`）：未被书眉/页码认领（`claimed` 集合），且字步进 ∈ [下限, 0.85 × 正文字步进)（下限实现默认 15px，非判据），
  且（版心外：`x0 < 边缘阈值` 且 `x1 ≤ 最左正文列 x0 + 余量`；默认 100/+2，非判据）或（`*` 开头的题注列）。
  步进下限 15px 挡 OCR 噪声页（末页 JSON 残片步进 1.1px）。
- **字列实测**（`note_cols`）：边注区内取连通组件（尺寸窗为步进倍数：默认 0.25–2.2×，非判据），剔版框线/界行线/噪点后
  按**组件 x 中心**聚类成竖列（阈值 0.75 × 组件宽中位（参数默认））；单组件列丢弃（噪点）。
  字步进 = 组件顶距中位（**自然步进**，比「行程 ÷ (字数−1)」稳 —— OCR 少读时会算出荒谬步进（实测例见 §参考基线））。
- **行 ↔ 列配对**：OCR 边注行按 x0 **降序**（竖排阅读序）与实测字列（同样 x 降序）按序 `zip` ——
  注文太长会在下一子列续排（p4 注头在右子列、末尾「的講演」续在左子列），子列间无白缝，只能靠结构配对。
- **字号**：`min(26, max(9, 字高中位/2 ÷ 0.88))`（9/26/2/0.88 为参数默认；不按字数反推，p4 实例见 §参考基线）。
- 正文流里剔除已由 `note_tex` 绝对定位渲染的行（`page_tex(drop_notes=True)`），避免重复。

## 输入 / 输出

- **输入**：OCR 行（文本 + bbox）、源 PDF（灰度实测 `src_gray`，缓存 8 页 FIFO）
- **输出**：每页若干 `\AddToShipoutPictureFG*{ \put(逐字) }` 片段；stdout 逐条日志
  （`[页码] p4 一八〇 墨迹x.. y.. 字号.. 步进..`）

## 约束

1. **任何逐页 `\put` 页面元素必须用带星号版本**（[01_engine.md](01_engine.md) 同约束）；
2. 坐标/字号一律源图墨迹实测，不问 OCR bbox（偏移 18-40pt）；
3. `VERT_SPECIAL=0` 关闭三件套（纯正文流）；需源 PDF 才能测墨迹（无 `--src-pdf` 时自动关闭）；
4. 依赖：`numpy` + `scipy.ndimage`（连通组件）、fitz（渲染源页灰度）。

## 验收方法

1. stdout 日志逐条核对（本书三件套计数见 §参考基线；#27 实测复核）；
2. 抽页对照源书墨迹：p4 书眉/页码/边注坐标见 §参考基线；；
3. 无"逐页累积"：探针 PDF（只留 `\put` 层）文本提取，每页只应出现本页元素；
4. `verify_vert.py` 字符量对照（书眉/页码/边注计入输出字符，OCR 侧同样计入）。

## 测试点

- eso-pic 带星版：第 N 页不出现前页元素
- 页码文本 = §1.87 纠正后的文本（不是 OCR 原样）
- 题注（`*` 开头）列绝对定位、不占正文列位
- `VERT_SPECIAL=0` 时不产生 `\put` 片段

## 已知遗留

- **页码行合并页**：OCR 把「书眉+页码」合成一个超过小字阈值的框 → 被 `special_rows` 丢掉（p3 无页码渲染）；
- 题注按实测字列绝对定位、不占正文流列位，源书落在列间空档，输出可能与相邻列贴得近（预存在）。
