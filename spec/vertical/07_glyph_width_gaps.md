## 1. 目标

用户逐页实测反馈两项，都指向「重建页与源书的墨迹疏密不一致」：

1. **「看着密密麻麻」**：重建页墨迹覆盖率比源书高 17-25%（p10 0.171 vs 0.146 / p14 0.154 vs 0.127 /
   p100 0.151 vs 0.121；单列同向 +13~29%）。
2. **「問：/答：」后源书空一格**：我们的数据与渲染都没有（spotting OCR 不保留排版空格）。

## 2. 测量（数据驱动，先测后改）

口径：源图/产物同用 4x 灰度、阈值 150（源书纸峰 253 / 墨峰 47，故 150 正是源书的**半墨位**阈值）、
逐列墨迹 run 逐字取（墨高、墨宽、墨迹面积、字步进、列距）。逐字样本 p10/p14/p100 = 225/172/201 字。

| 量 | 源书 | 本项目（Noto Serif CJK TC） | 比 |
|---|---|---|---|
| 墨高 | 29.75pt | 29.25pt | ×0.98 |
| **墨宽** | **20.0pt** | **29.25pt** | **×1.48** |
| 墨迹面积（逐字中位） | 205.6 / 202.8 / 192.1（p10/p14/p100） | 233.1 / 235.6 / 228.4 | ×1.13/1.16/1.19 |
| 宽高比 | 0.67（长体/窄体宋，竖排老铅字常态） | 1.00（全角方体） | — |

结论：覆盖率差 = **字宽因子 ×1.48 > 填充率因子 ×0.79**（源书笔画相对更粗）× 墨高 ×0.98 的合成；
即**主要是字模横向宽度偏大**，不是墨高、也不是步进（步进实测两侧同为 31.0pt，列距同为 43.5pt）。
覆盖率 ≈ 墨宽 × 墨高 / (步进 × 列距) 的分解与逐页核对见报告 §2。

## 3. 字模横向压缩（A）

逐字横向压缩（保字高），实现于 §1.0a。**实现方式在 taskJ2 换过一次（泄漏修复）**：

- **taskJ（旧）**：`\scalebox{K}[1]{...}`。它的 btrans/x:scale/etrans 由 dvipdfmx 展开为
  「平移到锚点·缩放·平移回」，`etrans` 用**数值逆矩阵**还原且只印 6 位有效数字
  （1/0.87 = 1.149425… → 印成 `1.14943`）→ **每字在 CTM 残留 x1.0000041**，N 字累积污染同页
  后续内容坐标。实测 N=2000 字时页尾规则线从 0.00..571.86bp 漂到 **−2.34..574.29bp**（越出页缘）；
  本书表现为 `verify_vert` 矢量越界 4 个（p157，最深 0.82pt，即 `draw bbox=[-0.8,284.7,572.6,284.7]`）。
- **taskJ2（现）**：改为自写 PDF 算子
  `\special{pdf:literal direct q <K> 0 0 1 0 0 cm}…\special{pdf:literal direct Q}` ——
  `Q` 是图形状态栈的**精确还原**（非数值逆）→ 残差恒 0（N=2000 实测规则线恒为 0.00..571.86，
  与不压缩态逐值相同）。`\usepackage{graphicx}` 随之下线。
- **锚点语义（两版一致，实测 `probe_literal.py`/`probe_anchor.py`）**：缩放参考点 = 字盒**左缘**；
  新实现因 `cm` 相对**页 x=72bp**（dvipdfmx DVI 原点 1in）缩放，写入坐标须反解
  **`put 值 = (X − 72)/K + 72`**（K=1 退化为 X）。调用方仍传「缩放后字盒左缘的目标页坐标」：
  墨心 = `put_x + K × 原墨心偏移`，故 `put_x = xc − K × F/2`（不补偿则整列左移 (1−K)·F/2 = 2.2pt）。
  三态墨迹对照（plain / 新 / 旧 `\scalebox`）：新实现与旧的墨迹位置与墨宽**逐字相同**。
- **K = 0.87**（`VERT_XSCALE`）：由 p10/p14/p100 三页按「修后逐字墨迹面积 vs 源书 ≤5%」标定；
  实测修后 202.8 / 205.1 / 197.2 vs 源 205.6 / 202.8 / 192.1 → **−1.4% / +1.1% / +2.7%**。
- **不动**：步进/列距/列位/列顶列底（框驱动基准）、标点挤格（标点字号与墨心定位同步按 K 缩放，
  `put_x = tx − K·dx·Fp`）、字号保护、边注/书眉/页码（**未压缩**，见 §6 遗留）。

## 4. 列内空隙对齐（B）

源书「問：」「答：」后空一格 —— 只能从源图墨迹反推。**难点**：源书字距紧（墨高 ≈ 步进），
相邻字常相碰并成一个 run（顶差也 = 2 步进），挤格标点的墨又落在格缝上 —— 单看「顶差 > 1.3×中位步进」
会被两类假象骗过。故用**结构对齐 DP**（`fit_gaps`）：

- 输入：本槽墨迹 run 序列（`page_metrics` 新增 `runs` 字段，逐字墨顶/墨底 pt）+ 本列文本
  （逐字**格号** `char_cells`：挤格标点与前字同格）。
- 状态 `(字符下标, run 下标, 已插格数)`；转移：匹配（代价 = |预测墨顶−实测墨顶|/步进 的平方）、
  并进上一 run（预测墨顶落在该 run 内 = 粘连）、标点跳（不参与匹配，见下）、普通字无墨（贵，
  防「跳字 + 中途插格」凑数）、跳过 run、**插一格**（0.55）。
- 预测墨顶 = `槽墨顶 + (格号 + 已插格数 + 0.85×[挤格标点]) × 步进`。
- 收口：末字格号与「槽实测墨迹跨度折合格数」`(B − T − 墨高)/步进 + 1` 的差（每格 1.0）——
  **必须减墨高**，漏减会系统性多算 ~0.95 格 → 每列都误判一处空隙（实测 p14 exp 22.89 vs 真值 22）。
- 两条硬校验：
  ①**挤格标点不参与匹配**（源书冒号墨心在本字格顶 +1.2~1.4 步进，与渲染端 `PUNCT_DY=0.85` 不一致，
  拿它做匹配依据会把整列带偏：实测 p14 答：列空隙被错插到第 17 字）；
  ②**逐格校验**：空格格内不得有墨 —— 借此把「排版空格」（该补）与「OCR 漏字」（格内有墨，补空格
  只是掩盖丢字）分开；
  ③插入点若落在挤格标点之前，后移到标点之后（源书标点紧跟上字字脚；DP 对两种插法代价相同）。
- 渲染：该格**只推进不落墨**（`col_puts` 的 `gap_at`），并计入排版格数 `nc`（步进随之按真实格数均分）。

## 6. 遗留

1. **空隙格内容**：检出 = 「源书该列比 OCR 文本多占一格」。其中①真排版空格（問：/答： 类，样例已确认）
   我们补空格 ✓；②源书那格是**未识别的小标记**（夹注/校勘号一类）→ 我们留白：格数/对齐正确、
   内容层少一个标记（任务书单点判据在源侧不可用、三种独立复核口径的失效分析见报告 §2.4）。
   后续可把该类标记纳入 `src/tools/patch_vert_symbols.py` 的补全（需扩符号集）。
2. **字模仍未完全对齐源书**：K=0.87 是「覆盖率口径」的解（墨迹面积对齐），源书字模本身更窄
   （墨宽 20.0 vs 我们 20.0/0.87 ≈ 23；宽高比 0.67 vs 0.80）。若要**字形**也一致需 K≈0.68，
   但那样我们比源书**轻 20%**（源书笔画被印墨/扫描展宽）。取舍与备选（换长体字模、按字数分布
   逐字微调）见报告 §5。
3. **边注/书眉/页码未压缩**（仍全角方体）：它们的字号由墨高实测反推、位置由 `\put` 绝对定位，
   本轮未动以免回归；如需要可复用 `_put_tex`（同一 K）扩展。
4. **OCR 漏字与排版空格同形**：靠「格内有墨」校验区分（§4②），漏字列不补（丢字问题另见
   `docs/vert_readability_report.md` 的符号补全链路）。
5. **K 的整页自适应**：目前全书单一 K（源书各页墨宽实测 p25-p75 差 ≤1pt，单值够用）；若换书
   应按页回归（脚本 `tmp_vert/taskJ/measure_char2.py` 可直接出该数）。
6. **p100 覆盖率不再压**：逐字墨迹面积口径已 +2.7%（≤5%）；内框区墨迹占比口径为 **−5.8%**
   （我们已比源书浅），继续压会反向偏离。
