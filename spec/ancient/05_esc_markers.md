# Spec: 校注标记转义 + 符号修正

## 目标
正文行中的校注标记 [X]/〔X〕/【X】转上标（小字）；修正 OCR 符号错误（○->〇、【】->〔〕）。

## 方案
### 校注标记上标
- 正则 `(?<=\S)[〔【[]([X])[】〕\]]`（前有文字=校注标记 -> 上标）
- 行首 [X] -> 〔X〕白括号（不上标，注释序号）
- MARKER_SCALE 0.55（上标字号 = 0.55×正文）
- 上标 \smash + \raisebox + \makebox[字号×字数]（占全字宽，防 makebox[s] 收缩补偿）

### 符号修正
- ○（U+25CB 字体不支持 -> ￿）转 〇（U+3007 CJK零）
- 【 -> 〔、】 -> 〕（OCR 误识白括号）
- _esc_chars 加映射

### $ ^{[X]} $ 处理
- LaTeX 语法 $...$ 内的上标标记 -> 上标
- $ ^{} $ 剥语法保留 [X]

## 输入
- spotting 行文字（含 [X]/〔X〕/【X】/$ ^{[X]} $/○/【】）

## 输出
- 行中校注标记 -> 上标 sz=0.55×正文
- 行首 [X] -> 〔X〕（白括号，不上标）
- ○ -> 〇
- 【】 -> 〔〕

## 约束
- [X] 和〔X〕都匹配
- 上标占全字宽（防 makebox[s] 收缩 -6pt）
- 不影响注释序号（行首不上标）

## 测试点
- p11 〔一〕~〔二七〕sz=8.6pt（上标）
- p11 〔一〇〕/〔二〇〕sz=8.6pt（○ 正则匹配）
- p20 无"】"（转〔〕）
- p32 〔一〇九〕（○ -> 〇）
