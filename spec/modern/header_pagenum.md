# Spec: 页眉 + 页码

## 目标
页眉顶部小字（共识校正 OCR 拆分）；页码 \setcounter（不占版心）+ 补全。

## 方案

### 页眉
- 识别：`y0 < page_px_h × 0.05`（页顶5%）+ `len(t) < 30`
- 原始行合并：`page_header_raw(key)` 提取页顶行
- 共识吸附：`CANON_HDRS`（全书出现 ≥3 次的规范页眉）
  - OCR 拆分/截断/混噪声校正（如"第一部分"+"历史考"->"第一部分历史考证"）
  - 匹配规范页眉（编辑距离/子串）
- 渲染：顶部小字 `FONT_SM`

### 页码
- 识别：`PN_RE`（`[·•.]?\s*\d{1,4}\s*[·•.]?$`）+ `y0 > page_px_h × 0.80`（底部）
- 渲染：`\setcounter{page}{N}`（LaTeX 页脚，不占版心）
- 补全：
  - `pntab`（页码表，`PAGENUM_GLOBAL_TABLE` env）
  - 连续推断（前后页 ±1，后向优先）
  - 封面/目录页（key<10）不补

## 输入
- spotting 行 y0、文字
- `page_px_h`、`PN_RE`
- `pntab`（页码表）

## 输出
- 页眉顶部小字（共识校正）
- 页码 \setcounter（页脚）

## 约束
- 页眉共识需 ≥3 次出现
- 页码 PN_RE + y0>80%（防正文数字误判）
- 封面/目录页不补页码

## 测试点
- wz1 页眉共识校正
- p11 页码=1
- 页码补全（缺失页）
