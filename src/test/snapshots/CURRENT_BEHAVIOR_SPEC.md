## diff 判断指引（重构后）

重构后重新生成 `_verify_*.json`，diff `baseline_*.json`，结合本 spec 判断：

| 样本 | 判断原则 |
|---|---|
| **wz1**（现代书主力） | pitch 应稳定 89%+。下降 = 回归。split 应保持 0。 |
| **优化前**（小样本） | 波动大，65% 作参考，小幅变化（±5pp）可接受。 |
| **wz2**（极端案例） | pitch 58.8% 变化需**人工判断**：降到 55% 可能是修夹注/案注的可接受代价；空白 87 变化看是否附录区调整。split 应保持 0。 |

**通用**：
- 三本 `overflow_pages`（split）应保持 0（1:1，校准生效）。若 >0 = 校准失效回归。
- `blank_pages` 大幅增加 = 排版变松（可能是字号/行距变化）。
- `pitch_ok_pct` 对图页/卷名/附录页（spec 标注的最差页）波动可接受；正文页 pitch 下降才是回归。

## 与 baseline_*.json 的关系

本 spec 是**定性 + 分布**的现状描述；`baseline_*.json` 是从同一 `_verify_*.json` 提取的**5 个量化指标**。两者同源（同一管线输出 + 同一 verify 口径），重构后一起 diff：
- baseline JSON 指标变化 -> 查本 spec 定位是哪类页/特征变化 -> 人工判断。
