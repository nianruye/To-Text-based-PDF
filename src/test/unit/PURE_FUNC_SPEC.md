# 纯函数单元测试 · 行为 Spec

> 对象：`build_pdf_v13.py` / `build_classic.py` / `build_geom.py` 中的 12 个纯函数。
> 原则：函数不依赖文件系统/外部命令/环境变量（`esc` 依赖全局 `FONT`、`_has_trad` 依赖 `_t2s`，测试用 mock 注入），只做输入->输出变换。
> 对应测试：[test_pure_funcs.py](test_pure_funcs.py)（每个 spec 条目标注对应测试类）。
> 加载方式：[ _loader.py](_loader.py) 用 ast 提取函数到隔离 namespace，绕开模块顶层副作用（不 import fitz/opencc）。

## 契约约定

- **正常输入**：典型业务文本 -> 期望输出
- **边界输入**：空串 / 纯标点 / 全角字符 / 极端格式 -> 期望输出（兜底或原样）
- **异常输入**：`None` -> 抛异常（AttributeError/TypeError）；超长字符串 -> 正常处理不抛异常

## build_pdf_v13.py

### clean_text(text) — L19-20
**契约**：`text.lstrip("‖‖| \t")`，去掉左侧 `‖`(U+2016)/`|`/空格/`\t`；右侧不动；全角空格(U+3000)不在字符集，不去。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"‖第一章"` / `"|标题"` / `"  缩进"` | `"第一章"` / `"标题"` / `"缩进"` |
| 边界 | `""` | `""` |
| 边界 | `"‖|"`（全是可去字符） | `""` |
| 边界 | `"标题‖"`（右侧） | `"标题‖"`（不去） |
| 边界 | `"　全角"`（U+3000） | `"　全角"`（不去） |
| 异常 | `None` | AttributeError |
| 异常 | 超长字符串 | 左侧可去字符剥光后正常返回，不抛异常 |

对应测试：`TestCleanText`

### normalize_text(text) — L32-39
**契约**：`re.sub(r'\s+','',text)` 去所有空白 + `translate(_QUOTE_MAP)` 归一引号（ASCII`"`/`“`/`”` -> 统一为同一双引号字符；`‘`/`’` -> ASCII`'`；`、`不变）。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"a b"` / `"a\tb\nc"` | `"ab"` / `"abc"` |
| 边界 | `""` / `"  "` | `""` / `""` |
| 边界 | `"、"` | `"、"` |
| 边界 | `'“a” “b” ‘c’'`（弯引号） | 无空白；单引号归一为 ASCII`'`；所有双引号归一为同一种字符 |
| 异常 | `None` | TypeError（re.sub on None） |

对应测试：`TestNormalizeText`

### escape_tex(text) — L41-46
**契约**：标准 LaTeX 转义，**保留** `\ { }`（`\`->`\textbackslash{}`，`{`->`\{`，`}`->`\}`，`& % # $ _ ~ ^` 各自转义，转义符**单反斜杠**）。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"a%b"` / `"$5"` / `"a#b&c"` | `"a\%b"` / `"\$5"` / `"a\#b\&c"` |
| 正常 | `"{x}"` | `"\{x\}"`（保留花括号） |
| 边界 | `""` / `"中文"`（无特殊字符） | `""` / `"中文"` |
| 副作用 | `"a\b"`（单反斜杠） | `"a\textbackslash\{\}b"`（`\textbackslash{}` 里的花括号被后续 `{`/`}` 规则二次转义） |
| 异常 | `None` | AttributeError |

对应测试：`TestEscapeTex`

### escape_body(text) — L48-70
**契约**：escape_tex + 处理 `$...$` 内联（`$^{x}$`->`\textsuperscript{x}`，内容经 escape_tex；`$\frac{a}{b}$`等数学->纯文本 a/b 后转义；孤立`$`->`\$`）。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"plain text"` / `"a%b"` | `"plain text"` / `"a\%b"` |
| 上标 | `"a $^{[八五]}$ b"` | `"a \textsuperscript{[八五]} b"` |
| 数学 | `"$\frac{1}{3}$"` / `"$\alpha$"` | `"1/3"` / `"alpha"` |
| 边界 | `""` | `""` |
| 边界 | `"price $5"`（孤立$无闭合） | `"price \$5"`（走 escape_tex） |
| 异常 | `None` | TypeError（re.split on None） |

对应测试：`TestEscapeBody`

### is_page_number(t) — L72-75
**契约**：正则 `^[·•‧]?\s*\d{1,4}\s*[·•‧]?$` 命中，或纯 `^\d{1,4}$` 且 `len<=4` -> True，否则 False。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"123"` / `"1"` / `"·45·"` | True |
| 边界 | `"  12  "`（前后空白） | True |
| 边界 | `"12345"`（5位） / `"12a"` / `"abc"` / `""` | False |
| 异常 | `None` | AttributeError |

对应测试：`TestIsPageNumber`

## build_classic.py

### _esc_chars(s) — L200-206
**契约**：通用转义，**删除** `\ { }`（双反斜杠`\\`->删，单`\`保留）；`% & # _ ^ ~` 转义为**双反斜杠**形式（源码 `r'\\%'`，疑似 bug）；`○`->`〇`；`【`->`〔`、`】`->`〕`；圈码`①..⑩`->`\textcircled{N}`（单反斜杠，来自 _CIRC）；省略号归一化（`⋯⋯`/`⋯`->`…`，`……`->`....`，`…`->`.`）。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"a%b"` | `"a\\%b"`（双反斜杠） |
| 正常 | `"○"` / `"【注】"` / `"①"` | `"〇"` / `"〔注〕"` / `"\textcircled{1}"` |
| 边界 | `""` | `""` |
| 边界 | `"{x}"` | `"x"`（花括号删除） |
| 边界 | `"a\b"`（单反斜杠） | `"a\b"`（保留，只删双反斜杠） |
| 边界 | `"a\\b"`（双反斜杠） | `"ab"`（删除） |
| 边界 | `"…"` | `"."`（省略号归一） |
| 异常 | `None` | AttributeError |

对应测试：`TestEscChars`

### esc(t) — L208-230
**契约**：_esc_chars + `$...$` 上标/数学 + 裸`[X]`校注上标。上标用 `\makebox`+`\smash`+`\raisebox`+`\fontsize` 渲染（字号=全局`FONT`×`MARKER_SCALE`，测试注入 `FONT=10.0`、`MARKER_SCALE` 默认 0.55）。行首`[X]`->`〔X〕`序号（不上标）；行中`[X]`（前有文字）->上标。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"plain 文本"` / `"a%b_c"` | `"plain 文本"` / `"a\\%b\\_c"` |
| 正常 | `"{x}"` | `"x"` |
| 数学 | `"$\frac{1}{3}$"` | `"1/3"` |
| 上标 | `"$^{[八五]}$"` | 含 `〔八五〕` + `\makebox` + `\fontsize`，无 `$`/`^` |
| 上标 | `"始元六年[二]"`（行中裸标记） | 含 `〔二〕` + `\makebox`，无 `[二]` |
| 行首 | `"[一]正文"` | `"〔一〕正文"`（不上标，无 `\makebox`） |
| 边界 | `""` | `""` |
| 异常 | `None` | TypeError |

对应测试：`TestEsc`

### _math_to_plain(m) — L192-197
**契约**：入参为正则 match 对象（`group(1)` 为 `$...$` 内容）-> 纯文本。`\frac{a}{b}`->`a/b`；`\command`->`command`；残余花括号去掉。

| 类别 | 输入（$...$ 内容） | 期望输出 |
|---|---|---|
| 正常 | `\frac{1}{3}` / `\frac{ab}{cd}` | `"1/3"` / `"ab/cd"` |
| 正常 | `\alpha` | `"alpha"` |
| 边界 | `{a}` | `"a"`（去花括号） |
| 边界 | `\sqrt{x}` | `"sqrtx"`（去`\command`+花括号） |
| 边界 | `plain` | `"plain"` |
| 异常 | 非 match 对象 | AttributeError（`m.group`） |

对应测试：`TestMathToPlain`

### _split_heading(t) — L235-241
**契约**：拆标题序号前缀 -> `(前缀, 剩余)`。匹配 `第X部分/章/节/编/篇`、`(一)/一`、`1.`等；中文数字后接 `百/千/万/亿` 不匹配（lookahead）；不匹配 -> `('', t)`。

| 类别 | 输入 | 期望输出 |
|---|---|---|
| 正常 | `"第一部分 引言"` / `"（一）概述"` / `"1. 标题"` | `("第一部分","引言")` / `("（一）","概述")` / `("1.","标题")` |
| 边界 | `""` | `("", "")` |
| 边界 | `"正文无序号"` | `("", "正文无序号")` |
| 边界 | `"一百"`（一后接百） | `("", "一百")`（lookahead 排除） |
| 异常 | `None` | AttributeError |

对应测试：`TestSplitHeading`

### _eff_chars(t, pw=PUNCT_WEIGHT) — L522-526
**契约**：先剥校注标记 `_MARKER_RE`（`$^{[X]}$` / 裸 `[X]`），再统计：CJK 字(`ord>0x2e80`)=1.0，标点/拉丁/数字=`pw`（默认 `PUNCT_WEIGHT=0.2`）。

## 对比测试（功能相似函数）

### escape_tex(v13) vs _esc_chars(classic)
同一输入，两者输出差异（`TestCrossFuncDivergence.test_escape_tex_vs_esc_chars`）：

| 输入 | escape_tex (v13) | _esc_chars (classic) | 一致？ |
|---|---|---|---|
| `"{x}"` | `\{x\}`（保留转义） | `x`（删除） | 不一致 |
| `"a\b"` | `a\textbackslash\{\}b`（转义+二次转义） | `a\b`（单反斜杠保留） | 不一致 |
| `"○"` | `○` | `〇` | 不一致 |
| `"【注】"` | `【注】` | `〔注〕` | 不一致 |
| `"a%b"` | `a\%b`（单反斜杠） | `a\\%b`（双反斜杠） | 不一致 |
| `"#"` | `\#` | `\\#` | 不一致 |
| `"plain"` | `plain` | `plain` | 一致 |

### _heading_core: v13 vs geom
| 输入 | v13 | geom | 一致？ |
|---|---|---|---|
| `"第一部分 引言"` 等无引号 | 剥编号+去空白 | 同 | 一致 |
| `"“引”言"`（弯引号） | 归一化（`“”`->ASCII`"`） | 原样保留 | 不一致 |

> v13 末步调 `normalize_text`（引号归一），geom 末步只 `re.sub(\s+)`。注：ASCII `"` 在 `_QUOTE_MAP` 是 identity，必须用弯引号才体现差异。

对应测试：`TestCrossFuncDivergence.test_heading_core_v13_vs_geom_*`

## 超长输入（异常类）

所有 12 函数对超长字符串（如 10000 字符）应**正常处理不抛异常**（Python 字符串无长度限制，转义/正则/统计按字符线性处理）。对应测试：`TestLongInput`。
